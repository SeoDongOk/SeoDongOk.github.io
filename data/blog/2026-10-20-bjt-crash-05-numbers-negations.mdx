## 왜 틀리는가

BJT는 단어를 알아도 시간, 수량, 비교, 이중부정을 놓치면 정답이 뒤집힌다. 특히 처음 나온 숫자를 기억하고 마지막 수정 숫자를 놓치는 경우가 많다.

## 시간·마감 표현

| 표현       | 읽기               | 뜻          | 판별                  |
| ---------- | ------------------ | ----------- | --------------------- |
| まで       | まで               | ~까지       | 동작·상태의 끝        |
| までに     | までに             | ~까지       | 그 시점 이전 완료     |
| 以降       | いこう             | 이후        | 기준 시점 포함 이후   |
| 以前       | いぜん             | 이전        | 기준 시점 포함 이전   |
| 遅くとも   | おそくとも         | 늦어도      | 최종 마감             |
| 早くても   | はやくても         | 빨라도      | 가장 이른 시점의 하한 |
| 前倒し     | まえだおし         | 앞당김      | 날짜가 빨라짐         |
| 延期       | えんき             | 연기        | 날짜가 늦어짐         |
| 一週間おき | いっしゅうかんおき | 일주일 간격 | 매주                  |
| 隔週       | かくしゅう         | 격주        | 2주에 한 번           |

### `まで`와 `までに`

- `五時まで働きます`: 5시까지 계속 일함
- `五時までに提出します`: 5시가 되기 전에 제출 완료

## 부정 함정

### 단순 부정

- `出席しません`: 참석하지 않습니다.
- `間に合いません`: 시간에 맞지 않습니다.

### 부분 부정

- `必ずしも安いとは限りません`: 반드시 싸다고는 할 수 없습니다.
- `全員が賛成したわけではありません`: 전원이 찬성한 것은 아닙니다.

### 이중부정·완곡 긍정

- `できないわけではありません`: 못 하는 것은 아닙니다 → 가능하지만 조건이 있음.
- `検討しないこともありません`: 검토하지 않을 것도 아닙니다 → 적극적 찬성은 아님.

### 강한 불가

- `品質を下げるわけにはいきません`: 품질을 낮출 수는 없습니다.
- `納期はこれ以上延ばせません`: 납기를 더는 연장할 수 없습니다.

## 조건 표현

| 표현         | 의미              | 예시 해석           |
| ------------ | ----------------- | ------------------- |
| 〜場合に限り | ~한 경우에 한하여 | 특정 조건만 허용    |
| 〜ない限り   | ~하지 않는 한     | 조건 미충족 시 불가 |
| 〜さえすれば | ~하기만 하면      | 최소 조건           |
| 〜に応じて   | ~에 따라          | 수량·상황에 비례    |
| 〜次第       | ~하는 대로        | 완료 직후 행동      |
| 〜に伴って   | ~에 따라          | 변화에 수반         |

## 숫자 메모법

숫자를 그대로 적지 말고 기능을 붙인다.

```text
금 3시(초기) → 금 5시(불가) → 월 10시(확정)
100개(재고) / 80개(주문) / 20개(잔여)
```

## 미니 문제 8개

1. `遅くとも木曜日までに提出してください。`  
   → 최종 제출 기한: 목요일.
2. `三時までは会議中です。`  
   → 3시까지 회의가 계속됨.
3. `三時までに会議室へ来てください。`  
   → 3시 이전 도착 완료.
4. `参加者は二十名以上です。`  
   → 20명 포함, 그 이상.
5. `参加者は二十名未満です。`  
   → 20명 제외, 19명 이하.
6. `全員が反対したわけではありません。`  
   → 일부는 반대하지 않았다.
7. `予算が承認されない限り、発注できません。`  
   → 예산 승인 전에는 발주 불가.
8. `確認が取れ次第、ご連絡します。`  
   → 확인이 끝난 직후 연락.

## 시험 직전 암기

`이상·이하=포함`, `미만·초과=제외`, `までに=완료 마감`, `検討=미정`, `ことになった=결정`을 한 묶음으로 외운다.
