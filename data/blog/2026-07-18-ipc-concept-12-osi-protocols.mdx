## 시험 직전 빈출도

> **우선순위 S · ★★★★★**
>
> 프로토콜 3요소, TCP/UDP, 계층별 프로토콜은 2020년부터 꾸준히 형태를 바꿔 출제됐다.

- **최소 암기:** 구문·의미·타이밍, OSI 7계층, TCP/UDP, ARP·ICMP·DNS·DHCP
- **5점 후보:** 프로토콜 3요소=구문·의미·타이밍 / TCP=연결·신뢰 / UDP=비연결·저지연
- **판정 기준:** 별점은 Q-Net의 공식 출제 확률이 아니다. 2020년 1회~2026년 1회 복원 목록과 2026 시나공 핵심요약의 실기 출제 이력 표기를 개념군 단위로 교차해 정한 **시험 전날 상대 우선순위**다.

네트워크 문제는 프로토콜이 어느 계층에서 어떤 역할을 하는지 연결하는 것이 핵심이다. 포트 번호만 외우기보다 **주소·오류·전송·응용 기능**을 먼저 구분한다.

## 1. 프로토콜 3요소

| 요소            | 의미                            |
| --------------- | ------------------------------- |
| 구문(Syntax)    | 데이터 형식, 부호화, 신호 수준  |
| 의미(Semantics) | 제어 정보, 오류 처리, 동기 제어 |
| 타이밍(Timing)  | 전송 속도와 순서 제어           |

```text
프로토콜 3요소 = 구문·의미·타이밍
```

## 2. OSI 7계층

| 계층         | 역할                               | 주요 예                |
| ------------ | ---------------------------------- | ---------------------- |
| 7 응용       | 사용자 서비스 제공                 | HTTP, FTP, SMTP, DNS   |
| 6 표현       | 변환, 암호화, 압축                 | 인코딩, JPEG           |
| 5 세션       | 연결 설정·유지·종료, 동기화        | 체크포인트             |
| 4 전송       | 종단 간 전송, 포트, 흐름·오류 제어 | TCP, UDP               |
| 3 네트워크   | 경로 선택, 논리 주소               | IP, ICMP, 라우터       |
| 2 데이터링크 | 프레임, 물리 주소, 오류 검출       | Ethernet, HDLC, 스위치 |
| 1 물리       | 비트와 전기·기계적 신호            | 허브, 리피터           |

암기:

```text
응표세전네데물
```

## 3. 계층별 전송 단위

| 계층           | PDU                            |
| -------------- | ------------------------------ |
| 응용·표현·세션 | 데이터                         |
| 전송           | 세그먼트(TCP), 데이터그램(UDP) |
| 네트워크       | 패킷                           |
| 데이터링크     | 프레임                         |
| 물리           | 비트                           |

## 4. 계층별 장비

| 장비       | 계층·역할                        |
| ---------- | -------------------------------- |
| 리피터     | 물리 계층, 신호 재생             |
| 허브       | 물리 계층, 모든 포트로 전달      |
| 브리지     | 데이터링크 계층, LAN 연결        |
| 스위치     | 데이터링크 계층, MAC 기반 전달   |
| 라우터     | 네트워크 계층, IP 기반 경로 선택 |
| 게이트웨이 | 서로 다른 프로토콜 체계 변환     |

## 5. TCP와 UDP

| 구분   | TCP                        | UDP                        |
| ------ | -------------------------- | -------------------------- |
| 연결   | 연결형                     | 비연결형                   |
| 신뢰성 | 순서·재전송·오류 제어 제공 | 보장하지 않음              |
| 속도   | 상대적으로 느림            | 빠름                       |
| 단위   | 세그먼트                   | 데이터그램                 |
| 예     | HTTP, FTP, SMTP, SSH       | DNS, 스트리밍, 실시간 통신 |

## 6. TCP 연결 관리

### 3-Way Handshake

```text
SYN → SYN+ACK → ACK
```

### 4-Way Handshake

```text
FIN → ACK → FIN → ACK
```

## 7. IP와 보조 프로토콜

| 프로토콜 | 역할                           |
| -------- | ------------------------------ |
| IP       | 비연결형 패킷 전달과 논리 주소 |
| ICMP     | IP 오류와 상태 정보 통보       |
| ARP      | IPv4 주소로 MAC 주소 확인      |
| RARP     | MAC 주소로 IP 주소 확인        |
| IGMP     | 멀티캐스트 그룹 관리           |

```text
IP→MAC = ARP
MAC→IP = RARP
오류 통보 = ICMP
멀티캐스트 그룹 = IGMP
```

## 8. 응용 프로토콜

| 프로토콜 | 역할                  | 대표 포트 |
| -------- | --------------------- | --------- |
| HTTP     | 웹 문서 전송          | 80        |
| HTTPS    | TLS 기반 웹 통신      | 443       |

| SMTP     | 메일 전송             | 25        |
| DNS      | 도메인 이름과 IP 변환 | 53        |
| DHCP     | IP 설정 자동 할당     | 67·68     |
| POP3     | 메일 다운로드         | 110       |
| IMAP     | 서버에서 메일 동기화  | 143       |

## 9. DNS와 DHCP

### DNS

도메인 이름을 IP 주소로 변환하는 분산 계층형 이름 시스템이다.

### DHCP

클라이언트에 IP 주소, 서브넷 마스크, 게이트웨이, DNS 정보를 자동 할당한다.

```text
Discover → Offer → Request → Acknowledge
```

## 10. HDLC

비트 중심의 데이터링크 제어 프로토콜이다.

| 프레임  | 역할                     |
| ------- | ------------------------ |
| I-Frame | 사용자 정보 전송         |
| S-Frame | 흐름·오류 제어           |
| U-Frame | 링크 설정·해제·모드 설정 |

## 11. 오류 제어

| 방식      | 의미                               |
| --------- | ---------------------------------- |
| FEC       | 수신 측이 재전송 없이 오류 정정    |
| BEC·ARQ   | 오류 발생 시 송신 측에 재전송 요구 |
| 패리티    | 검사 비트를 추가하여 오류 검출     |
| CRC       | 생성 다항식의 나눗셈으로 오류 검출 |
| 해밍 코드 | 오류 검출과 단일 비트 정정         |

## 12. 시험 직전 암기

```text
OSI = 응표세전네데물
전송 계층 = TCP·UDP·포트
네트워크 계층 = IP·ICMP·라우터
데이터링크 = 프레임·MAC·스위치
물리 = 비트·허브·리피터
ARP = IP→MAC
ICMP = 오류 통보
DNS = 이름→IP
DHCP = IP 자동 할당
SSH = 22
HTTPS = 443
```
