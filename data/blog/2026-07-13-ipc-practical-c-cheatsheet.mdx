C 문제는 코드를 눈으로만 따라가면 포인터와 증감 연산에서 틀리기 쉽다. **주소, 저장된 값, 현재 인덱스**를 표로 분리해 추적한다.

## 1. 포인터 기본식

```c
int value = 10;
int *pointer = &value;
```

| 표현       | 의미                    | 값        |
| ---------- | ----------------------- | --------- |
| `value`    | 변수 값                 | 10        |
| `&value`   | value의 주소            | 주소      |
| `pointer`  | pointer가 저장한 주소   | `&value`  |
| `*pointer` | 해당 주소의 값          | 10        |
| `&pointer` | 포인터 변수 자체의 주소 | 별도 주소 |

```c
*pointer = 20; // value도 20으로 변경
```

## 2. 배열과 포인터

```c
int array[] = {10, 20, 30};
int *p = array;
```

```text
array[i] == *(array + i)
&array[i] == array + i
p[i] == *(p + i)
```

포인터 덧셈은 바이트가 아니라 가리키는 자료형 크기 단위로 이동한다. `int *p`에서 `p + 1`은 다음 int 원소를 가리킨다.

## 3. 증감 연산자 함정

| 표현     | 의미                                      |
| -------- | ----------------------------------------- |
| `*p++`   | `*(p++)`: 현재 값을 사용한 후 포인터 이동 |
| `(*p)++` | 현재 원소의 값을 1 증가                   |
| `*++p`   | 포인터를 먼저 이동한 후 그 값 참조        |
| `++*p`   | 현재 원소의 값을 먼저 1 증가              |

```c
int a[] = {10, 20, 30};
int *p = a;
printf("%d ", *p++); // 10, 이후 p는 a[1]
printf("%d", *p);    // 20
```

## 4. 이중 포인터

```c
int value = 10;
int *p = &value;
int **pp = &p;

printf("%d", **pp); // 10
```

```text
pp → p의 주소
*pp → p에 저장된 주소, 즉 &value
**pp → value
```

## 5. 함수 인자와 주소 전달

C의 인자는 항상 값으로 전달된다. 포인터 값을 넘기면 그 주소를 통해 원본을 변경할 수 있다.

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 1, y = 2;
swap(&x, &y);
```

포인터 자체가 다른 주소를 가리키게 하려면 이중 포인터가 필요하다.

## 6. 문자열과 문자 배열

```c
char text[] = "ABC";
```

메모리에는 `A`, `B`, `C`, `\0` 총 4바이트가 저장된다.

| 함수           | 역할                       |
| -------------- | -------------------------- |
| `strlen(s)`    | 널 문자 전까지 문자열 길이 |
| `strcpy(a, b)` | b를 a에 복사               |
| `strcat(a, b)` | a 뒤에 b 연결              |
| `strcmp(a, b)` | 사전식 비교, 같으면 0      |

```text
sizeof("ABC") = 4
strlen("ABC") = 3
```

문자열 비교에 `==`를 사용하면 내용이 아니라 주소를 비교한다. 내용 비교는 `strcmp(a, b) == 0`을 사용한다.

## 7. 2차원 배열

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

C의 2차원 배열은 행 우선으로 연속 저장된다.

```text
matrix[1][2] == *(*(matrix + 1) + 2) == 6
```

## 8. 구조체

```c
struct Student {
    int id;
    char grade;
};

struct Student student = {1, 'A'};
struct Student *p = &student;

printf("%d %c", student.id, p->grade);
```

```text
일반 구조체 변수 접근: student.id
구조체 포인터 접근: p->id, 또는 (*p).id
```

## 9. 비트 연산

| 연산자 | 의미        |
| ------ | ----------- |
| `&`    | 비트 AND    |
| `\|`   | 비트 OR     |
| `^`    | 비트 XOR    |
| `~`    | 비트 NOT    |
| `<<`   | 왼쪽 이동   |
| `>>`   | 오른쪽 이동 |

```text
5 = 0101, 3 = 0011
5 & 3 = 0001 = 1
5 | 3 = 0111 = 7
5 ^ 3 = 0110 = 6
5 << 1 = 10
```

논리 연산자 `&&`, `||`와 비트 연산자 `&`, `|`를 구분한다. `&&`, `||`에는 단락 평가가 적용된다.

## 10. switch와 반복문

```c
int value = 2;
switch (value) {
    case 1: printf("A");
    case 2: printf("B");
    case 3: printf("C"); break;
    default: printf("D");
}
```

결과는 `BC`다. case 2부터 시작하고 break 전까지 fall-through가 발생한다.

```text
break: 가장 가까운 반복문 또는 switch 종료
continue: 현재 반복의 나머지를 건너뛰고 다음 반복
```

## 11. 재귀 함수

```c
int function(int n) {
    if (n <= 1) return 1;
    return n + function(n - 2);
}
```

`function(5)`는 다음처럼 푼다.

```text
f(5) = 5 + f(3)
     = 5 + 3 + f(1)
     = 5 + 3 + 1
     = 9
```

종료 조건을 먼저 표시하고 호출 단계와 반환 단계를 분리한다.

## 12. 연산자 우선순위 요약

```text
() [] -> .
→ 단항 ! ~ ++ -- * & sizeof
→ * / %
→ + -
→ << >>
→ < <= > >=
→ == !=
→ 비트 & → ^ → |
→ 논리 && → ||
→ 삼항 ?:
→ 대입
```

애매하면 문제 코드에 괄호를 직접 그려 의미를 고정한다.

## 13. 시험 직전 점검

```text
array[i] == *(array+i)
*p++는 포인터 이동, (*p)++는 값 증가
문자열 끝에는 \0
sizeof("ABC")=4, strlen("ABC")=3
문자열 내용 비교는 strcmp
구조체 포인터는 ->
&&/||와 &/| 구분
switch는 break가 없으면 아래 case까지 실행
정수 나눗셈은 소수점 버림
재귀는 종료 조건부터 확인
```

포인터 문제는 `변수 | 주소 | 현재 값 | 포인터가 가리키는 곳` 네 칸을 그려 한 문장씩 갱신하면 된다.
