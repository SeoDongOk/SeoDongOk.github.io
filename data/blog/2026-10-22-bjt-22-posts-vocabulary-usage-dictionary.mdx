> 기존 BJT 학습 글 22편에 나온 핵심 표현을 중복 제거해 **읽기 → 한글 발음 → 뜻 → 실제 활용** 순서로 다시 묶었다. 실제 기출문장을 복제한 자료가 아니라, 공식 BJT가 다루는 비즈니스 상황을 바탕으로 작성한 학습용 정리다.

## 이 페이지 사용법

1. `일본어`만 보고 2초 안에 뜻을 말한다.
2. `읽기`를 확인한 뒤 한글 발음에만 의존하지 말고 일본어로 소리 내어 읽는다.
3. `핵심 활용`을 통째로 말한다. BJT에서는 단어 하나보다 **결정 상태·행동 주체·다음 행동**이 중요하다.
4. A는 반드시 즉시 반응, B는 문맥 속 판별, C는 고득점 보강 순서로 복습한다.

## 1. 일정·결정·진행

### 상태를 구분하는 문장

- `検討します`（けんとうします）: 검토하겠습니다 → **아직 미정**
- `実施する予定です`（じっしする よていです）: 실시할 예정입니다 → 계획 단계
- `実施することになりました`（じっしする ことに なりました）: 실시하기로 했습니다 → **결정 완료**
- `実施しております`（じっしして おります）: 실시하고 있습니다 → 진행 중

## 10. 활용형을 들으면 이렇게 판별한다

| 형태           | 예                         | 판단                                                 |
| -------------- | -------------------------- | ---------------------------------------------------- |
| 정중 현재·미래 | `確認します`               | 확인합니다/확인하겠습니다. 문맥으로 현재와 미래 판별 |
| 진행·상태      | `確認しています`           | 확인 중입니다 또는 확인해 둔 상태입니다              |
| 완료           | `確認しました`             | 확인을 끝냈습니다                                    |
| 요청           | `確認してください`         | 상대에게 확인하라는 지시·요청                        |
| 완곡 요청      | `確認していただけますか`   | 상대에게 정중히 확인을 부탁                          |
| 가능           | `確認できます`             | 확인할 수 있습니다                                   |
| 가능 부정      | `確認できません`           | 확인할 수 없습니다                                   |
| 수동           | `確認されました`           | 누군가에 의해 확인되었습니다                         |
| 사역           | `確認させます`             | 누군가에게 확인하게 합니다                           |
| 사역수동       | `確認させられました`       | 원치 않아도 확인하게 되었습니다                      |
| 조건           | `確認すれば`               | 확인하면                                             |
| 완료 직후      | `確認し次第`               | 확인하는 대로                                        |
| 결정           | `確認することになりました` | 확인하기로 결정되었습니다                            |
| 의무           | `確認しなければなりません` | 확인해야 합니다                                      |
| 불필요         | `確認する必要はありません` | 확인할 필요가 없습니다                               |

### 사역수동의 감정

- `待たされる`（またされる / 마타사레루）: 기다리게 되다
- `働かされる`（はたらかされる / 하타라카사레루）: 억지로 일하게 되다
- `話させられる`（はなさせられる / 하나사세라레루）: 어쩔 수 없이 말하게 되다

사역수동은 대체로 **본인의 의사와 무관하게 행동하게 된 불만·피해**를 포함한다. 누가 지시했고 누가 실제로 행동했는지 분리해서 듣는다.

## 11. 시험 직전 회상 묶음

1. `延期 ↔ 前倒し` — 연기 ↔ 앞당김
2. `検討 → 決定 → 実施` — 검토 → 결정 → 실시
3. `申請 → 承認 / 差し戻し` — 신청 → 승인 / 반려
4. `作成 → 確認 → 修正 → 提出` — 작성 → 확인 → 수정 → 제출
5. `見積もり → 発注 → 受注 → 納品` — 견적 → 발주 → 수주 → 납품
6. `発生 → 調査 → 復旧 → 報告 → 再発防止` — 발생 → 조사 → 복구 → 보고 → 재발 방지
7. `不良品 → 交換 / 返品 / 返金` — 불량품 → 교환 / 반품 / 환불
8. `まで ↔ までに` — 계속되는 종료 시점 ↔ 완료 마감
9. `以上・以下・未満` — 이상·이하·미만
10. `しかし・ただし・一方で・そのため` — 역접·예외·대조·인과

## 12. 20분 복습 루틴

- **5분:** A 표시 표현만 보고 뜻과 읽기를 즉답한다.
- **5분:** 흐름 묶음 10개를 순서대로 소리 내어 말한다.
- **5분:** 활용형 표에서 긍정·부정·수동·결정 상태를 바꿔 말한다.
- **5분:** 임의의 표현 5개로 `누가 → 무엇을 → 언제까지 → 어떤 상태로` 문장을 만든다.

한글 발음은 첫 진입을 돕기 위한 보조 표기다. 장음과 촉음까지 완전히 나타내지는 못하므로, 최종 암기는 반드시 **히라가나 읽기와 일본어 음성**을 기준으로 한다.
