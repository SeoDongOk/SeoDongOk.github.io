## 시험 직전 빈출도

> **우선순위 A · ★★★★☆**
>
> UML 다이어그램 종류와 관계 기호는 최근 회차까지 보기 선택·단답형으로 반복됐다.

- **최소 암기:** 구조/행위 다이어그램 분류, 연관·의존·일반화·실체화·집약·합성
- **5점 후보:** “시간 순서 메시지”=시퀀스, “객체 상태 변화”=상태, “부분이 전체 생명주기에 종속”=합성
- **판정 기준:** 별점은 Q-Net의 공식 출제 확률이 아니다. 2020년 1회~2026년 1회 복원 목록과 2026 시나공 핵심요약의 실기 출제 이력 표기를 개념군 단위로 교차해 정한 **시험 전날 상대 우선순위**다.

UML 문제는 다이어그램의 목적 또는 관계 표기법을 보고 이름을 쓰는 형태가 많다. **구조 다이어그램과 행위 다이어그램**, 그리고 **빈 삼각형과 마름모**를 먼저 구분한다.

## 1. UML의 구성 요소

| 요소                 | 의미                          |
| -------------------- | ----------------------------- |
| 사물(Things)         | 모델을 구성하는 기본 요소     |
| 관계(Relationships)  | 사물 사이의 연결              |
| 다이어그램(Diagrams) | 사물과 관계를 시각적으로 표현 |

## 2. 구조 다이어그램

시스템의 정적인 구조를 표현한다.

| 다이어그램  | 식별 키워드                         |
| ----------- | ----------------------------------- |
| 클래스      | 클래스, 속성, 연산, 클래스 간 관계  |
| 객체        | 특정 시점의 객체 인스턴스           |
| 컴포넌트    | 구현 단위와 컴포넌트 의존 관계      |
| 배치        | 하드웨어 노드와 소프트웨어 배치     |
| 패키지      | 폴더 형태의 그룹과 패키지 의존 관계 |
| 복합체 구조 | 클래스 내부 구조와 협력 요소        |

```text
클래스 설계 → 클래스 다이어그램
실행 시점 객체 상태 → 객체 다이어그램
모듈·라이브러리 → 컴포넌트 다이어그램
서버·장비 배치 → 배치 다이어그램
폴더·그룹화 → 패키지 다이어그램
```

## 3. 행위 다이어그램

시스템의 동작과 상호작용을 표현한다.

| 다이어그램    | 식별 키워드                           |
| ------------- | ------------------------------------- |
| 유스케이스    | 사용자 관점의 기능과 액터             |
| 시퀀스        | 시간 순서에 따른 메시지 교환          |
| 커뮤니케이션  | 객체 관계와 메시지 중심 상호작용      |
| 상태          | 이벤트에 따른 객체 상태 변화          |
| 활동          | 업무 흐름과 제어 흐름                 |
| 타이밍        | 시간 제약과 상태 변화                 |
| 상호작용 개요 | 여러 상호작용 흐름을 활동 형태로 표현 |

```text
액터와 기능 → 유스케이스
세로 생명선과 메시지 순서 → 시퀀스
상태와 이벤트 → 상태
업무 절차와 분기 → 활동
```

## 4. UML 관계

| 관계   | 표기           | 의미                                  |
| ------ | -------------- | ------------------------------------- |
| 연관   | 실선           | 객체가 지속적으로 관련됨              |
| 의존   | 점선 화살표    | 한 요소가 다른 요소를 일시적으로 사용 |
| 일반화 | 빈 삼각형 실선 | 상속, 일반-특수 관계                  |
| 실체화 | 빈 삼각형 점선 | 인터페이스 구현                       |
| 집약   | 빈 마름모      | 약한 전체-부분 관계                   |
| 합성   | 채운 마름모    | 강한 전체-부분, 생명주기 공유         |

### 집약과 합성

```text
집약: 전체가 없어져도 부분은 독립적으로 존재 가능
합성: 전체가 없어지면 부분도 함께 소멸
```

예시:

```text
팀과 선수 → 집약으로 볼 수 있음
주문과 주문항목 → 합성으로 볼 수 있음
```

## 5. 유스케이스 관계

| 관계          | 의미                                      |
| ------------- | ----------------------------------------- |
| 포함(Include) | 여러 유스케이스가 공통 기능을 반드시 사용 |
| 확장(Extend)  | 특정 조건에서 선택적으로 기능 추가        |
| 일반화        | 상위 액터·유스케이스의 특성을 하위가 상속 |

```text
항상 실행되는 공통 기능 → include
특정 조건에서 선택 실행 → extend
```

## 6. 클래스 다이어그램

클래스는 일반적으로 세 영역으로 표현한다.

```text
클래스 이름
속성
연산·메서드
```

### 접근 제어자 표기

| 기호 | 접근 범위       |
| ---- | --------------- |
| `+`  | public          |
| `-`  | private         |
| `#`  | protected       |
| `~`  | package·default |

### 다중성

| 표기        | 의미              |
| ----------- | ----------------- |
| `1`         | 정확히 하나       |
| `0..1`      | 없거나 하나       |
| `*`, `0..*` | 0개 이상          |
| `1..*`      | 1개 이상          |
| `n..m`      | n개 이상 m개 이하 |

## 7. 시퀀스 다이어그램

| 요소      | 의미                        |
| --------- | --------------------------- |
| 액터      | 시스템 외부 사용자·시스템   |
| 객체      | 상호작용에 참여하는 대상    |
| 생명선    | 객체가 존재하는 시간        |
| 실행 상자 | 객체가 동작을 수행하는 기간 |
| 메시지    | 객체 사이의 호출과 응답     |

위에서 아래로 시간이 흐른다. 객체 사이의 메시지 순서를 묻는 문제에서 가장 먼저 확인할 규칙이다.

## 8. 활동 다이어그램

| 요소      | 의미                             |
| --------- | -------------------------------- |
| 시작점    | 활동 시작                        |
| 종료점    | 활동 종료                        |
| 액션      | 수행 작업                        |
| 결정 노드 | 조건에 따른 분기                 |
| 병합 노드 | 여러 분기 흐름 통합              |
| 포크      | 하나의 흐름을 병렬 흐름으로 분리 |
| 조인      | 병렬 흐름을 하나로 동기화        |
| 스윔레인  | 담당 조직·역할별 활동 구분       |

## 9. 상태 다이어그램

객체가 이벤트에 반응하여 한 상태에서 다른 상태로 전이되는 과정을 표현한다.

```text
상태 + 이벤트 + 전이 + 조건 + 동작
```

객체의 생명주기나 주문·결제 상태처럼 상태 변화가 중요한 문제에 사용한다.

## 10. 시험 직전 암기

```text
정적 구조 = 구조 다이어그램
동작·상호작용 = 행위 다이어그램
액터 = 유스케이스
시간 순 메시지 = 시퀀스
업무 흐름 = 활동
상태 변화 = 상태
빈 삼각형 실선 = 일반화
빈 삼각형 점선 = 실체화
빈 마름모 = 집약
채운 마름모 = 합성
항상 공통 사용 = include
조건부 추가 = extend
```
