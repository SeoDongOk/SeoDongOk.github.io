## 시험 직전 빈출도

> **우선순위 A · ★★★★☆**
>
> 정규화 단계 자체와 함수 종속·이상 현상은 회차를 바꾸어 반복되는 DB 이론 단골이다.

- **최소 암기:** 1NF 원자값, 2NF 부분 종속 제거, 3NF 이행 종속 제거, BCNF 모든 결정자가 후보키
- **5점 후보:** 도부이결다조: 도메인 원자화→부분→이행→결정자→다치→조인 종속 제거
- **판정 기준:** 별점은 Q-Net의 공식 출제 확률이 아니다. 2020년 1회~2026년 1회 복원 목록과 2026 시나공 핵심요약의 실기 출제 이력 표기를 개념군 단위로 교차해 정한 **시험 전날 상대 우선순위**다.

정규화 문제는 각 정규형의 이름보다 **무엇을 제거하는 단계인지**가 중요하다. 2NF의 부분 함수 종속과 3NF의 이행 함수 종속을 반드시 구분한다.

## 1. 정규화 목적

```text
데이터 중복 최소화
이상 현상 방지
데이터 일관성과 무결성 향상
변경 시 영향 범위 축소
```

## 2. 이상 현상

| 이상      | 의미                                         |
| --------- | -------------------------------------------- |
| 삽입 이상 | 불필요한 정보까지 넣어야 새 정보를 삽입 가능 |
| 갱신 이상 | 중복된 데이터 일부만 변경되어 불일치 발생    |
| 삭제 이상 | 한 정보를 삭제하면서 필요한 정보까지 삭제    |

## 3. 함수 종속

`X → Y`는 X의 값이 정해지면 Y의 값이 하나로 정해진다는 뜻이다.

```text
X = 결정자
Y = 종속자
```

| 종속           | 의미                                   |
| -------------- | -------------------------------------- |
| 완전 함수 종속 | 기본키 전체에 종속                     |
| 부분 함수 종속 | 복합키의 일부에 종속                   |
| 이행 함수 종속 | X→Y이고 Y→Z이므로 X→Z                  |
| 다치 종속      | 하나의 X에 여러 Y 값이 독립적으로 대응 |

## 4. 제1정규형

모든 속성값이 더 나눌 수 없는 원자값이어야 한다.

```text
학생(학번, 전화번호들)
전화번호들 = 010-1111, 010-2222
```

한 셀에 여러 전화번호를 저장하면 1NF를 위반한다. 전화번호를 별도 행이나 릴레이션으로 분리한다.

## 5. 제2정규형

1NF를 만족하고, 기본키가 아닌 모든 속성이 기본키 전체에 완전 함수 종속이어야 한다.

### 예제

```text
수강(학번, 과목코드, 학생이름, 과목명, 성적)
기본키: (학번, 과목코드)

(학번, 과목코드) → 성적
학번 → 학생이름
과목코드 → 과목명
```

학생이름과 과목명은 복합키 일부에 종속되므로 부분 함수 종속이다.

```text
학생(학번, 학생이름)
과목(과목코드, 과목명)
수강(학번, 과목코드, 성적)
```

## 6. 제3정규형

2NF를 만족하고 기본키가 아닌 속성 사이의 이행 함수 종속을 제거한다.

### 예제

```text
학생(학번, 학과코드, 학과명)

학번 → 학과코드
학과코드 → 학과명
```

학번이 학과코드를 거쳐 학과명을 결정하므로 이행 함수 종속이다.

```text
학생(학번, 학과코드)
학과(학과코드, 학과명)
```

## 7. BCNF

모든 결정자가 후보키가 되도록 분해한다. 3NF보다 강한 조건이다.

```text
결정자인데 후보키가 아님 → BCNF 위반 가능성
```

## 8. 고차 정규형

| 정규형 | 제거 대상 |
| ------ | --------- |
| 4NF    | 다치 종속 |
| 5NF    | 조인 종속 |

## 9. 정규화 단계 암기

```text
1NF = 원자값
2NF = 부분 함수 종속 제거
3NF = 이행 함수 종속 제거
BCNF = 모든 결정자가 후보키
4NF = 다치 종속 제거
5NF = 조인 종속 제거
```

두음:

```text
도부이결다조
도메인 원자화-부분-이행-결정자-다치-조인
```

## 10. 무손실 분해와 종속성 보존

| 조건        | 의미                                               |
| ----------- | -------------------------------------------------- |
| 무손실 분해 | 분해한 릴레이션을 조인하면 원래 릴레이션 복원 가능 |
| 종속성 보존 | 분해 후에도 기존 함수 종속을 유지·검사 가능        |

좋은 분해는 정보 손실 없이 종속성을 가능한 한 보존해야 한다.

## 11. 반정규화

조회 성능을 높이기 위해 정규화된 구조에 데이터 중복과 통합을 의도적으로 허용한다.

| 장점           | 단점               |
| -------------- | ------------------ |
| 조인 감소      | 데이터 중복 증가   |
| 조회 성능 향상 | 저장 공간 증가     |
| 쿼리 단순화    | 변경 비용 증가     |
|                | 무결성 관리 어려움 |

```text
정규화 = 무결성·일관성
반정규화 = 조회 성능
```

## 12. 시험 직전 암기

```text
복합키 일부에 종속 = 부분 함수 종속 = 2NF
일반 속성이 다른 일반 속성을 결정 = 이행 함수 종속 = 3NF
모든 결정자가 후보키 = BCNF
한 셀에 여러 값 = 1NF 위반
중복 일부만 변경 = 갱신 이상
삭제하며 다른 정보도 소실 = 삭제 이상
성능을 위한 중복 = 반정규화
```
