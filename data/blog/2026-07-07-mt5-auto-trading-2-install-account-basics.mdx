> 이 글은 학습용 정리이며 투자 권유가 아니다. 처음부터 실계좌로 자동매매를 돌리지 말고 반드시 데모 계정으로 기능과 주문 흐름을 먼저 확인해야 한다.

MT5 자동매매를 배우려면 가장 먼저 해야 할 일은 **거래 환경을 안전하게 만들어두는 것**이다. 초보자는 실계좌보다 데모 계정으로 시작하는 것이 좋다. 자동매매 코드는 실수 한 줄로도 주문을 반복해서 낼 수 있기 때문이다.

## 1. MT5 설치

MT5는 보통 두 가지 방식으로 설치한다.

1. MetaTrader 공식 사이트에서 설치
2. 사용할 브로커 사이트에서 해당 브로커용 MT5 설치

실전 거래는 결국 브로커 서버에 접속해야 하므로, 실제 사용할 브로커가 정해져 있다면 브로커가 제공하는 MT5를 설치하는 것이 편하다.

설치 후 실행하면 기본적으로 아래 요소들이 보인다.

| 영역         | 설명                             |
| ------------ | -------------------------------- |
| Market Watch | 종목 목록과 Bid/Ask 가격         |
| Navigator    | 계좌, 지표, Expert Advisors 목록 |
| Chart        | 선택한 종목의 차트               |
| Toolbox      | 주문, 포지션, 거래내역, 로그     |

## 2. 데모 계정 만들기

자동매매 학습은 데모 계정부터 시작한다. 데모 계정은 가상자금으로 실제와 유사한 환경에서 주문을 테스트할 수 있는 계정이다.

체크할 항목:

- 서버 이름이 맞는가?
- 로그인 ID와 비밀번호가 맞는가?
- 계좌 통화가 무엇인가?
- 레버리지는 얼마인가?
- 거래 가능한 종목이 무엇인가?

데모 계정에 연결되면 우측 하단 또는 Toolbox의 계좌 정보에서 잔고와 서버 상태를 확인할 수 있다.

## 3. 종목 열기

`Market Watch`에서 거래할 종목을 찾는다. 예를 들어 EURUSD를 보고 싶다면 종목 목록에서 EURUSD를 선택하고 차트로 열면 된다.

브로커마다 종목 이름이 다를 수 있다.

예시:

```text
EURUSD
EURUSD.a
EURUSDm
XAUUSD
XAUUSD.pro
US100
NAS100
```

Python이나 EA를 만들 때는 이 종목 이름을 정확히 써야 한다. `EURUSD`라고 생각했는데 실제 브로커 종목명이 `EURUSDm`이면 주문이 실패할 수 있다.

## 4. 차트 기본 조작

자동매매를 하더라도 차트는 계속 봐야 한다. 최소한 아래 조작은 익숙해져야 한다.

- 시간봉 변경: M1, M5, M15, H1, D1 등
- 캔들/라인/바 차트 전환
- 지표 추가: 이동평균, RSI, ATR 등
- 확대/축소
- 자동 스크롤 켜기/끄기
- 차트 템플릿 저장

전략을 코딩하기 전에 차트에서 눈으로 조건을 확인해보는 습관이 중요하다.

## 5. 주문 창 익히기

자동매매 전에 수동 주문을 반드시 넣어봐야 한다. 데모 계정에서 아래를 연습한다.

- 시장가 매수
- 시장가 매도
- 손절가 설정
- 익절가 설정
- 지정가 주문
- 예약 주문 취소
- 포지션 일부 또는 전체 청산

자동매매 코드는 결국 이 과정을 프로그램으로 반복하는 것이다. 수동 주문을 이해하지 못하면 자동 주문 오류를 해석하기 어렵다.

## 6. AutoTrading 버튼

MT5 상단에는 자동매매를 켜고 끄는 버튼이 있다. 보통 `Algo Trading` 또는 `AutoTrading`으로 표시된다.

중요한 점:

- 버튼이 꺼져 있으면 EA가 주문을 보낼 수 없다.
- EA 자체는 차트에서 동작할 수 있지만 주문 전송이 막힐 수 있다.
- 실수로 켜둔 상태에서 EA를 붙이면 바로 주문이 나갈 수 있다.

초보자는 EA를 테스트할 때 아래 순서가 안전하다.

```text
1. AutoTrading 끄기
2. EA를 차트에 붙이기
3. 입력값 확인
4. 데모 계정인지 확인
5. AutoTrading 켜기
6. Toolbox의 Journal/Experts 로그 확인
```

## 7. 로그 확인 위치

자동매매 문제 해결은 로그에서 시작한다.

| 로그    | 보는 이유                     |
| ------- | ----------------------------- |
| Experts | EA가 출력한 메시지, 에러 확인 |
| Journal | 터미널 전체 이벤트 확인       |
| Trade   | 현재 포지션과 주문 확인       |
| History | 과거 체결 내역 확인           |

주문이 안 나갔을 때 “코드가 틀렸다”고 바로 판단하면 안 된다. 자동매매 비활성화, 종목명 오류, 최소 lot 미만, 증거금 부족, 거래 시간 아님, 브로커 제한 등 다양한 이유가 있을 수 있다.

## 8. 첫날 목표

MT5 첫날 목표는 수익 전략을 만드는 것이 아니다. 아래만 성공하면 충분하다.

- 데모 계정 연결
- 관심 종목 차트 열기
- 수동 시장가 주문 1회
- 손절/익절 설정
- 포지션 청산
- Journal과 Experts 로그 위치 확인

이 단계를 건너뛰고 바로 자동매매 코드를 돌리면, 나중에 문제가 생겼을 때 어디서부터 봐야 할지 모르게 된다.

## 정리

MT5 설치 후 가장 먼저 해야 할 일은 안전한 데모 환경을 만드는 것이다. 자동매매는 주문을 자동으로 내는 시스템이므로, 수동 주문과 로그 확인을 먼저 익히는 것이 필수다.

다음 글에서는 주문 타입, lot, 스프레드, 손절, 익절, 리스크 관리처럼 자동매매에서 반드시 알아야 하는 거래 기본기를 정리한다.
