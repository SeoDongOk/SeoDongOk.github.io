BJT 청해의 매력적인 오답은 대화에 **실제로 등장한 내용**이다. 전혀 엉뚱한 말을 넣는 것이 아니라, 처음 검토했다가 버린 안이나 원인과 결과를 바꾼 문장을 선택지에 넣는다.

그래서 단어를 많이 들었다고 정답을 맞히는 것은 아니다. 대화가 끝났을 때 **무엇이 남았는지**를 들어야 한다.

> 예문은 모두 학습용 창작 예문이다.

## 가장 흔한 네 가지 오답 구조

### 1. 처음 제안했지만 거절된 안

```text
A: 가격을 낮춰 보는 건 어떨까요?
B: 이미 경쟁사보다 저렴합니다. 오히려 홍보 방식을 바꿔 보죠.
```

`가격`이 먼저 들렸지만 최종 행동은 `홍보 변경`이다.

### 2. 원인과 대응을 바꾼 안

배송 지연이 원인이고 고객 안내가 대응이라면 “고객 안내 때문에 배송이 늦었다”는 선택지는 오답이다.

### 3. 검토와 결정을 혼동한 안

- `検討します` → 검토하겠다
- `その方向で進めます` → 그 방향으로 진행한다

둘은 같은 단계가 아니다.

### 4. 가능성과 확정을 혼동한 안

- `可能性があります` → 가능성이 있다
- `決まりました` → 결정됐다
- `予定です` → 예정이다

## 방향을 바꾸는 전환어

| 표현         | 읽기         | 듣기 기능                 |
| ------------ | ------------ | ------------------------- |
| ただ         | ただ         | 조건·제약 추가            |
| しかし       | しかし       | 앞 내용과 반대            |
| とはいえ     | とはいえ     | 인정 후 반전              |
| ところが     | ところが     | 예상 밖 결과              |
| もっとも     | もっとも     | 예외·보충 조건            |
| 一方で       | いっぽうで   | 다른 측면 제시            |
| むしろ       | むしろ       | 진짜 선택지를 뒤에서 제시 |
| 結局         | けっきょく   | 최종 결과 요약            |
| 要するに     | ようするに   | 핵심 재정리               |
| というわけで | というわけで | 결론·다음 행동            |

`ただ`, `しかし`, `むしろ`가 들리면 앞부분을 지우라는 뜻이 아니다. **앞 내용의 지위가 바뀌는지** 확인하라는 신호다.

## 완곡한 거절을 긍정으로 듣지 않는다

비즈니스 일본어는 `싫습니다`보다 간접적으로 거절한다.

| 표현                 | 표면 의미                        | 실제 기능               |
| -------------------- | -------------------------------- | ----------------------- |
| 難しいですね         | 어렵네요                         | 사실상 거절 가능성이 큼 |
| 今回は見送ります     | 이번에는 보냅니다                | 이번 안을 채택하지 않음 |
| ご期待に沿いかねます | 기대에 따르기 어렵습니다         | 요청을 수락할 수 없음   |
| 検討させてください   | 검토하게 해 주세요               | 즉시 동의가 아님        |
| 今の段階では何とも   | 현재 단계에서는 뭐라 하기 어렵다 | 판단 유보               |

## 질문의 시점을 먼저 표시한다

질문에 다음 표현이 나오면 메모 기호를 정한다.

- `このあと` → 다음 행동 `→`
- `最終的に` → 최종 결정 `◎`
- `なぜ` → 원인 `C`
- `何を心配しているか` → 걱정 대상 `!`
- `どうすることになったか` → 합의된 행동 `D`

이 한 글자만 적어도 대화 중 등장한 부수 정보에 덜 끌린다.

## 세 줄 메모법

회의 대화가 길어지면 아래 세 줄만 기록한다.

```text
문제: 신제품 판매 부진
제외: 가격, 유통
결정: 젊은 층 대상 홍보
```

공식 청해 샘플의 해설도 대화 속 후보를 하나씩 제외하고 마지막에 남는 결정이나 걱정거리를 찾는 방식을 강조한다. 모든 문장을 번역하기보다 **문제–제외–결정** 구조를 잡는 편이 빠르다.

## 미니 드릴

```text
A: 회의를 금요일로 옮길까요?
B: 금요일은 고객 방문이 있습니다.
A: 그렇다면 시간은 그대로 두고 온라인으로 진행하죠.
B: 네, 그렇게 하겠습니다.
```

- 처음 제안: 금요일로 변경
- 제약: 금요일 고객 방문
- 최종 결정: 기존 시간에 온라인 개최

정답 선택지에 `금요일`이 들어갔다고 고르면 안 된다.

## 시험 직전 체크리스트

- 처음 나온 명사는 정답이 아니라 후보일 수 있다.
- `検討`과 `決定`을 구분한다.
- `ただ・しかし・むしろ・結局` 뒤를 표시한다.
- “이후 무엇을 하는가”와 “왜 문제가 생겼는가”를 섞지 않는다.
- 선택지의 키워드 수가 아니라 대화 종료 시점의 합의를 고른다.
