시험 전날 암기 드릴을 돌리고 나서 **끝까지 안 외워진 것들만** 걸러낸 개인 오답노트다.
문맥규정(부사)과 유의표현(言い換え)은 아는 만큼 그대로 점수가 되는 구역이라, 이 목록만 시험 직전에 다시 훑는다.

## 부사 15개 (문맥규정 대비)

⚠️ 앞의 3개는 **뒤에 반드시 부정문**이 온다. 이 세트 여부부터 확인하는 게 문맥규정 풀이의 첫 단추.

| 단어                          | 발음       | 뜻                  | 예문                                                  |
| ----------------------------- | ---------- | ------------------- | ----------------------------------------------------- |
| ちっとも〜ない                | 칫토모     | 조금도 (~않다)      | ちっとも面白くない。조금도 재미없다                   |
| けっして〜ない                | 켓시테     | 결코 (~않다)        | けっして忘れません。결코 잊지 않겠습니다              |
| それほど〜ない                | 소레호도   | 그렇게까지 (~않다)  | それほど難しくない。그렇게까지 어렵진 않다            |
| とうとう                      | 토-토-     | 결국, 마침내        | とうとう最終日になった。결국 마지막 날이 됐다         |
| だいぶ                        | 다이부     | 상당히, 많이        | だいぶ良くなりました。많이 좋아졌어요                 |
| たいてい                      | 타이테-    | 대개, 보통          | 日曜日はたいてい家にいます。일요일엔 대개 집에 있어요 |
| たまに                        | 타마니     | 가끔                | たまに映画を見ます。가끔 영화를 봐요                  |
| きゅうに (急に)               | 큐-니      | 갑자기              | 急に雨が降ってきた。갑자기 비가 내리기 시작했다       |
| いっしょうけんめい (一生懸命) | 잇쇼-켄메- | 열심히              | 一生懸命勉強した。열심히 공부했다                     |
| ぜひ                          | 제히       | 꼭 (희망·권유 전용) | ぜひ遊びに来てください。꼭 놀러 오세요                |
| なるべく                      | 나루베쿠   | 가능한 한           | なるべく早く来てください。가능한 한 빨리 와 주세요    |
| ゆっくり                      | 육쿠리     | 천천히, 푹          | ゆっくり休んでください。푹 쉬세요                     |
| ほとんど                      | 호톤도     | 거의                | 宿題はほとんど終わった。숙제는 거의 끝났다            |
| だいたい                      | 다이타이   | 대체로, 대충        | だいたい分かりました。대체로 이해했어요               |
| ちょうど                      | 쵸-도      | 딱, 마침, 정각      | 今ちょうど12時です。지금 딱 12시예요                  |

### 헷갈림 방지 3세트

- **だいぶ(정도가 많이) / だいたい(대충·대체로) / たいてい(빈도: 대개)** — だいぶ痛い(많이 아프다), だいたい100人(대략 100명), たいてい7時に起きる(대개 7시에 일어난다)
- **とうとう / やっと** — 둘 다 "마침내"지만, やっと는 고생 끝 좋은 결과 전용. とうとう는 나쁜 결과에도 씀 (とうとう雨が降り出した)
- **ぜひ(부탁·희망: ~てください/たい와 세트) / かならず(반드시: 의무·약속) / きっと(분명: 추측)**

## 유의표현(言い換え) 17개

시험에선 왼쪽 문장이 나오고 "같은 의미의 문장"을 고르는 형태로 출제된다. **읽기 → 뜻 → 바꿔쓰기** 순으로 소리 내서 확인.

| 표현 (읽기)             | 뜻                  | ≒ 바꿔쓰기 (읽기)                          |
| ----------------------- | ------------------- | ------------------------------------------ |
| 留守です (るすです)     | 부재중이다          | 家にいません (いえ)                        |
| びっくりした            | 깜짝 놀랐다         | 驚いた (おどろいた)                        |
| うるさい                | 시끄럽다            | 静かではない (しずか)                      |
| 大切だ (たいせつだ)     | 소중하다, 중요하다  | 大事だ (だいじだ)                          |
| 用意する (よういする)   | 준비하다            | 準備する (じゅんびする)                    |
| やさしい問題 (もんだい) | 쉬운 문제           | 簡単な問題 (かんたん)                      |
| 危険だ (きけんだ)       | 위험하다            | あぶない (危ない)                          |
| 怒られた (おこられた)   | 혼났다              | 叱られた (しかられた)                      |
| だんだん                | 점점                | 少しずつ (すこしずつ)                      |
| 〜しか〜ない            | ~밖에 없다          | 〜だけ (~만) ※しか는 부정문, だけ는 긍정문 |
| 空いている (すいている) | 한산하다, 비어 있다 | 人が少ない (ひとがすくない)                |
| 間に合った (まにあった) | 시간에 맞췄다       | 遅れなかった (おくれなかった)              |
| 引っ越した (ひっこした) | 이사했다            | 新しい家に移った (うつった)                |
| 戻る (もどる)           | 되돌아오다          | 帰ってくる (かえってくる)                  |
| チェックする            | 확인하다            | 確かめる (たしかめる)・調べる (しらべる)   |
| くださった              | 주셨다              | くれた의 높임 (주어는 윗사람)              |
| 見物する (けんぶつする) | 구경하다            | 見て回る (みてまわる)                      |

### 유의표현 풀이 요령

1. 답 문장은 **원문보다 쉬운 말**로 풀어쓴 경우가 대부분 (見物する → 見て回る)
2. 부정 표현이 끼어 있으면 방향 주의: うるさい ≒ 静かでは**ない**, 間に合った ≒ 遅れ**なかった**
3. 경어가 나오면 보통형으로 환원해서 생각: くださった → くれた
