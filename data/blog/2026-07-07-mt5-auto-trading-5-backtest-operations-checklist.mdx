> 이 글은 학습용 정리이며 투자 권유가 아니다. 백테스트 수익은 실전 수익을 보장하지 않는다. 자동매매는 항상 손실 가능성을 전제로 운영해야 한다.

MT5 자동매매에서 백테스트는 필수다. 하지만 백테스트 결과가 좋다고 바로 실계좌에 넣으면 위험하다. 백테스트는 “과거에 이 규칙이 어떻게 동작했는지”를 보는 도구이지, 미래 수익을 약속하는 도구가 아니다.

## 1. 백테스트란?

백테스트는 과거 가격 데이터에 자동매매 전략을 적용해보는 과정이다.

확인할 수 있는 것:

- 전략이 실제로 주문을 내는지
- 손절/익절이 의도대로 작동하는지
- 포지션 중복이 발생하지 않는지
- 특정 기간에 손실이 얼마나 커지는지
- 거래 횟수가 너무 많거나 적지 않은지
- 수익 곡선이 안정적인지

확인할 수 없는 것:

- 미래 수익 보장
- 실제 슬리피지 완전 반영
- 브로커 서버 장애
- 실계좌 심리 부담
- 급변동장에서의 체결 품질 완전 재현

## 2. Strategy Tester 기본 흐름

MT5에는 EA를 테스트할 수 있는 Strategy Tester가 있다.

기본 흐름은 아래와 같다.

```text
1. 테스트할 EA 선택
2. 종목 선택
3. 시간봉 선택
4. 테스트 기간 선택
5. 초기 예치금과 레버리지 설정
6. 모델링 방식 선택
7. 입력 파라미터 설정
8. Start 클릭
9. 결과와 그래프 확인
```

처음에는 최적화보다 단일 테스트부터 해야 한다. 전략이 정상 작동하는지 확인하기 전에 최적화부터 하면 결과 해석이 어려워진다.

## 3. 결과에서 볼 것

백테스트 결과에서 수익률만 보면 안 된다.

| 항목         | 보는 이유                     |
| ------------ | ----------------------------- |
| 총손익       | 전체적으로 수익인지 손실인지  |
| 최대 낙폭    | 계좌가 얼마나 깊게 흔들렸는지 |
| 거래 횟수    | 통계적으로 의미 있는지        |
| 승률         | 전략의 성격 파악              |
| 손익비       | 평균 이익과 평균 손실의 관계  |
| 연속 손실    | 운영 중 버틸 수 있는지        |
| Equity Curve | 평가자산 곡선이 자연스러운지  |
| Deposit Load | 증거금 부담이 과하지 않은지   |

자동매매에서 가장 중요한 지표 중 하나는 최대 낙폭이다. 수익률이 높아도 낙폭이 너무 크면 실전 운영이 어렵다.

## 4. 과최적화 조심하기

과최적화는 과거 데이터에만 딱 맞는 파라미터를 찾는 문제다.

예를 들어 이동평균 기간을 1부터 200까지 돌려서 가장 수익이 좋은 조합을 찾았다고 하자. 그 조합이 미래에도 잘 된다는 보장은 없다. 과거의 노이즈에 맞춘 결과일 수 있다.

과최적화를 줄이는 방법:

- 파라미터 개수를 줄인다.
- 너무 좁은 기간만 테스트하지 않는다.
- 여러 시장 구간에서 테스트한다.
- 포워드 테스트를 사용한다.
- 거래 비용과 스프레드를 보수적으로 반영한다.
- 결과가 지나치게 예쁜 전략을 의심한다.

## 5. 포워드 테스트

포워드 테스트는 전체 기간 중 일부를 최적화에 쓰지 않고 남겨두었다가, 나중에 검증용으로 확인하는 방식이다.

예시:

```text
2019~2024년: 전략 개발/백테스트
2025년: 포워드 테스트
2026년: 데모 계정 실시간 테스트
```

MT5 Strategy Tester에도 포워드 테스트 기능이 있다. 포워드 구간에서 성능이 급격히 무너지면 과최적화 가능성을 의심해야 한다.

## 6. 데모 계정 실시간 테스트

백테스트를 통과해도 바로 실계좌로 가면 안 된다. 다음 단계는 데모 계정 실시간 테스트다.

데모 테스트에서 볼 것:

- 주문이 의도한 시간에 나가는가?
- 종목명이 정확한가?
- 스프레드 필터가 작동하는가?
- 손절/익절이 정상 설정되는가?
- 중복 포지션이 생기지 않는가?
- 로그가 충분히 남는가?
- 하루 손실 한도에서 멈추는가?
- VPS 또는 PC 재시작 후 복구되는가?

최소 2~4주 이상은 데모로 돌려보는 것이 좋다. 전략 주기가 길다면 더 오래 봐야 한다.

## 7. 실전 운영 전 체크리스트

실계좌 투입 전 아래 항목을 확인한다.

### 계좌/브로커

- 실계좌 서버명 확인
- 종목명 확인
- 최소 lot과 lot step 확인
- 거래 가능 시간 확인
- 레버리지와 증거금 확인
- 수수료와 스프레드 확인

### 전략

- 진입 조건 명확함
- 청산 조건 명확함
- 손절가 항상 존재
- 익절 또는 청산 로직 존재
- 중복 진입 방지
- 뉴스 시간 회피 여부 결정

### 리스크

- 1회 거래 손실 한도
- 하루 손실 한도
- 연속 손실 중지 규칙
- 최대 포지션 수 제한
- 최대 lot 제한
- 비정상 스프레드 차단

### 운영

- 로그 저장
- 주문 실패 시 알림
- VPS 또는 PC 전원 관리
- 인터넷 장애 대응
- MT5 업데이트 후 재검증
- 수동 비상정지 방법 숙지

## 8. 실계좌 첫 운영 원칙

실계좌 첫 운영은 수익을 내기 위한 단계가 아니라 “시스템이 망가지지 않는지 확인하는 단계”다.

추천 원칙:

```text
- 최소 lot으로 시작한다.
- 한 전략만 켠다.
- 첫 1~2주는 주문을 매일 확인한다.
- 코드 수정 후에는 다시 데모 테스트한다.
- 예상과 다른 주문이 한 번이라도 나오면 즉시 중지한다.
```

자동매매는 켜놓고 잊어버리는 것이 아니다. 오히려 처음에는 수동매매보다 더 꼼꼼히 관찰해야 한다.

## 9. 운영 일지 작성

자동매매를 개선하려면 운영 일지가 필요하다.

기록할 항목:

- 날짜
- 전략 버전
- 종목
- 거래 횟수
- 손익
- 최대 낙폭
- 오류 로그
- 수정한 파라미터
- 다음 개선점

운영 일지가 없으면 전략이 좋아진 것인지, 운이 좋았던 것인지 구분하기 어렵다.

## 정리

MT5 자동매매의 실전 흐름은 아래 순서가 안전하다.

```text
아이디어
→ 코드 작성
→ 단일 백테스트
→ 여러 기간 테스트
→ 포워드 테스트
→ 데모 실시간 운영
→ 최소 lot 실계좌 운영
→ 로그 기반 개선
```

자동매매는 한 번에 완성하는 프로젝트가 아니라 계속 검증하고 고치는 운영 시스템이다. 첫 목표는 큰 수익이 아니라 **계좌를 지키면서 전략의 실제 동작을 확인하는 것**이어야 한다.
