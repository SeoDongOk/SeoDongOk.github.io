정보처리기사 실기에서 네트워크 프로토콜은 양이 많아 보이지만, 실제로는 **계층 + 역할 + 포트 + 키워드**로 묶으면 훨씬 외우기 쉽다.  
내가 약한 부분은 “프로토콜 이름은 들어봤는데, 문제에서 어떤 키워드가 나오면 어떤 답을 써야 하는지”가 흔들리는 점이다.

그래서 이번 글은 시험 직전용으로 **프로토콜을 답안 키워드 중심**으로 정리한다.

## 1. 먼저 OSI 7계층부터 고정하기

프로토콜 문제는 대부분 계층을 물어보거나, 특정 프로토콜의 역할을 묻는다.  
따라서 OSI 7계층은 무조건 암기해야 한다.

| 계층 | 이름            | 핵심 키워드          | 대표 장비/프로토콜            |
| ---- | --------------- | -------------------- | ----------------------------- |
| 7    | 응용 계층       | 사용자 서비스        | HTTP, FTP, SMTP, DNS          |
| 6    | 표현 계층       | 인코딩, 암호화, 압축 | JPEG, MPEG, SSL/TLS 개념 연결 |
| 5    | 세션 계층       | 연결 유지, 세션 관리 | RPC, NetBIOS                  |
| 4    | 전송 계층       | 종단 간 전송, 포트   | TCP, UDP                      |
| 3    | 네트워크 계층   | 경로, IP 주소        | IP, ICMP, 라우터              |
| 2    | 데이터링크 계층 | MAC, 프레임          | Ethernet, PPP, 스위치         |
| 1    | 물리 계층       | 비트, 전기 신호      | 허브, 리피터                  |

암기 구호는 아래처럼 잡는다.

```text
아파서 티내다 피나다
Application Presentation Session Transport Network DataLink Physical
```

시험에서는 “어느 계층?”보다 “역할과 연결”로 나오는 경우도 많다.

예를 들어:

```text
신뢰성 있는 연결형 전송 → TCP → 전송 계층
비연결형 빠른 전송 → UDP → 전송 계층
IP 주소로 경로 선택 → IP / 라우터 → 네트워크 계층
MAC 주소 기반 전달 → 데이터링크 계층
```

## 2. TCP와 UDP 비교

TCP/UDP는 거의 반드시 나온다고 생각하고 외워야 한다.

| 구분      | TCP             | UDP                 |
| --------- | --------------- | ------------------- |
| 연결 방식 | 연결형          | 비연결형            |
| 신뢰성    | 높음            | 낮음                |
| 순서 보장 | 보장            | 보장 안 함          |
| 속도      | 상대적으로 느림 | 빠름                |
| 오류 제어 | 있음            | 거의 없음           |
| 흐름 제어 | 있음            | 없음                |
| 사용 예   | HTTP, FTP, SMTP | DNS, DHCP, 스트리밍 |

키워드로는 이렇게 외운다.

```text
TCP = 연결, 신뢰성, 순서, 재전송, 3-way handshake
UDP = 비연결, 빠름, 실시간, 오버헤드 적음
```

## 3. TCP 3-way handshake

TCP 연결 설정 과정은 자주 나오는 개념이다.

```text
1. SYN
2. SYN + ACK
3. ACK
```

흐름은 다음과 같다.

```text
클라이언트 → 서버: SYN
서버 → 클라이언트: SYN + ACK
클라이언트 → 서버: ACK
```

문제에서 “TCP 연결 설정”, “3단계 연결”, “SYN Flooding” 같은 키워드가 보이면 이 개념을 떠올린다.

## 4. 주요 응용 계층 프로토콜

응용 계층 프로토콜은 포트 번호까지 같이 외우는 것이 좋다.

| 프로토콜 | 포트  | 역할             | 키워드             |
| -------- | ----- | ---------------- | ------------------ |
| HTTP     | 80    | 웹 문서 전송     | 웹, 하이퍼텍스트   |
| HTTPS    | 443   | 암호화된 웹 통신 | TLS, 보안 웹       |
| FTP      | 20/21 | 파일 전송        | 데이터 20, 제어 21 |
| SSH      | 22    | 원격 접속        | 보안 쉘            |
| Telnet   | 23    | 원격 접속        | 평문, 보안 취약    |
| SMTP     | 25    | 메일 송신        | 보내기             |
| DNS      | 53    | 도메인 → IP 변환 | 이름 해석          |
| DHCP     | 67/68 | IP 자동 할당     | 임대, 동적 주소    |
| POP3     | 110   | 메일 수신        | 내려받기           |
| IMAP     | 143   | 메일 수신/동기화 | 서버 보관          |
| SNMP     | 161   | 네트워크 관리    | 장비 모니터링      |
| NTP      | 123   | 시간 동기화      | 시각 동기화        |

시험에서는 포트 번호를 직접 묻기보다 역할을 묻는 경우가 많다. 그래도 `HTTP 80`, `HTTPS 443`, `DNS 53`, `SSH 22`, `FTP 20/21`, `SMTP 25`는 반드시 외운다.

## 5. 메일 프로토콜 3종 비교

메일 프로토콜은 SMTP, POP3, IMAP이 헷갈린다.

| 프로토콜 | 역할           | 핵심                  |
| -------- | -------------- | --------------------- |
| SMTP     | 메일 송신      | 보내는 프로토콜       |
| POP3     | 메일 수신      | 클라이언트로 내려받기 |
| IMAP     | 메일 수신/관리 | 서버에 두고 동기화    |

암기:

```text
SMTP = Send
POP3 = Pull
IMAP = Internet Mail Access, 서버 동기화
```

## 6. 주소 관련 프로토콜

주소 변환 문제도 자주 나온다.

| 프로토콜 | 역할                         |
| -------- | ---------------------------- |
| ARP      | IP 주소를 MAC 주소로 변환    |
| RARP     | MAC 주소를 IP 주소로 변환    |
| DNS      | 도메인 이름을 IP 주소로 변환 |
| DHCP     | IP 주소를 자동 할당          |

헷갈리면 이렇게 외운다.

```text
ARP: IP → MAC
RARP: MAC → IP
DNS: 이름 → IP
DHCP: IP를 빌려줌
```

## 7. ICMP와 ping

ICMP는 IP 계층에서 오류와 제어 메시지를 전달하는 프로토콜이다.  
대표적으로 `ping` 명령에서 사용된다.

문제 키워드:

```text
네트워크 오류 보고
도달 가능성 확인
ping
echo request / echo reply
```

답: `ICMP`

## 8. 보안 프로토콜

보안 관련 프로토콜은 역할 중심으로 본다.

| 프로토콜/기술 | 역할               |
| ------------- | ------------------ |
| SSL/TLS       | 통신 암호화        |
| HTTPS         | HTTP + SSL/TLS     |
| SSH           | 보안 원격 접속     |
| IPsec         | IP 계층 보안       |
| SFTP          | SSH 기반 파일 전송 |
| FTPS          | SSL/TLS 기반 FTP   |

특히 Telnet과 SSH 비교는 자주 나온다.

```text
Telnet = 평문 원격 접속, 보안 취약
SSH = 암호화 원격 접속
```

문제에서 아래 키워드를 보면 바로 매칭한다.

| 문제 키워드             | 답    |

| 도메인 이름을 IP로 변환 | DNS   |

| 보안 원격 접속          | SSH   |
| 웹 보안 통신            | HTTPS |
| 메일 송신               | SMTP  |
| 메일 수신, 다운로드     | POP3  |

## 마무리

프로토콜은 하나씩 외우면 많아 보인다. 하지만 시험에서는 대부분 **역할 키워드**가 정해져 있다.  
따라서 아래 네 줄을 기준으로 반복하면 된다.

```text
계층을 먼저 본다.
역할 키워드를 찾는다.
포트 번호는 빈출만 외운다.
비교형은 TCP/UDP, POP3/IMAP, Telnet/SSH 중심으로 본다.
```

정보처리기사 실기에서는 정확한 용어를 쓰는 것이 중요하다.  
문제에서 “동적 IP 할당”이 나오면 “IP 자동 배정”처럼 풀어 쓰기보다 **DHCP**라고 정확히 쓰는 연습을 하자.
