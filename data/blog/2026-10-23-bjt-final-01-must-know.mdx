> 내일 시험장에서 바로 점수로 바뀌는 것만 남겼다. 오늘은 새 단어를 넓히지 말고, 아래 항목을 **보자마자 판단할 수 있는 상태**로 만든다.

## 1. 미정·예정·확정을 반드시 구분한다

| 표현               | 읽기                | 뜻                 | 판단               |
| ------------------ | ------------------- | ------------------ | ------------------ |
| 検討します         | けんとうします      | 검토하겠습니다     | 아직 미정          |
| 予定です           | よていです          | 예정입니다         | 계획 단계          |
| 〜つもりです       | 〜つもりです        | ~할 생각입니다     | 개인 의향          |
| 〜ことになりました | 〜ことに なりました | ~하기로 되었습니다 | 결정 완료          |
| 決定しました       | けっていしました    | 결정했습니다       | 확정               |
| 実施します         | じっしします        | 실시합니다         | 실행 단계          |
| 見送ります         | みおくります        | 보류합니다         | 이번에는 하지 않음 |
| 中止します         | ちゅうしします      | 중지합니다         | 계획 취소          |

**가장 위험한 오해:** `検討します`는 “하겠습니다”가 아니다.

## 2. 일정 방향을 놓치지 않는다

- `延期する`（えんきする / 엔키스루）: 뒤로 연기하다
- `前倒しする`（まえだおしする / 마에다오시스루）: 앞당기다
- `繰り上げる`（くりあげる / 쿠리아게루）: 순서·시기를 앞당기다
- `繰り下げる`（くりさげる / 쿠리사게루）: 순서·시기를 늦추다
- `変更する`（へんこうする / 헨코-스루）: 변경하다
- `延長する`（えんちょうする / 엔쵸-스루）: 기간을 늘리다

처음 나온 날짜가 아니라 **마지막으로 확정된 날짜**가 정답이다.

## 3. `まで`와 `までに`

- `三時まで働きます。`（さんじまで はたらきます）: 3시까지 계속 일합니다.
- `三時までに提出します。`（さんじまでに ていしゅつします）: 3시까지 제출을 완료합니다.

`まで`는 동작의 지속 종료점, `までに`는 완료 마감이다.

## 4. 숫자 범위를 정확히 자른다

| 표현               | 포함 관계          |
| ------------------ | ------------------ |
| 10以上             | 10 포함, 10 이상   |
| 10以下             | 10 포함, 10 이하   |
| 10未満             | 10 미포함, 10 미만 |
| 10を超える         | 10 미포함, 10 초과 |
| 遅くとも金曜までに | 늦어도 금요일까지  |
| 早くても来週       | 빨라도 다음 주     |
| 少なくとも三日     | 적어도 3일         |
| 多くても十名       | 많아도 10명        |

## 5. 부정은 문장 끝까지 듣는다

- `参加します`: 참가합니다
- `参加しません`: 참가하지 않습니다
- `参加できません`: 참가할 수 없습니다
- `参加しないわけではありません`: 참가하지 않는 것은 아닙니다 → 참가 가능성 있음
- `必ずしも必要ではありません`: 반드시 필요한 것은 아닙니다
- `〜かねます`: 하기 어렵습니다 → 사실상 정중한 거절

명사나 긍정 동사만 듣고 고르지 말고, **ない・ません・かねます**까지 기다린다.

## 6. 경어는 주체를 알려주는 표지다

| 기본형       | 존경어: 상대·상사 | 겸양어: 나·우리 편 |
| ------------ | ----------------- | ------------------ |
| 言う         | おっしゃる        | 申し上げる         |
| 行く・来る   | いらっしゃる      | 伺う・参る         |
| 見る         | ご覧になる        | 拝見する           |
| 聞く         | お聞きになる      | 伺う               |
| する         | なさる            | いたす             |
| いる         | いらっしゃる      | おる               |
| 食べる・飲む | 召し上がる        | いただく           |

거래처 앞에서는 자기 회사 부장도 우리 편이므로 `部長が伺います`처럼 낮춘다.

## 7. 업무 흐름은 순서로 외운다

1. `作成 → 確認 → 修正 → 提出 → 承認`
2. `申請 → 承認 / 差し戻し`
3. `見積もり → 発注 → 受注 → 出荷 → 納品`
4. `発生 → 影響確認 → 原因調査 → 復旧 → 報告 → 再発防止`
5. `問い合わせ → 回答 → 対応完了`

질문이 “다음에 무엇을 하는가”라면 현재 단계의 **바로 다음 단계**를 고른다.

## 8. 전환어 뒤가 결론일 가능성이 높다

- `しかし・ところが`: 그러나
- `ただし`: 단, 다만
- `一方で`: 한편
- `そのため・したがって`: 그 때문에·따라서
- `結局`: 결국
- `つまり・要するに`: 즉·요컨대

앞부분을 이해하지 못해도 전환어가 들리면 집중을 다시 시작한다.

## 9. 전화 문제는 다섯 칸만 잡는다

```text
발신자 / 찾는 사람 / 부재 이유 / 복귀 시각 / 누가 다시 연락하는가
```

- `席を外しております`: 자리를 비웠습니다
- `終日外出しております`: 종일 외출 중입니다
- `戻り次第、折り返します`: 돌아오는 대로 다시 전화하겠습니다
- `その旨、申し伝えます`: 그 내용을 전달하겠습니다

`전달만 한다`와 `담당자가 다시 전화한다`를 구분한다.

## 10. 청독해는 화면과 음성의 역할을 나눈다

- 화면: 날짜·가격·수량·조건·이름
- 음성: 변경·예외·화자의 의도·최종 행동

화면에 있는 숫자를 그대로 고르지 말고, 음성에서 바뀌었는지 확인한다.

## 11. 독해는 전부 번역하지 않는다

1. 질문에서 `이유 / 결론 / 일치 / 다음 행동`을 확인한다.
2. 제목·첫 문장·접속어·마지막 문장을 본다.
3. 질문 키워드 주변에서 근거를 찾는다.
4. 본문보다 강하거나 넓게 말하는 선택지를 제거한다.

모르는 한자가 있어도 날짜, 조사, 접속어, 숫자, 반복어로 정답 범위를 좁힌다.

## 12. 시험 직전 마지막 열 문장

1. `検討します。` → 아직 미정
2. `実施することになりました。` → 실시 확정
3. `納期を前倒しします。` → 납기를 앞당김
4. `金曜日までに提出してください。` → 금요일까지 제출 완료
5. `申請が差し戻されました。` → 신청이 반려됨
6. `担当者が戻り次第、折り返します。` → 담당자가 복귀 후 전화
7. `ご要望には添いかねます。` → 요청 수용 곤란
8. `不良品の場合に限り交換します。` → 불량품일 때만 교환
9. `復旧しましたが、原因は調査中です。` → 서비스는 복구, 원인은 조사 중
10. `結論は次回に持ち越します。` → 아직 결론 없음

## 오늘의 종료 기준

이 페이지를 두 번 읽고 A급 어휘가 바로 떠오르면 종료한다. 새로운 200개를 더 보는 것보다 **이미 본 핵심을 틀리지 않는 것**이 내일 점수에 더 직접적이다.
