실제로는 4개 축이었다는 걸 확인했다. 볼린저 3밴드를 `%B` + 밴드폭으로 바꾸고,
z-score를 `expanding()`으로 고친 뒤 나머지 파이프라인을 마저 붙였다.

Fama-French 롤링 베타 → K-Means 클러스터링 → 최대 샤프 최적화 → SPY 백테스트.

그리고 결과가 나왔다.

```
                전략        SPY
누적수익      182.1%      69.3%
연환산        23.63%     11.37%
연변동성      24.88%     21.49%
샤프            0.95       0.53
MDD           -33.7%     -33.7%
```

**SPY의 2배를 이겼다.** 샤프도 0.95면 나쁘지 않다.

이 글은 이 숫자를 믿지 않기로 한 이유에 대한 기록이다.

## 먼저 파이프라인

검증 구간은 2018-11 ~ 2023-09, 60개월. 월 단위 리밸런싱 59회.

```
1. S&P500 503종목 일봉 (2015-09 ~ 2023-09)
2. 지표: GK변동성, RSI, %B, 밴드폭, ATR, MACD, 달러거래대금
3. 월말 집계 → 5년 평균 거래대금 상위 150종목
4. 1/2/3/6/9/12개월 수익률
5. Fama-French 5팩터 24개월 롤링 베타      ← 신규
6. K-Means k=4, 월별 횡단면                ← 신규
7. 최대 샤프 최적화 (long-only, 종목당 10% 상한)  ← 신규
8. SPY 대비 백테스트                        ← 신규
```

### 5단계에서 중요했던 한 줄

```python
betas = betas.groupby(level=1).shift()   # 1개월 시프트
```

t월 수익률로 추정한 베타를 t월 피처로 쓰면 미래를 보는 것이다. 한 칸 밀어야 한다.
사이드 체크로 시장베타 평균이 **0.998**, 중앙값 0.960이 나왔다. S&P500 종목이니
1 근처가 맞고, 계산이 안 틀렸다는 신호다.

### 6단계 — 강의 코드를 두 군데 고쳤다

강의 원본은 표준화 없이 K-Means를 돌린다.

```python
# 원본
KMeans(n_clusters=4, init=initial_centroids).fit(df)
```

RSI는 0~100, 수익률은 0.01 스케일이다. 유클리드 거리에서 **RSI가 사실상 혼자
결정한다.** 원본은 초기중심을 RSI 값(30/45/55/70)으로 찍어서 이 성질을 오히려
이용하는데, 그러면 나머지 16개 피처를 왜 넣었는지 알 수 없어진다.

월별 횡단면 표준화를 넣되, 라벨 안정성은 살려야 했다. K-Means 라벨은 원래
임의 순서라 매월 "3번 군집"의 의미가 달라진다. 표준화된 RSI 축 위에만
초기중심을 고정하는 방식으로 풀었다.

```python
init = np.zeros((K, len(FEATURES)))
init[:, rsi_idx] = [-1.5, -0.5, 0.5, 1.5]   # 표준화 공간의 RSI 축
```

| 1     | 47.4     | -0.55     | 0.40     | -1.8%      | 44.4          |

군집 3을 "고모멘텀"이라고 불러도 되는 근거다.

### 7단계 — PyPortfolioOpt 없이

의존성을 늘리고 싶지 않아 `scipy.optimize`로 직접 풀었다.

```python
def max_sharpe_weights(R):
    mu = R.mean().values * 252
    S  = R.cov().values * 252
    n  = len(mu)
    def neg_sharpe(w):
        v = np.sqrt(w @ S @ w)
        return -(w @ mu) / v if v > 1e-12 else 1e6
    res = minimize(neg_sharpe, np.repeat(1/n, n), method='SLSQP',
                   bounds=[(0.0, max(0.10, 1/n))] * n,
                   constraints=({'type':'eq','fun': lambda w: w.sum()-1},))
    ...
```

59회 리밸런싱 전부 수렴했다(동일가중 대체 0회). 공분산은 **t 시점까지의
직전 12개월 일별수익률만** 쓴다.

## 여기서부터가 본론

### 의심 1 — MDD가 둘 다 -33.7%인 게 이상하다

전략과 SPY의 최대낙폭이 소수점까지 같아 보였다. 계산 버그를 의심하고 정밀하게 찍었다.

```
strategy  MDD = -33.6715%   저점일 2022-09-26
SPY       MDD = -33.7173%   저점일 2020-03-23
```

**저점 시기가 다르다.** 전략은 2022년 긴축장에서, SPY는 2020년 코로나에서 바닥을
쳤다. 크기가 우연히 비슷했을 뿐 버그는 아니었다. 다만 이건 전략이 SPY와 다른
방식으로 깨진다는 뜻이기도 하다.

### 의심 2 — 2020년

연도별로 쪼개봤다.

|                | 전략       | SPY        |
| -------------- | ---------- | ---------- |
| 2018 (11~12월) | -0.40%     | -8.09%     |
| 2019           | 30.57%     | 31.22%     |
| **2020**       | **83.93%** | **18.33%** |
| 2021           | 42.83%     | 28.73%     |
| 2022           | -18.17%    | -18.18%    |
| 2023 (~9월)    | 0.89%      | 12.60%     |

2019년은 SPY에 졌다. 2022년은 똑같이 깨졌다. 2023년은 크게 뒤진다.
**2020년 +83.93%가 혼자 서 있다.**

빼봤다.

```
             전체                    2020 제외
전략   23.63% / 샤프 0.95      11.64% / 샤프 0.61
SPY    11.37% / 샤프 0.53       9.65% / 샤프 0.56
```

연환산 우위가 12.3%p에서 **2.0%p로 줄고**, 샤프는 0.61 대 0.56으로 거의 붙는다.

고모멘텀 종목을 사는 전략이, 모멘텀이 역사적으로 폭발한 해에 이겼다.
이건 알파라기보다 **동어반복에 가깝다.**

### 의심 3 — 회전율

월평균 단측 회전율이 **68.2%**. 연으로 818%다. 포트폴리오를 1년에 여덟 번 갈아엎는다.

```
왕복  5bp → 연 0.82%p → 조정 후 22.81%
왕복 10bp → 연 1.64%p → 조정 후 21.99%
왕복 20bp → 연 3.27%p → 조정 후 20.36%
```

전체 기간 기준으로는 견딘다. 하지만 2020년을 뺀 11.64%에 3.27%p를 물리면
**8.37%**, SPY(9.65%)에 진다.

### 의심 4 — 그래서 어느 단계가 일한 건가

이게 제일 중요했다. 사다리를 만들어 각 단계의 기여를 분해했다.

|                                  | 연환산 | 샤프 | 증분        |
| -------------------------------- | ------ | ---- | ----------- |
| SPY                              | 11.37% | 0.53 | —           |
| 동일가중 (전체 유니버스 150종목) | 14.70% | 0.63 | **+3.33%p** |
| 동일가중 (군집 3)                | 21.22% | 0.84 | +6.52%p     |
| MaxSharpe (군집 3)               | 23.63% | 0.95 | +2.41%p     |

읽는 법:

- **+3.33%p는 클러스터링과 무관하다.** 거래대금 상위 150종목을 그냥 동일가중으로
  들고만 있어도 SPY를 이긴다. 시가총액가중(SPY) 대비 동일가중의 소형주 편향 효과다.
  전략의 우위를 주장하려면 최소한 **이 동일가중을 벤치마크로 삼아야** 한다.
- **+6.52%p가 클러스터링의 몫이다.** 여기가 진짜 기여다.
- **+2.41%p가 최적화의 몫이다.** 샤프는 0.84 → 0.95로 올랐다. 변동성을 25.28%에서
  24.88%로 낮추면서 수익을 올렸으니 최적화는 제 일을 했다.

SPY 대비 12.3%p 중 **3.3%p는 벤치마크를 잘못 고른 데서 나온 착시**였다.

### 의심 5 — 생존 편향

이건 고칠 수 없었다. 종목 리스트를 위키피디아에서 받는데, 그건 **현재** 구성종목이다.
2018년에 S&P500이었다가 지금 없는 회사는 처음부터 데이터에 안 들어온다.

실제로 다운로드 단계에서 8개 종목(`GEV`, `SOLV`, `VLTO`, `RDDT` 등)이 과거 데이터
없음으로 실패했다. 최근 스핀오프·신규상장이다. 반대 방향 — 사라진 회사 — 은
실패조차 하지 않는다. 조용히 없다.

point-in-time 구성종목 데이터가 없으면 이 편향은 원리적으로 제거 불가능하다.

## 정리

| 점검            | 결과                                    |
| --------------- | --------------------------------------- |
| 표면 성과       | 연 23.63%, 샤프 0.95 (SPY 11.37%, 0.53) |
| 2020년 제외     | 연 11.64%, 샤프 0.61 (SPY 9.65%, 0.56)  |
| 회전율          | 월 68.2% / 연 818%, 20bp 시 -3.27%p     |
| 올바른 벤치마크 | 유니버스 동일가중 14.70% (SPY 아님)     |
| 생존 편향       | 제거 불가 (현재 구성종목 사용)          |

2020년을 빼고, 올바른 벤치마크(동일가중 14.70%)와 비교하고, 거래비용 20bp를
물리면 남는 게 거의 없다. **이 전략은 실전에 쓸 수 없다.**

그런데 이게 실패한 프로젝트라는 뜻은 아니다. 파이프라인은 정상 동작하고,
클러스터링이 +6.52%p를 만든다는 것도 사실이다. 문제는 그 우위가 특정 레짐
(2020년 모멘텀 장세)에 몰려 있다는 것이고, 그건 전략을 버릴 이유가 아니라
**레짐 의존성을 인정하고 다르게 설계할 이유**다.

## CFA 관점에서

CFA Level II Portfolio Management의 `Backtesting and Simulation` 모듈에
"**identify problems in a backtest of an investment strategy**"라는 LOS가 있다.
교재는 survivorship bias / look-ahead bias / data snooping을 설명한다.

이번에 만난 게 정확히 그것들이었다.

- **look-ahead bias** → `expanding()` z-score, 베타 1개월 시프트로 제거
- **survivorship bias** → 제거 실패, 한계로 명시
- **data snooping** → 2020년 제외 테스트가 사실상 이걸 확인하는 절차

Level II `Machine Learning` 모듈의 "unsupervised ML algorithms—including
principal components analysis, **k-means clustering**"도 그대로 만났다.
교재에서 읽을 땐 그냥 알고리즘 이름이었는데, 스케일이 다른 피처를 그냥 넣으면
RSI 하나가 거리를 지배한다는 건 직접 돌려봐야 알았다.
