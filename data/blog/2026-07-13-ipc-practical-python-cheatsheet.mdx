Python 문제는 코드가 짧은 대신 슬라이싱 경계, 자료형별 연산, 가변 객체에서 실수가 발생한다. 각 줄을 실행할 때 **변수의 값과 자료형을 함께 기록**한다.

## 1. 핵심 자료형

| 자료형  | 순서           | 변경   | 중복         |
| ------- | -------------- | ------ | ------------ |
| `list`  | 있음           | 가능   | 허용         |
| `tuple` | 있음           | 불가능 | 허용         |
| `set`   | 보장하지 않음  | 가능   | 불허         |
| `dict`  | 삽입 순서 유지 | 가능   | 키 중복 불허 |
| `str`   | 있음           | 불가능 | 허용         |

```python
type([1, 2])   # list
type((1, 2))   # tuple
type({1, 2})   # set
type({})       # dict: 빈 세트는 set()으로 생성
```

## 2. 슬라이싱

```text
sequence[start:stop:step]
start 포함, stop 미포함
```

```python
values = [0, 1, 2, 3, 4, 5]

values[1:4]    # [1, 2, 3]
values[:3]     # [0, 1, 2]
values[3:]     # [3, 4, 5]
values[::2]    # [0, 2, 4]
values[::-1]   # [5, 4, 3, 2, 1, 0]
values[-1]     # 5
values[-3:]    # [3, 4, 5]
```

음수 step에서는 오른쪽에서 왼쪽으로 이동한다. stop 인덱스가 포함되지 않는 규칙은 동일하다.

## 3. 리스트 연산

```python
values = [1, 2]
values.append([3, 4])  # [1, 2, [3, 4]]

values = [1, 2]
values.extend([3, 4])  # [1, 2, 3, 4]

values.insert(1, 9)    # [1, 9, 2, 3, 4]
```

| 메서드             | 의미                                  |
| ------------------ | ------------------------------------- |
| `append(x)`        | x 자체를 마지막 원소로 추가           |
| `extend(iterable)` | 각 원소를 펼쳐 추가                   |
| `pop(i)`           | i의 값을 반환하고 삭제, 기본은 마지막 |
| `remove(x)`        | 첫 번째 x 삭제                        |
| `sort()`           | 원본 정렬, 반환값은 `None`            |
| `sorted(x)`        | 정렬된 새 리스트 반환                 |

```python
matrix = [[0] * 3 for _ in range(2)]  # 독립된 내부 리스트
```

`[[0] * 3] * 2`는 같은 내부 리스트 참조를 반복할 수 있어 한 행 변경이 다른 행에도 반영되는 함정이 있다.

## 4. 문자열

문자열은 불변 객체이므로 인덱스로 문자를 직접 변경할 수 없다.

```python
text = "a,b,c"
text.split(",")            # ['a', 'b', 'c']
"-".join(["a", "b"])     # 'a-b'
"  hello  ".strip()        # 'hello'
"hello".replace("l", "L") # 'heLLo'
```

```python
"abc" * 2      # 'abcabc'
"a" in "cat"  # True
```

## 5. 세트 연산

```python
a = {1, 2, 3}
b = {3, 4}

a | b  # {1, 2, 3, 4}: 합집합
a & b  # {3}: 교집합
a - b  # {1, 2}: 차집합
a ^ b  # {1, 2, 4}: 대칭 차집합
```

세트는 중복을 제거한다. 순서가 문제의 핵심일 때 세트 출력 순서를 임의로 가정하지 않는다.

## 6. 딕셔너리

```python
score = {"Kim": 90, "Lee": 80}

score["Kim"]           # 90
score.get("Park", 0)   # 0
score["Park"] = 70

for key, value in score.items():
    print(key, value)
```

`dict[key]`는 키가 없으면 `KeyError`, `dict.get(key, default)`는 기본값을 반환한다.

## 7. 조건식과 논리 연산

```python
result = "짝수" if number % 2 == 0 else "홀수"
```

```text
and: 앞이 거짓이면 앞의 값을 반환, 아니면 뒤의 값
or: 앞이 참이면 앞의 값을 반환, 아니면 뒤의 값
not: 논리값 반전
```

```python
0 or 10       # 10
5 and 10      # 10
[] or [1, 2]  # [1, 2]
```

대표적인 거짓 값은 `False`, `None`, 숫자 0, 빈 문자열, 빈 리스트, 빈 튜플, 빈 세트, 빈 딕셔너리다.

## 8. 반복문과 range

```text
range(start, stop, step): start 포함, stop 미포함
```

```python
list(range(1, 5))       # [1, 2, 3, 4]
list(range(5, 0, -2))   # [5, 3, 1]
```

```python
for index, value in enumerate(["a", "b"]):
    print(index, value)

for left, right in zip([1, 2], [3, 4]):
    print(left + right)
```

`break`는 반복문 종료, `continue`는 다음 반복, 반복문 `else`는 break 없이 정상 종료했을 때 실행된다.

## 9. 함수 인자

```python
def add(a: int, b: int = 0) -> int:
    return a + b

def total(*args: int) -> int:
    return sum(args)

def show(**kwargs: object) -> None:
    print(kwargs)
```

```text
*args: 여러 위치 인자를 튜플로 받음
**kwargs: 여러 키워드 인자를 딕셔너리로 받음
```

가변 기본 인자는 호출 간 공유될 수 있으므로 실무에서는 다음 패턴을 사용한다.

```python
def append_value(value: int, values: list[int] | None = None) -> list[int]:
    if values is None:
        values = []
    values.append(value)
    return values
```

## 10. 가변 객체와 얕은 복사

```python
a = [1, 2]
b = a
b.append(3)
print(a)  # [1, 2, 3]
```

`a`와 `b`가 같은 리스트를 참조하기 때문이다.

```python
b = a[:]       # 얕은 복사
b = a.copy()   # 얕은 복사
```

중첩 객체까지 독립적으로 복사하려면 깊은 복사가 필요하다. 시험에서는 각 변수가 같은 객체를 가리키는지 화살표로 표시한다.

## 11. 클래스와 상속

```python
class Parent:
    def print_value(self) -> None:
        print("P")

class Child(Parent):
    def print_value(self) -> None:
        print("C")

obj: Parent = Child()
obj.print_value()  # C
```

- `self`: 현재 인스턴스
- `__init__`: 인스턴스 초기화 메서드
- `super()`: 부모 클래스 기능 호출
- `__str__`: 문자열 표현 정의

## 12. 시험 직전 점검

```text
슬라이스 stop은 미포함
[::-1]은 역순
append는 통째로, extend는 펼쳐서 추가
sort는 원본 변경·None 반환, sorted는 새 리스트 반환
{}는 빈 dict, 빈 set은 set()
세트: | 합집합, & 교집합, - 차집합, ^ 대칭 차집합
range도 stop 미포함
//는 몫, %는 나머지, **는 거듭제곱
가변 객체의 대입은 같은 객체를 가리킬 수 있음
==는 값 비교, is는 객체 동일성 비교
```

Python 문제는 각 변수 옆에 `자료형: 현재 값`을 적는다. 리스트나 딕셔너리가 함수에 전달되면 원본 객체가 변경되는지까지 확인한다.
