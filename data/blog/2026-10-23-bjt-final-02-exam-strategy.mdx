> 목표는 모든 일본어를 이해하는 것이 아니라, 제한된 시간 안에 **관계·의도·최종 결정·다음 행동**을 최대한 많이 맞히는 것이다.

## 1. 시험 시작 전

- 신분증과 시험장 안내를 다시 확인한다.
- 최소 30분 전 도착을 목표로 한다.
- 시험 직전에는 새 문법을 보지 않고 `검토/확정`, `연기/앞당김`, `이상/미만`만 확인한다.
- 긴장하면 4초 들이마시고 6초 내쉬는 호흡을 세 번 한다.

## 2. 전체 운영 원칙

1. 한 문제를 놓쳐도 다음 문제까지 끌고 가지 않는다.
2. 들리지 않은 단어보다 들린 **관계와 결론**을 사용한다.
3. 선택지의 경어가 화려하다는 이유로 고르지 않는다.
4. 첫 제안보다 마지막 수정안을 우선한다.
5. 정답을 바꿀 때는 명확한 근거가 있을 때만 바꾼다.

## 3. 청해: 음성이 나오기 전

사진이나 선택지를 볼 시간이 있다면 세 가지만 예측한다.

```text
장소: 사무실 / 전화 / 회의 / 매장 / 현장
관계: 상사-부하 / 동료 / 직원-고객 / 자사-거래처
목적: 보고 / 요청 / 거절 / 변경 / 사과 / 확인
```

예측은 정답을 미리 정하는 일이 아니라, 들을 단어의 범위를 줄이는 작업이다.

## 4. 청해: 듣는 동안

### 짧은 문제

- 누가 말하는가?
- 누구에게 말하는가?
- 이 상황에서 자연스러운 경어인가?

### 긴 대화

```text
처음 안:
문제:
수정 안:
최종 결정:
다음 행동:
```

메모는 일본어나 완전한 문장이 필요 없다. `월→수`, `A× B○`, `김/전화`처럼 짧게 쓴다.

### 놓쳤을 때

- 앞 문장을 복원하려 하지 않는다.
- `しかし・ただ・では・結局・それでは` 뒤부터 다시 듣는다.
- 마지막 동사의 긍정·부정을 잡는다.

## 5. 청독해: 화면을 먼저 읽는 법

화면에서 다음만 찾는다.

- 제목과 목적
- 날짜와 마감
- 가격과 수량
- 대상과 예외
- 사람 이름과 담당

음성에서는 **화면에 없는 변경사항**을 찾는다.

### 자료형별 우선순위

| 자료      | 먼저 볼 것                  |
| --------- | --------------------------- |
| 표        | 행·열 제목과 단위           |
| 그래프    | 축, 최고·최저, 증가·감소    |
| 광고      | 가격, 기간, 대상, 제외 조건 |
| 일정표    | 날짜, 시간, 중복 일정       |
| 이메일    | 발신자, 목적, 요청, 기한    |
| 결재 화면 | 상태, 승인자, 반려 사유     |

## 6. 독해: 30분 운영

### 권장 배분

- 어휘·문법: 약 7분
- 표현독해: 약 9분
- 종합독해: 약 12분
- 최종 확인: 약 2분

개인 속도에 따라 조정하되, 초반 한 문제에 시간을 모두 쓰지 않는다.

### 한 문제 루틴

1. 질문을 먼저 읽는다.
2. 무엇을 찾는지 한 단어로 정한다: `이유 / 결론 / 대상 / 다음 행동`.
3. 접속어와 숫자 주변을 찾는다.
4. 근거와 가장 가까운 선택지를 고른다.
5. 60~90초가 넘으면 표시하고 이동한다.

## 7. 선택지 제거 규칙

다음 선택지는 우선 의심한다.

- 본문의 `일부`를 `전부`라고 확대한다.
- `검토`를 `확정`으로 바꾼다.
- 행동 주체를 바꾼다.
- 날짜·수량의 최초 값만 반복한다.
- 이유와 결과를 뒤집는다.
- 맞는 사실이지만 질문에 답하지 않는다.
- 지나치게 강한 `必ず・すべて・絶対に`를 붙인다.

## 8. 420점 목표 운영

420점은 모든 고난도 문제를 풀어야만 가능한 목표로 생각하지 않는다. 다음 영역의 실수를 줄이는 데 집중한다.

- 전화 부재와 재연락
- 일정 연기·앞당김
- 신청·승인·반려
- 문서 제출과 수정
- 표·광고의 마감과 예외
- 이메일의 요청과 다음 행동
- 장애의 현재 상태

어려운 경어 한 문제보다 **명확한 업무 흐름 문제를 지키는 것**이 중요하다.

## 9. 멘탈 리셋 문장

한 문제를 놓쳤을 때 속으로 말한다.

> `この問題は終わり。次の結論を聞く。`  
> この もんだいは おわり。つぎの けつろんを きく。  
> 코노 몬다이와 오와리. 츠기노 케츠론오 키쿠.  
> 이 문제는 끝났다. 다음 결론을 듣는다.

## 10. 마지막 10분 행동

- 독해에서 표시한 문제로 돌아간다.
- 답을 바꿀 때는 본문 근거 위치를 확인한다.
- 숫자 단위와 `以上・以下・未満`을 다시 본다.
- 미응답이 없는지 확인한다.

## 하지 않을 것

- 전날 밤새기
- 시험 직전 새 단어 수백 개 보기
- 모르는 한자 하나 때문에 지문 전체 포기
- 청해 한 문제를 머릿속에서 계속 복기하기
- 선택지 번호의 분포로 정답 추측하기
