> 한국 한자음과 일본어 음독은 같은 뿌리(중고 중국어)에서 갈라져 나왔다. 그래서 **한국어 받침을 보면 일본어 음독의 끝소리를 상당한 확률로 추측할 수 있다.** N2 어휘의 대부분이 음독 한자어이므로, 이 규칙 하나로 아낄 수 있는 시간이 꽤 크다.

## 시작 전 전제 세 가지

규칙을 쓰기 전에 범위를 명확히 해둔다.

1. **음독에만 적용된다.** 훈독(やま, たべる)은 일본 고유어라 한국 한자음과 아무 관계가 없다.
2. **경향이지 법칙이 아니다.** 예외가 있고, 뒤에서 따로 정리한다.
3. **끝소리만 맞춰준다.** 앞부분 자음·모음은 별도로 익혀야 한다.

즉 이 규칙은 "정답을 만들어내는 도구"가 아니라 **"보기 4개 중에서 2개를 지우는 도구"** 다. 시험장에서는 그것만으로도 충분히 크다.

## 대응 규칙 한눈에

| 한국어 받침 | 일본어 음독 끝소리 | 예시            |
| ----------- | ------------------ | --------------- |
| ㄱ          | く / き            | 학 → が**く**   |
| ㄹ          | つ / ち            | 일 → い**ち**   |
| ㄴ          | ん                 | 산 → さ**ん**   |
| ㅁ          | ん                 | 삼 → さ**ん**   |
| ㅇ          | う / い (장음)     | 동 → と**う**   |
| ㅂ          | う                 | 십 → じゅ**う** |
| 받침 없음   | 모음으로 끝남      | 사(社) → しゃ   |

이제 하나씩 예시를 붙인다.

## 1. 받침 ㄱ → く / き

가장 규칙성이 높은 그룹이다. 체감상 거의 안 틀린다.

| 한자 | 한국음 | 음독   | N2 숙어 예시       |
| ---- | ------ | ------ | ------------------ |
| 学   | 학     | がく   | 学習（がくしゅう） |
| 国   | 국     | こく   | 国際（こくさい）   |
| 石   | 석     | せき   | 石油（せきゆ）     |
| 服   | 복     | ふく   | 服装（ふくそう）   |
| 力   | 력     | りょく | 能力（のうりょく） |
| 式   | 식     | しき   | 形式（けいしき）   |
| 続   | 속     | ぞく   | 継続（けいぞく）   |

**く와 き 중 어느 쪽인가**는 앞 모음을 따라간다. あ·お 계열이면 く, え·い 계열이면 き로 가는 경향이 있다 (がく, こく / せき, しき).

## 2. 받침 ㄹ → つ / ち

한국어 ㄹ 받침은 원래 -t 소리였다. 일본어에서는 つ 또는 ち로 남았다.

| 한자 | 한국음 | 음독 | N2 숙어 예시     |
| ---- | ------ | ---- | ---------------- |
| 一   | 일     | いち | 一般（いっぱん） |
| 発   | 발     | はつ | 発展（はってん） |
| 物   | 물     | ぶつ | 物価（ぶっか）   |
| 室   | 실     | しつ | 温室（おんしつ） |
| 月   | 월     | げつ | 月末（げつまつ） |
| 質   | 질     | しつ | 品質（ひんしつ） |
| 活   | 활     | かつ | 活動（かつどう） |

이 그룹은 **촉음(っ)으로 변하는 일이 잦다.** 뒤에 か·さ·た·は행이 오면 つ가 っ로 줄어든다.

```text
発 (はつ) + 展 (てん) → はってん
一 (いち) + 般 (ぱん) → いっぱん
物 (ぶつ) + 価 (か)   → ぶっか
```

N4 때 가장 많이 틀렸던 지점이 여기였다. ㄹ 받침 한자가 앞에 오면 촉음을 먼저 의심한다.

## 3. 받침 ㄴ·ㅁ → ん

둘 다 ん으로 합쳐진다. 한국어에서는 구별되지만 일본어에서는 구별이 사라졌다.

| 한자 | 한국음 | 음독 | N2 숙어 예시     |
| ---- | ------ | ---- | ---------------- |
| 山   | 산     | さん | 火山（かざん）   |
| 新   | 신     | しん | 新聞（しんぶん） |
| 因   | 인     | いん | 原因（げんいん） |
| 三   | 삼     | さん | 三角（さんかく） |
| 心   | 심     | しん | 安心（あんしん） |
| 金   | 금     | きん | 金額（きんがく） |
| 感   | 감     | かん | 感覚（かんかく） |

한국어로는 산(ㄴ)과 삼(ㅁ)이 다르지만 일본어로는 둘 다 さん이다. **역방향 추측은 안 된다**는 뜻이기도 하다. さん을 보고 한국음이 산인지 삼인지는 알 수 없다.

## 4. 받침 ㅇ → う / い (장음)

이 그룹이 가장 많고, 장음 표기 실수가 나오는 구간이다.

| 한자 | 한국음 | 음독   | N2 숙어 예시       |
| ---- | ------ | ------ | ------------------ |
| 東   | 동     | とう   | 東京（とうきょう） |
| 生   | 생     | せい   | 生産（せいさん）   |
| 中   | 중     | ちゅう | 中心（ちゅうしん） |
| 空   | 공     | くう   | 空港（くうこう）   |
| 明   | 명     | めい   | 説明（せつめい）   |
| 経   | 경     | けい   | 経済（けいざい）   |
| 影   | 영     | えい   | 影響（えいきょう） |
| 相   | 상     | そう   | 相談（そうだん）   |

**う인지 い인지**는 앞 모음이 갈라놓는다.

- お단 뒤 → う (とう, そう, こう)
- え단 뒤 → い (せい, めい, けい, えい)

그리고 이건 전부 **장음**이다. せい는 "세이"가 아니라 "세-"에 가깝다. 시험에서 장음을 하나 빼면 그냥 오답이다.

## 5. 받침 ㅂ → う

원래 -p 소리였고, 일본어에서 ふ를 거쳐 う로 바뀌었다.

| 한자 | 한국음 | 음독   | N2 숙어 예시         |
| ---- | ------ | ------ | -------------------- |
| 十   | 십     | じゅう | 十分（じゅうぶん）   |
| 入   | 입     | にゅう | 入学（にゅうがく）   |
| 業   | 업     | ぎょう | 産業（さんぎょう）   |
| 急   | 급     | きゅう | 急速（きゅうそく）   |
| 集   | 집     | しゅう | 集中（しゅうちゅう） |
| 合   | 합     | ごう   | 合計（ごうけい）     |

## 반드시 알아야 할 예외

규칙을 믿되, 아래는 예외로 따로 외운다.

**ㅂ 받침인데 つ로 가는 것**

| 한자 | 한국음 | 음독 | 예시             |
| ---- | ------ | ---- | ---------------- |
| 立   | 립     | りつ | 独立（どくりつ） |
| 雑   | 잡     | ざつ | 複雑（ふくざつ） |

규칙대로면 りゅう, ぞう가 되어야 하는데 실제로는 りつ, ざつ다. 다른 시기에 들어온 읽기가 굳어진 경우다.

**한자 하나에 음독이 여러 개인 것**

| 한자 | 한국음 | 음독 1        | 음독 2        |
| ---- | ------ | ------------- | ------------- |
| 生   | 생     | せい (生産)   | しょう (一生) |
| 行   | 행     | こう (行動)   | ぎょう (行事) |
| 人   | 인     | じん (日本人) | にん (三人)   |
| 分   | 분     | ぶん (分析)   | ふん (五分)   |

이건 규칙으로 못 자른다. 숙어 단위로 외우는 수밖에 없다.

**한국음이 여러 개인 것**

樂은 한국어에서 낙(樂園)·악(音樂)·요(樂山)로 갈린다. 이런 글자는 한국음을 출발점으로 삼는 것 자체가 위험하다.

## 실전 적용 예제

처음 보는 단어 `複雑` 의 읽기를 고른다고 하자.

> 複雑な問題を解決する。
> ① ふくそう　② ふくざつ　③ ほうざつ　④ ふくしゅう

1. `複` = 복, 받침 ㄱ → **く로 끝난다** → ふく 또는 ほく. ③ 탈락.
2. `雑` = 잡, 받침 ㅂ → 규칙대로면 う 계열이지만, 이건 예외로 ざつ.
3. 남은 건 ①과 ②. ① そう는 ㅇ 받침 글자의 읽기라 잡(ㅂ)과 안 맞는다.
4. 정답 ②.

예외 하나를 미리 알고 있어야 풀리는 문제지만, **규칙만으로도 4개 중 2개는 지웠다.** 이게 이 규칙을 쓰는 방식이다.

## 정리

| 받침  | 끝소리  | 주의할 점                |
| ----- | ------- | ------------------------ |
| ㄱ    | く / き | 규칙성 가장 높음         |
| ㄹ    | つ / ち | 촉음(っ)으로 자주 변함   |
| ㄴ·ㅁ | ん      | 역방향 추측 불가         |
| ㅇ    | う / い | 전부 장음, 빼먹으면 오답 |
| ㅂ    | う      | 立·雑 예외               |

다음 편에서는 이번에 예외로 미뤄둔 **음독이 여러 개인 빈출 한자**를 숙어와 묶어서 정리한다.
