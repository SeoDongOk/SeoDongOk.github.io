## 빈칸 문제 풀이 순서

1. 빈칸 앞뒤가 명사·동사·조사 중 무엇을 요구하는지 본다.
2. 문장의 긍정·부정과 시제를 확인한다.
3. 업무 흐름상 맞는 동사를 고른다.
4. 관용적으로 함께 쓰이는 조합을 확인한다.

## 업무 흐름으로 외울 동사

| 흐름 | 일본어                       | 읽기                                                 | 뜻                           |
| ---- | ---------------------------- | ---------------------------------------------------- | ---------------------------- |
| 문서 | 作成→確認→修正→提出→承認     | さくせい→かくにん→しゅうせい→ていしゅつ→しょうにん   | 작성→확인→수정→제출→승인     |
| 거래 | 見積もり→発注→受注→納品      | みつもり→はっちゅう→じゅちゅう→のうひん              | 견적→발주→수주→납품          |
| 장애 | 発生→調査→復旧→報告→再発防止 | はっせい→ちょうさ→ふっきゅう→ほうこく→さいはつぼうし | 발생→조사→복구→보고→재발방지 |
| 일정 | 予定→調整→変更→決定          | よてい→ちょうせい→へんこう→けってい                  | 예정→조정→변경→결정          |

| 패턴           | 뜻                | 예문                       |
| -------------- | ----------------- | -------------------------- |

| 〜に関して     | ~에 관해서        | 変更に関して連絡する       |
| 〜に対して     | ~에 대해·대조하여 | 顧客に対して謝罪する       |
| 〜によって     | ~에 따라·의해     | 地域によって異なる         |
| 〜に応じて     | ~에 맞추어        | 状況に応じて対応する       |
| 〜に伴って     | ~에 수반하여      | 移転に伴って住所が変わる   |
| 〜に基づいて   | ~에 근거하여      | データに基づいて判断する   |
| 〜を通じて     | ~을 통하여        | 研修を通じて学ぶ           |
| 〜に限り       | ~에 한하여        | 会員に限り割引する         |

| 〜にかかわらず | ~와 관계없이      | 経験にかかわらず応募できる |

## 결정 상태를 가르는 표현

- `検討します`: 검토하므로 아직 미정
- `検討した結果`: 검토를 마친 뒤 결과가 이어짐
- `〜ことにしました`: 화자·조직이 결정함
- `〜ことになりました`: 결정된 결과를 알림
- `見送ることにしました`: 시행하지 않기로 결정
- `保留となりました`: 결정 보류

## 자주 틀리는 유사어

| 표현 A | 표현 B | 차이                              |
| ------ | ------ | --------------------------------- |
| 返信   | 転送   | 답장 / 다른 사람에게 전달         |
| 延期   | 中止   | 뒤로 미룸 / 실시하지 않음         |
| 申請   | 承認   | 허가 요청 / 허가 결정             |
| 発注   | 受注   | 주문함 / 주문받음                 |
| 対応   | 対象   | 처리·응대 / 적용되는 대상         |
| 改善   | 改正   | 상태 개선 / 규정·법률 개정        |
| 回収   | 収集   | 제품 등을 거둠 / 정보·자료를 모음 |
| 欠品   | 不良品 | 재고 없음 / 결함 상품             |

## 빈칸 훈련 10문제

1. 内容を確認した（　）、提出してください。  
   ①上で ②たびに ③一方で ④に限り → **①**
2. 予算が承認され（　）、発注します。  
   ①次第 ②ながら ③ほど ④だけ → **①**
3. 会員（　）、参加費は三千円です。  
   ①に限り ②について ③によって ④を通じて → **①**
4. 祝日を（　）、午前九時から営業します。  
   ①除き ②伴い ③応じて ④基づいて → **①**
5. 調査の結果に（　）、対応を決めます。  
   ①基づいて ②限って ③先立ち ④かかわらず → **①**
6. 移転に（　）、電話番号も変わります。  
   ①伴って ②除いて ③限って ④対して → **①**
7. お客様からの問い合わせに（　）する。  
   ①対応 ②対象 ③対策 ④対立 → **①**
8. 注文を受けた会社が行うのは（　）です。  
   ①受注 ②発注 ③欠席 ④申請 → **①**
9. 会議は来月に（　）されました。  
   ①延期 ②中止 ③欠品 ④返信 → **①**
10. 今回の導入は（　）となり、次期に再検討します。  
    ①見送り ②承認済み ③納品 ④受注 → **①**

## 암기 기준

한자를 보고 2초 안에 뜻을 말하고, 비슷한 단어와 차이를 한 문장으로 설명할 수 있으면 통과다.
