## 시험 직전 빈출도

> **우선순위 S · ★★★★★**
>
> 키·무결성·차수·카디널리티는 거의 매년 DB/SQL 문제와 결합 가능한 안정적인 득점 영역이다.

- **최소 암기:** 슈퍼키·후보키·기본키·대체키·외래키, 개체·참조·도메인 무결성
- **5점 후보:** 후보키=유일성+최소성 / 기본키=NULL·중복 불가 / 외래키=참조 무결성
- **판정 기준:** 별점은 Q-Net의 공식 출제 확률이 아니다. 2020년 1회~2026년 1회 복원 목록과 2026 시나공 핵심요약의 실기 출제 이력 표기를 개념군 단위로 교차해 정한 **시험 전날 상대 우선순위**다.

관계형 데이터베이스 이론은 정의가 명확해 반드시 득점해야 한다. `행`, `열`, `기본키`, `외래키`, `값의 범위` 같은 단어를 먼저 찾으면 답이 빠르게 좁혀진다.

## 1. 릴레이션 구성 요소

| 용어       | 의미                                 | 같은 표현       |
| ---------- | ------------------------------------ | --------------- |
| 릴레이션   | 행과 열로 구성된 논리적 테이블       | 테이블          |
| 튜플       | 릴레이션의 한 행                     | 레코드          |
| 속성       | 릴레이션의 한 열                     | 필드            |
| 카디널리티 | 릴레이션의 튜플 수                   | 행의 수, 기수   |
| 차수       | 릴레이션의 속성 수                   | 열의 수, Degree |
| 도메인     | 한 속성이 가질 수 있는 원자값의 집합 | 값의 범위       |

```text
행 = 튜플 = 레코드
열 = 속성 = 필드
행의 수 = 카디널리티
열의 수 = 차수
```

## 2. 릴레이션의 특성

```text
튜플의 유일성: 같은 튜플은 중복되지 않음
튜플의 무순서성: 행의 순서는 의미가 없음
속성의 무순서성: 열의 논리적 순서는 의미가 없음
속성의 원자성: 한 셀은 더 나눌 수 없는 하나의 값
```

## 3. 스키마와 인스턴스

| 용어              | 의미                                  |
| ----------------- | ------------------------------------- |
| 릴레이션 스키마   | 릴레이션 이름과 속성 등 논리적 구조   |
| 릴레이션 인스턴스 | 특정 시점에 실제로 저장된 튜플의 집합 |

```text
스키마 = 구조
인스턴스 = 현재 데이터
```

## 4. 키의 조건

| 조건   | 의미                                 |
| ------ | ------------------------------------ |
| 유일성 | 하나의 키값으로 튜플 하나를 식별     |
| 최소성 | 식별에 불필요한 속성을 포함하지 않음 |

## 5. 키의 종류

| 키     | 조건과 의미                   |
| ------ | ----------------------------- |
| 슈퍼키 | 유일성 만족                   |
| 후보키 | 유일성 + 최소성 만족          |
| 기본키 | 후보키 중 대표로 선택         |
| 대체키 | 기본키가 되지 않은 후보키     |
| 외래키 | 다른 릴레이션의 기본키를 참조 |
| 복합키 | 둘 이상의 속성으로 구성       |

### 예제

```text
학생(학번, 주민번호, 이름, 학과코드)

후보키: 학번, 주민번호
기본키: 학번
대체키: 주민번호
슈퍼키: 학번, (학번, 이름), 주민번호 등
외래키: 학과코드
```

`(학번, 이름)`은 유일하지만 학번만으로도 식별 가능하므로 최소성을 만족하지 않는다.

## 6. 기본키 선택 기준

```text
NULL이 없는 속성
값이 자주 바뀌지 않는 속성
길이가 짧고 단순한 속성
업무적으로 안정적인 속성
```

## 7. 무결성

데이터베이스에 저장된 값이 현실 세계의 값과 일치하고 정확한 상태를 유지하는 성질이다.

| 종류               | 규칙                              | 식별어      |
| ------------------ | --------------------------------- | ----------- |
| 개체 무결성        | 기본키는 NULL과 중복 불가         | 기본키      |
| 참조 무결성        | 외래키는 참조 기본키 값 또는 NULL | 외래키      |
| 도메인 무결성      | 속성값은 정의된 도메인에 속함     | 자료형·범위 |
| 사용자 정의 무결성 | 업무 규칙이 정한 조건 만족        | 업무 제약   |

```text
기본키 문제 = 개체 무결성
외래키 문제 = 참조 무결성
값의 범위 문제 = 도메인 무결성
```

## 8. 참조 무결성 동작

참조되는 기본키가 삭제·변경될 때 적용할 수 있는 대표 정책이다.

| 정책        | 동작                             |
| ----------- | -------------------------------- |
| RESTRICT    | 참조 중이면 삭제·변경 거부       |
| CASCADE     | 참조하는 행에도 변경을 연쇄 적용 |
| SET NULL    | 외래키를 NULL로 변경             |
| SET DEFAULT | 외래키를 기본값으로 변경         |

## 9. NULL

NULL은 0이나 빈 문자열이 아니라 **알 수 없거나 존재하지 않는 값**이다.

```text
NULL과 연산한 결과는 일반적으로 NULL
NULL 비교는 =가 아니라 IS NULL
NULL = NULL은 TRUE가 아니라 UNKNOWN
```

## 10. 시험 직전 암기

```text
후보키 = 유일성 + 최소성
슈퍼키 = 유일성
대체키 = 선택되지 않은 후보키
외래키 = 다른 릴레이션 기본키 참조
카디널리티 = 행
차수 = 열
도메인 = 값의 범위
개체 무결성 = 기본키
참조 무결성 = 외래키
도메인 무결성 = 속성값 범위
```
