일본어 한자를 처음 공부할 때 한자의 모든 읽기를 외우려고 하면 금방 지친다. 기초 단계에서는 **한자 하나의 읽기 목록**보다 **자주 쓰는 단어를 통째로 읽는 연습**이 효과적이다.

이 글은 일본어 생활 문장과 JLPT N5~N4 학습의 기반이 되는 한자 50자를 정리한 자료다. JLPT가 공식 한자 목록을 공개하는 것은 아니므로, 특정 시험의 출제 보장이 아니라 **학습 순서를 위한 기본 목록**으로 사용한다.

## 공부 원칙

1. 한자 하나보다 예시 단어를 먼저 소리 내어 읽는다.
2. 음독·훈독은 대표적인 것만 먼저 익힌다.
3. 손으로 한 번 쓰고, 다음에는 문장에서 다시 만난다.
4. 하루 5자씩 10일 동안 1회독한 뒤, 모르는 단어만 다시 복습한다.

### 숫자에서 주의할 점

숫자는 뒤에 오는 단위에 따라 발음이 바뀐다.

```text
一人（ひとり） 한 명
二人（ふたり） 두 명
三人（さんにん） 세 명
四人（よにん） 네 명

一日（ついたち） 1일
一日（いちにち） 하루
```

같은 一日도 날짜인지 기간인지에 따라 읽기가 달라진다. 숫자 한자는 글자보다 단어와 함께 외우자.


## 10일 학습 루틴

| 기간   | 학습 내용                  |
| ------ | -------------------------- |
| 1일차  | 숫자 1~5, 예시 단어 5개    |
| 2일차  | 숫자 6~10, 숫자 발음 복습  |
| 3일차  | 시간·날짜 1~5              |
| 4일차  | 시간·날짜 6~10             |
| 5일차  | 사람·학습 1~5              |
| 6일차  | 사람·학습 6~10             |
| 7일차  | 자연·방향 1~5              |
| 8일차  | 자연·방향 6~10             |
| 9일차  | 기본 동작 1~5              |
| 10일차 | 기본 동작 6~10과 전체 복습 |

매일 다음 순서로 공부한다.

```text
① 한자를 보고 뜻 말하기
② 예시 단어를 소리 내어 읽기
③ 단어를 가리고 한자로 다시 쓰기
④ 짧은 문장 하나 만들기
```

## 마무리

기초 한자의 목표는 50자를 완벽하게 암기하는 것이 아니다.  
毎日, 学校, 日本語, 読む처럼 **실제로 자주 만나는 단어를 읽을 수 있게 되는 것**이 첫 번째 목표다.

한자 하나에 여러 읽기가 있다는 사실에 겁먹지 말자. 처음에는 대표 단어 하나를 확실히 익히고, 새로운 단어를 만날 때마다 읽기를 조금씩 확장하면 된다.
