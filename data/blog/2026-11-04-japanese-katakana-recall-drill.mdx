[가타카나 그림 암기표](/blog/2026-06-18-japanese-katakana-visual-matching-table)로 모양을 익혔다면, 이제는 **그림 설명 없이 읽는 단계**로 넘어간다. 표를 보면 아는 것과 단어 속에서 바로 읽는 것은 다르다.

이 글의 한국어 표기는 첫 회상을 돕는 근사치다. 일본어의 길이와 리듬까지 정확히 옮기는 표기는 아니므로, 익숙해지면 가타카나만 보고 읽는다.

## 1. 시작 전 2분 진단

아래를 순서대로 읽고, 멈칫한 글자에만 표시한다. 아직 정답표를 펼치지 않는다.

> シ ツ ソ ン ク ケ ウ ワ フ ラ ヌ ス ナ メ

<details>
<summary>읽기 확인</summary>

시 / 쓰 / 소 / 응 / 쿠 / 케 / 우 / 와 / 후 / 라 / 누 / 스 / 나 / 메

ン은 독립된 한국어 ‘응’과 언제나 같은 발음은 아니다. 여기서는 글자를 식별하기 위한 이름표로만 사용한다.

</details>

맞힌 글자까지 처음부터 반복하지 않는다. **틀림·느림·안정** 세 칸으로 나누고 틀림과 느림부터 연습한다. 아래 시간 기준은 개인 연습용이지 공인 숙련도 기준은 아니다.

- 틀림: 다른 글자로 읽거나 읽지 못함
- 느림: 맞혔지만 약 2초 이상 망설임
- 안정: 바로 읽고 비슷한 글자와의 차이도 설명함

## 2. 혼동 글자는 따로가 아니라 나란히

| 대조 | 확인할 모양 | 바로 읽을 단어 |
| --- | --- | --- |
| シ / ツ | シ는 짧은 획이 위아래로 놓이고 긴 획이 아래쪽에서 오른쪽 위로 향한다. ツ는 짧은 획이 좌우로 놓이고 긴 획이 위쪽에서 왼쪽 아래로 내려온다. | システム / ツアー |
| ソ / ン | ソ의 긴 획은 위에서 왼쪽 아래로, ン의 긴 획은 아래에서 오른쪽 위로 향한다. | ソース / パン |
| ク / ケ | ケ는 윗부분의 가로획을 확인한다. | クラス / ケーキ |
| ウ / ワ | ウ는 맨 위의 짧은 획이 하나 더 있다. | ウイルス / ワイン |
| フ / ラ | ラ는 위쪽에 별도의 짧은 가로획이 있다. | ファイル / ラベル |
| ヌ / ス | ヌ는 안쪽의 교차를, ス는 오른쪽 아래로 뻗는 획을 확인한다. | カヌー / スキー |
| ナ / メ | ナ는 가로획이 눈에 띄고, メ는 두 사선이 교차한다. | ナイフ / メモ |

서체에 따라 기울기와 끝 모양은 달라진다. 화면의 경사만 외우지 말고 **표준 획순을 따라 크게 한 번 써 본 뒤** 인쇄체에서 다시 구별한다.

### 30초 대조 훈련

1. `シ ツ シ ツ` → `ソ ン ソ ン`을 읽는다.
2. 종이에 `シ ツ ソ ン`을 쓰고 각각 긴 획의 진행 방향을 표시한다.
3. 순서를 섞어 `ン ツ ソ シ`를 읽는다.
4. 틀린 쌍만 다시 한다. 처음부터 46자를 반복하지 않는다.

## 3. 글자를 알아도 단어가 안 읽히는 이유

### 장음 ー: 앞 모음을 한 박 더

- コーヒー: コ・ー・ヒ・ー, 네 박
- スーパー: ス・ー・パ・ー, 네 박
- メール: メ・ー・ル, 세 박

`ー`를 무시하고 읽지 않는다. 손가락으로 박을 짚으면 길이 차이를 확인하기 쉽다.

### 촉음 ッ: 작은 글자도 한 박

- チケット: チ・ケ・ッ・ト, 네 박
- ネット: ネ・ッ・ト, 세 박
- バッグ: バ・ッ・グ, 세 박

작은 ッ를 큰 ツ처럼 ‘쓰’라고 읽지 않는다. 뒤 자음으로 넘어가기 전에 한 박의 막힘을 둔다.

### 작은 ャ・ュ・ョ와 외래어 조합

- シャツ: シャ・ツ, 두 박. シヤツ처럼 세 박으로 쪼개지 않는다.
- ニュース: ニュ・ー・ス, 세 박
- ファイル: ファ・イ・ル, 세 박
- チェック: チェ・ッ・ク, 세 박

### 탁점·반탁점

`カ→ガ`, `サ→ザ`, `タ→ダ`, `ハ→バ→パ`처럼 기본 글자와 부호를 함께 본다. 예를 들어 バッグ는 ハック와 같은 글자가 아니다.

## 4. 실전 단어 24개 — 답을 가리고 읽기

뜻을 아는지보다 **글자를 빠뜨리지 않고 읽는지** 먼저 확인한다.

| 단어 | 읽기 보조 | 뜻 |
| --- | --- | --- |
| システム | 시스테무 | 시스템 |
| ツアー | 쓰아아 | 투어 |
| ソース | 소오스 | 소스·출처(문맥에 따라) |
| パン | 판 | 빵 |
| クラス | 쿠라스 | 클래스·반 |
| ケーキ | 케에키 | 케이크 |
| ウイルス | 우이루스 | 바이러스 |
| ワイン | 와인 | 와인 |
| ファイル | 화이루 | 파일 |
| ラベル | 라베루 | 라벨 |
| カヌー | 카누우 | 카누 |
| スキー | 스키이 | 스키 |
| ナイフ | 나이후 | 나이프 |
| メモ | 메모 | 메모 |
| コーヒー | 코오히이 | 커피 |
| スーパー | 스우파아 | 슈퍼마켓 |
| メール | 메에루 | 이메일 |
| チケット | 치켓토 | 티켓 |
| ネット | 넷토 | 인터넷·망 |
| バッグ | 박구 | 가방 |
| シャツ | 샤쓰 | 셔츠 |
| ニュース | 뉴우스 | 뉴스 |
| チェック | 첵쿠 | 확인·체크 |
| パソコン | 파소콘 | 개인용 컴퓨터 |

한국어 근사 표기의 ‘화’는 ファ의 정확한 발음 표기가 아니다. 영어 철자를 떠올려 추측하기보다 일본어 표기 자체를 읽는 연습을 한다.

## 5. 마지막 테스트 — 문장에서 읽기

다음 문장을 소리 내어 읽은 뒤 가타카나 부분의 뜻을 말한다.

1. メールをチェックします。
2. ファイルをコピーします。
3. システムのエラーを確認します。
4. コンビニでコーヒーを買います。
5. ニュースを見ます。

<details>
<summary>정답과 확인 포인트</summary>

1. 이메일을 확인합니다. メール의 장음, チェック의 작은 ェ와 ッ.
2. 파일을 복사합니다. ファ는 한 박, コピー는 コ・ピ・ー.
3. 시스템 오류를 확인합니다. シ와 ツ를 구별하고 エラー의 장음을 유지한다.
4. 편의점에서 커피를 삽니다. コンビニ의 ン과 탁점, コーヒー의 장음 두 곳.
5. 뉴스를 봅니다. ニュ는 한 박이고 ニュース는 세 박이다.

</details>

## 6. 7일 복습 루틴

하루 10분을 상한으로 둔다. 날짜 간격은 실천을 위한 제안이며 누구에게나 최적이라는 뜻은 아니다.

| 시점 | 할 일 | 남길 기록 |
| --- | --- | --- |
| 오늘 | 혼동 글자 진단 + 단어 24개 | 틀린 글자·단어 |
| 다음 날 | 정답을 가리고 같은 단어 읽기 | 틀림 / 느림 / 안정 |
| 3일 뒤 | 단어 순서를 섞고 문장 5개 읽기 | 다시 틀린 항목 |
| 7일 뒤 | 글자·단어·문장 순서로 재시험 | 최초 오답 중 남은 항목 |

오답은 `システム → ツ로 읽음 → シ/ツ 대조 후 다시 읽기`처럼 **문제·실수·수정 행동**을 한 줄로 적는다.

종료 기준은 “표를 한 번 다 봄”이 아니다. 연습용 목표로 **24개 중 22개 이상을 도움 없이 읽고, 틀린 단어를 다음 날 다시 맞히기**를 잡는다. 읽기 속도를 올리더라도 장음·촉음을 생략하지 않는다.
