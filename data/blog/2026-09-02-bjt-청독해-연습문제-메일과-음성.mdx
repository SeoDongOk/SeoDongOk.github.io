청독해는 음성만 듣거나 문서만 읽는 문제가 아니다. 두 정보가 합쳐져야 최종 답을 낼 수 있다. 문서를 먼저 훑어 **제목·날짜·금액·상태**를 확인하고 음성을 듣는다.

## 예시 문제

**문서**

> システムメンテナンスのお知らせ  
> 9月3日（木）22:00〜24:00

**음성**

> 作業時間が延びる可能性があるため、終了予定を午前1時に変更します。

**질문:** 올바른 종료 예정 시간은?

1. 22시
2. 24시
3. 다음 날 오전 1시
4. 다음 날 오전 2시

**정답: 3**

문서의 기존 정보는 24시였지만 음성에서 `変更します`라고 수정했다. BJT에서는 **기존 정보와 새 정보의 충돌**이 자주 나오는 유형으로 연습할 수 있다.

## 빠른 처리 순서

1. 문서에서 고유명사·숫자·부정 표현에 표시한다.
2. 음성에서 `変更`, `追加`, `中止`, `延期`를 들으면 해당 부분을 갱신한다.
3. 마지막 문장의 결론과 행동 주체를 확인한다.
4. 보기에 문서의 옛 정보가 있으면 먼저 의심한다.

## 자주 나오는 연결 표현

| 표현     | 기능             |
| -------- | ---------------- |
| なお     | 추가 안내        |
| ただし   | 예외·제한        |
| そのため | 원인에 따른 결과 |
| 一方     | 대조             |
| 改めて   | 다시 안내·재공지 |

청독해 연습에서는 정답을 맞힌 뒤에도 “문서의 어느 단어와 음성의 어느 표현을 연결했는가”를 말해보자. 이 설명 과정이 실전 처리 속도를 높인다.
