> 이 글은 학습용 정리이며 투자 권유가 아니다. 자동매매는 손실 위험이 크므로 반드시 데모 계정과 소액 검증을 먼저 거쳐야 한다.

MT5는 **MetaTrader 5**의 줄임말이다. 전 세계 여러 브로커가 제공하는 트레이딩 플랫폼이고, 외환(FX), CFD, 지수, 원자재, 일부 주식·선물 상품 거래에 사용된다. 핵심은 단순 차트 프로그램이 아니라 **주문, 차트 분석, 자동매매, 백테스트를 한 번에 다룰 수 있는 플랫폼**이라는 점이다.

MT5 자동매매를 이해하려면 먼저 아래 네 가지를 구분해야 한다.

| 용어       | 의미                                                         |
| ---------- | ------------------------------------------------------------ |
| MT5 터미널 | PC에 설치해서 차트, 주문, 계좌, 자동매매를 실행하는 프로그램 |
| 브로커     | 실제 계좌와 호가, 주문 체결을 제공하는 회사                  |
| EA         | Expert Advisor. MT5 안에서 돌아가는 자동매매 프로그램        |
| MQL5       | EA와 지표를 만드는 MT5 전용 프로그래밍 언어                  |

## MT5 자동매매란?

MT5에서 자동매매는 사람이 직접 매수·매도 버튼을 누르는 대신, 프로그램이 정해진 규칙에 따라 주문을 내는 방식이다.

예를 들면 이런 규칙을 만들 수 있다.

```text
1. EURUSD 5분봉을 본다.
2. 단기 이동평균이 장기 이동평균을 위로 돌파하면 매수한다.
3. 손절은 진입가에서 -0.5%, 익절은 +1.0%에 둔다.
4. 이미 포지션이 있으면 새로 진입하지 않는다.
```

이 규칙을 사람이 매번 확인하면 수동매매이고, EA나 Python 프로그램이 대신 실행하면 자동매매다.

## MT5 자동매매의 기본 구조

전체 흐름은 보통 아래와 같다.

```text
시장 데이터 수신
→ 전략 조건 계산
→ 진입/청산 판단
→ 주문 전송
→ 체결 결과 확인
→ 포지션/손익 관리
→ 로그 기록
```

여기서 초보자가 가장 많이 착각하는 부분은 “전략 조건”만 만들면 끝이라고 생각하는 것이다. 실제 자동매매는 전략보다 **주문, 리스크 관리, 장애 대응**이 더 중요하다.

## EA 방식과 Python 방식

MT5 자동매매는 크게 두 가지 방식으로 접근할 수 있다.

### 1. EA 방식

EA는 MT5 내부에서 실행되는 자동매매 프로그램이다. MQL5로 작성하고, 차트에 붙여서 실행한다.

장점:

- MT5에 기본 통합되어 있다.
- Strategy Tester로 백테스트하기 좋다.
- VPS에서 24시간 돌리기 쉽다.
- 주문 처리 구조가 MT5에 맞게 설계되어 있다.

단점:

- MQL5 문법을 배워야 한다.
- Python 생태계의 데이터 분석 라이브러리를 바로 쓰기는 어렵다.

### 2. Python 연동 방식

Python의 `MetaTrader5` 패키지를 사용해 MT5 터미널과 연결하는 방식이다. Python에서 시세를 가져오고 주문도 보낼 수 있다.

장점:

- pandas, numpy, scikit-learn 같은 데이터 분석 도구를 쓰기 좋다.
- 기존 Python 자동매매 코드와 연결하기 쉽다.
- 전략 실험 속도가 빠르다.

단점:

- MT5 터미널이 실행 중이어야 한다.
- 백테스트는 직접 구현하거나 별도 도구를 써야 한다.
- 운영 안정성은 직접 챙겨야 한다.

## MT5를 처음 배우는 순서

아예 처음이라면 아래 순서를 추천한다.

1. MT5 설치
2. 데모 계정 연결
3. 관심 종목 차트 열기
4. 수동으로 시장가/지정가/손절/익절 주문 넣어보기
5. Strategy Tester에서 기본 EA 실행해보기
6. 아주 단순한 EA 또는 Python 조회 스크립트 만들어보기
7. 데모 계정에서 최소 2~4주 이상 관찰하기
8. 실계좌는 소액으로만 시작하기

자동매매는 코딩보다 먼저 “내가 어떤 주문을 보내는지”를 이해해야 한다. 주문 타입, 스프레드, 슬리피지, 레버리지, 증거금, 손절가가 무엇인지 모르면 봇이 정상 동작해도 계좌가 위험해질 수 있다.

## MT5에서 자주 보는 화면

| 화면            | 역할                              |
| --------------- | --------------------------------- |
| Market Watch    | 거래 가능한 종목과 호가 확인      |
| Chart           | 차트와 지표 확인                  |
| Navigator       | 계좌, 지표, EA 목록 확인          |
| Toolbox         | 주문, 포지션, 로그, 거래내역 확인 |
| MetaEditor      | MQL5 코드 작성                    |
| Strategy Tester | EA 백테스트 및 최적화             |

처음에는 기능이 많아 보이지만, 자동매매 관점에서는 `차트`, `Navigator`, `Toolbox`, `Strategy Tester` 네 가지만 먼저 익혀도 충분하다.

## 자동매매에서 가장 중요한 위험 요소

MT5 자동매매를 시작할 때 아래 항목은 반드시 체크해야 한다.

- 데모 계정과 실계좌의 체결 환경은 다를 수 있다.
- 스프레드가 넓어지는 시간에는 손익이 크게 달라질 수 있다.
- 백테스트 수익이 실전 수익을 보장하지 않는다.
- 과최적화된 전략은 실전에서 쉽게 무너진다.
- 손절 없는 자동매매는 한 번의 사고로 계좌를 크게 훼손할 수 있다.
- VPS, 인터넷, 브로커 서버 장애도 리스크다.

## 정리

MT5는 자동매매를 하기 위한 완성형 플랫폼에 가깝다. EA, MQL5, Strategy Tester, Python 연동까지 지원하므로 초보자도 시작할 수 있다.

하지만 자동매매의 본질은 “돈을 벌어주는 프로그램”이 아니라 **정해진 규칙을 감정 없이 반복 실행하는 시스템**이다. 규칙이 나쁘면 자동으로 돈을 잃는 속도도 빨라진다.
