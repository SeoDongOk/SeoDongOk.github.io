BJT 독해는 어려운 한자를 많이 아는 것보다 **표현이 요구하는 행동**을 읽는 것이 중요하다.

## 업무 표현 6개

| 표현                         | 실제 의미               |
| ---------------------------- | ----------------------- |
| ご確認いただけますでしょうか | 확인해 주세요           |
| ご対応のほどお願いいたします | 대응해 주세요           |
| 差し支えなければ             | 문제가 없다면           |
| 恐れ入りますが               | 죄송하지만 부탁드립니다 |
| お手数をおかけしますが       | 번거롭지만 부탁드립니다 |
| 取り急ぎご報告いたします     | 우선 급히 보고합니다    |

`取り急ぎ`는 보고가 완결됐다는 뜻이 아니라, 우선 상황을 공유한다는 뉘앙스다. 뒤에 상세 보고가 이어질 수 있다.

## 예시 문제

> 恐れ入りますが、添付ファイルをご確認のうえ、金曜日までにご返信いただけますでしょうか。

**질문:** 상대방에게 요구하는 행동은?

1. 파일을 삭제한다
2. 파일을 확인하고 금요일까지 답장한다
3. 금요일에 회의에 참석한다
4. 새 파일을 만든다

**정답: 2**

`〜のうえ`는 “~한 후에”라는 순서를 만든다. 먼저 확인하고, 그다음 답장해야 한다.

## 거절을 부드럽게 읽기

> 今回は見送らせていただければと存じます。

이는 “이번에는 진행하지 않겠습니다”라는 정중한 거절이다. `〜と思います`처럼 약한 의견으로만 읽으면 안 된다. 메일의 제목과 앞뒤 문장을 함께 보고 **결정인지 검토 중인지** 판단한다.

독해 문제를 풀 때는 문장을 한국어로 전부 번역하기보다, 주체·기한·요청 행동을 표시하자.
