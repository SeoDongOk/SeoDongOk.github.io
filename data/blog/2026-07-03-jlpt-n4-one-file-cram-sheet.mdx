| 항목          | 기준                       |
| ------------- | -------------------------- |
| 총점          | **90 / 180 이상**          |
| 언어지식·독해 | **38 / 120 이상** (과락선) |
| 청해          | **19 / 60 이상** (과락선)  |

### D-3 전략 (우선순위)

1. **청해 과락(19/60)만은 절대 피한다** → §8 정형표현·즉시응답 페어 암기. 청해는 반만 맞아도 30점.
2. **문자·어휘가 가성비 최고** → §5 한자 + §6 가타카나 + §7 부사. 아는 만큼 그대로 점수.
3. **문장만들기(★ 문제)는 조사가 답** → §2 조사 + 문형 접속만 알면 퍼즐처럼 풀림. ★에 들어갈 것을 찾는 문제 = 4칸 전체를 먼저 조립하고 3번째 칸 확인.
4. **독해는 접속사 싸움** → それで(그래서)・しかし(그러나)・だから(그러니까)・ところが(그런데) + のに/ので 구분이 반은 먹고 들어감.
5. 모르는 문제는 **일단 마킹하고 넘어가기**. N4는 시간이 빠듯하지 않지만 한 문제에 매몰되면 끝장.

## 1. 동사 활용 총정리

N4 문법의 8할은 동사 변형이다. **가능형·의지형·조건형·수동·사역**이 N4에서 새로 나온다.

### 1.1 동사 그룹 구분 (10초 판별법)

| 그룹               | 판별법                                                                         | 예                               |
| ------------------ | ------------------------------------------------------------------------------ | -------------------------------- |
| **1그룹 (五段)**   | う단으로 끝남 (う·く·ぐ·す·つ·ぬ·ぶ·む·る). る로 끝나면 る 앞이 **あ·う·お단** | 書く, 飲む, 作る(つくる), 分かる |
| **2그룹 (一段)**   | る로 끝나고 る 앞이 **い단·え단**                                              | 食べる, 見る, 起きる, 寝る       |
| **3그룹 (불규칙)** | 딱 2개                                                                         | する, 来る(くる)                 |

#### ⚠️ 겉모습은 2그룹, 실제는 1그룹 (시험 단골!)

**帰る(かえる 돌아가다)・入る(はいる 들어가다)・走る(はしる 달리다)・切る(きる 자르다)・知る(しる 알다)・要る(いる 필요하다)・減る(へる 줄다)・しゃべる(수다떨다)**

→ 전부 1그룹! 帰る→帰**って**(○) / 帰て(×), 入る→入**れば**, 切る→切**らない**

### 1.2 て형 / た형 변환 룰 (같은 룰)

| 어미       | て형            | た형           | 예                                    |
| ---------- | --------------- | -------------- | ------------------------------------- |
| く         | 〜いて          | 〜いた         | 書く→書いて / 書いた                  |
| ぐ         | 〜いで          | 〜いだ         | 泳ぐ→泳いで / 泳いだ                  |
| す         | 〜して          | 〜した         | 話す→話して / 話した                  |
| う・つ・る | 〜って          | 〜った         | 買う→買って, 待つ→待って, 作る→作って |
| ぬ・ぶ・む | 〜んで          | 〜んだ         | 死ぬ→死んで, 遊ぶ→遊んで, 飲む→飲んで |
| 2그룹      | る떼고+て       | +た            | 食べて / 食べた, 見て / 見た          |
| 3그룹      | して, 来(き)て  | した, 来(き)た | —                                     |
| **예외**   | 行く→**行って** | 行った         | ※「行いて」아님!                      |

### 1.3 N4 신규 변형 7종 — 만드는 법

#### ① 가능형 (できる形) — "~할 수 있다"

| 그룹  | 규칙                                   | 예                                    |
| ----- | -------------------------------------- | ------------------------------------- |
| 1그룹 | う단 → **え단 + る**                   | 書く→書ける, 飲む→飲める, 話す→話せる |
| 2그룹 | る → **られる**                        | 食べる→食べられる, 見る→見られる      |
| 3그룹 | する→**できる**, 来る→**来(こ)られる** | —                                     |

- ⚠️ **조사가 を → が로 바뀜**: 漢字**を**読む → 漢字**が**読める
- 회화에선 ら抜き(食べれる)도 쓰지만 **시험 답은 반드시 られる**
- 가능형은 전부 **2그룹 활용**이 됨: 書ける→書けます, 書けない, 書けた

#### ② 의지형 (意向形) — "~하자 / ~해야지"

| 그룹  | 규칙                 | 예                                    |
| ----- | -------------------- | ------------------------------------- |
| 1그룹 | う단 → **お단 + う** | 行く→行こう, 飲む→飲もう, 待つ→待とう |
| 2그룹 | る → **よう**        | 食べる→食べよう, 見る→見よう          |
| 3그룹 | しよう, 来(こ)よう   | —                                     |

- **〜(よ)うと思(おも)っています**: ~하려고 생각하고 있어요 (N4 초빈출!)
  - 夏休みに日本へ行こうと思っています。(여름방학에 일본에 가려고 생각하고 있어요.)

#### ③ 명령형 & 금지형

| 형태            | 규칙                     | 예                           |
| --------------- | ------------------------ | ---------------------------- |
| 명령형 1그룹    | う단→**え단**            | 行け! 書け! 待て!            |
| 명령형 2그룹    | る→**ろ**                | 食べろ! 見ろ!                |
| 명령형 3그룹    | しろ, 来(こ)い           | —                            |
| 금지형 (전그룹) | **사전형 + な**          | 行くな! (가지 마!) 見るな!   |
| 부드러운 명령   | **ます형 어간 + なさい** | 早く寝なさい。(빨리 자거라.) |

#### ④ 조건 ば형 — "~하면"

| 품사      | 규칙               | 예                               |
| --------- | ------------------ | -------------------------------- |
| 1그룹     | う단→**え단+ば**   | 行く→行けば, 飲む→飲めば         |
| 2그룹     | る→**れば**        | 食べる→食べれば                  |
| 3그룹     | すれば, 来(く)れば | —                                |
| い형용사  | い→**ければ**      | 安い→安ければ, いい→**よければ** |
| 부정형    | ない→**なければ**  | 行かない→行かなければ            |
| 명사·な형 | **なら(ば)**       | 学生なら, ひまなら               |

#### ⑤ 수동형 (受身形) — "~당하다 / ~되다"

| 그룹                 | 규칙                             | 예                           |
| -------------------- | -------------------------------- | ---------------------------- |
| 1그룹                | う단 → **あ단 + れる**           | 書く→書かれる, 読む→読まれる |
| 1그룹 う로 끝나는 것 | う → **われる**                  | 言う→言われる, 笑う→笑われる |
| 2그룹                | る → **られる** (가능형과 동형!) | 食べる→食べられる            |
| 3그룹                | される, 来(こ)られる             | —                            |

- 기본 수동: 先生に**ほめられました**。(선생님께 칭찬받았어요.)
- **피해 수동(迷惑の受身)** — N4 단골: 남의 행동으로 내가 피해봄
  - 雨に**降られて**、服が濡れた。(비를 맞아서 옷이 젖었다.)
  - 隣の人に足を**踏まれた**。(옆 사람에게 발을 밟혔다.)
- 존경 표현으로도 씀: 先生はもう**帰られました**。(선생님은 벌써 돌아가셨습니다.)

#### ⑥ 사역형 (使役形) — "~하게 시키다 / ~하게 해주다"

| 그룹  | 규칙                   | 예                           |
| ----- | ---------------------- | ---------------------------- |
| 1그룹 | う단 → **あ단 + せる** | 行く→行かせる, 読む→読ませる |
| 2그룹 | る → **させる**        | 食べる→食べさせる            |
| 3그룹 | させる, 来(こ)させる   | —                            |

- 강제: 母は弟に野菜を**食べさせた**。(엄마는 남동생에게 야채를 먹였다.)
- 허가: 子どもを公園で**遊ばせた**。(아이를 공원에서 놀게 했다.)
- **〜させてください**: ~하게 해주세요 (겸손한 부탁, 초빈출!)
  - すみません、今日は早く**帰らせてください**。(죄송하지만 오늘은 일찍 가게 해주세요.)

#### ⑦ 사역수동 (억지로 ~하게 됨)

- 만들기: 사역형 → 수동형. 行かせる→行かせ**られる**, 食べさせる→食べさせ**られる**
- 1그룹 축약형: 行か**される**, 飲ま**される**
- 私は母に野菜を**食べさせられた**。(나는 엄마가 시켜서 억지로 야채를 먹었다.)

### 1.5 자동사 vs 타동사 빈출 쌍 (표기·문법 양쪽 단골 ⭐⭐⭐)

> 💡 패턴 감각: **〜まる(자) ↔ 〜める(타)**, **〜あ단+る(자) ↔ 〜え단+る(타)** 가 많다.

#### 「〜ている」 vs 「〜てある」 (문법문제 초단골)

| 문장                                   | 뉘앙스                                |
| -------------------------------------- | ------------------------------------- |
| 窓**が**開いて**いる** (자동사+ている) | 창문이 열려 있다 (그냥 상태)          |
| 窓**が**開けて**ある** (타동사+てある) | 창문이 (누군가 일부러) 열어 둔 상태다 |
| 窓**を**開けて**おく** (타동사+ておく) | 창문을 (미리) 열어 두다 (행위)        |

## 2. 조사 총정리

문장만들기(★)와 문법형식판단의 핵심. **뜻이 아니라 "어떤 동사·상황과 세트인가"로 외운다.**

### 2.1 기본 조사 한 방 정리

| 조사        | 핵심 용법                           | 예문                                                                                            |
| ----------- | ----------------------------------- | ----------------------------------------------------------------------------------------------- |
| は          | 주제 / 대조                         | 私**は**学生です。/ 肉は食べるが、魚**は**食べない。                                            |
| が          | 신정보 주어 / 의문사 주어 / 대상    | 誰**が**来ましたか。/ 日本語**が**分かる・できる・好きだ・上手だ・ほしい                        |
| を          | 목적어 / 통과·출발 지점             | パンを食べる / 公園**を**散歩する / 家**を**出る / バス**を**降りる                             |
| に          | 존재장소·시각·도착점·상대·목적·빈도 | 部屋**に**いる / 7時**に** / 駅**に**着く / 友達**に**会う / 買い**に**行く / 週**に**2回       |
| で          | 동작장소·수단·재료·이유·범위·합계   | 図書館**で**勉強 / バス**で** / 木**で**作る / 病気**で**休む / 世界**で**一番 / 全部**で**千円 |
| へ          | 방향                                | 日本**へ**行く                                                                                  |
| と          | 함께 / 인용 / 그리고(전부 나열)     | 友達**と** / 「はい」**と**言う / パン**と**牛乳                                                |
| や          | 나열(일부, ~など와 세트)            | パン**や**牛乳など                                                                              |
| から / まで | 부터 / 까지(계속)                   | 9時**から**5時**まで**                                                                          |
| より        | 비교 (~보다)                        | バス**より**電車のほうが速い                                                                    |
| も          | ~도 / 수량 강조(많음)               | 私**も** / 3時間**も**待った                                                                    |
| か          | 의문 / ~인지                        | 行く**か**どうか分かりません                                                                    |
| の          | 소유 / 명사화 / ~의 것              | 私**の**本 / 走る**の**が好きだ / それは私**の**です                                            |

### 2.2 N4 포인트 조사 (여기서 나온다 ⭐⭐⭐)

| 조사               | 뜻 & 규칙                   | 예문                                             |
| ------------------ | --------------------------- | ------------------------------------------------ |
| **しか + 부정**    | ~밖에 없다 (반드시 부정문!) | お金が100円**しか**ありません。                  |
| **だけ**           | ~만 (긍정 OK)               | 一つ**だけ**ください。                           |
| **ばかり**         | ~만, ~뿐 (편중·불만 뉘앙스) | 弟はゲーム**ばかり**しています。                 |
| **までに**         | ~까지 (기한, 1회 동작)      | 5時**までに**帰ってください。                    |
| **まで**           | ~까지 (계속)                | 5時**まで**勉強します。                          |
| **でも** ①         | ~라도 (가벼운 예시·권유)    | お茶**でも**飲みませんか。                       |

| 의문사+**でも**    | 전부 긍정                   | 誰**でも** / 何**でも** / いつ**でも** OK        |

| 의문사+**も**+부정 | 전부 부정                   | 何**も**食べていません。/ どこへ**も**行かない。 |
| **とか〜とか**     | ~라든가 (구어 나열)         | 寿司**とか**ラーメン**とか**                     |
| **など**           | ~등                         | 野菜**など**を買った。                           |
| **し**             | ~고 (나열+이유 겹침)        | 安い**し**、おいしい**し**、よく行きます。       |
| **のに**           | ~인데도 (역접+의외·유감)    | 薬を飲んだ**のに**、治らない。                   |
| **ので**           | ~이므로 (객관·정중한 이유)  | 頭が痛い**ので**、帰ります。                     |

### 2.3 헷갈림 최종 비교 (시험 직전 1분 체크)

- **に vs で**: 있다/살다/도착 → **に** (いる・ある・住む・着く) / 뭔가 한다 → **で** (食べる・勉強する・会議する)
  - ⚠️ 예외 세트로 암기: 「〜**に**住んでいます」「いす**に**座る」「電車**に**乗る」
- **が 나오는 술어 세트**: 好き・嫌い・上手・下手・ほしい・分かる・できる・見える・聞こえる・要る → 전부 **が**
- **は vs が**: 의문사가 주어면 무조건 が (誰**が**?), 대답도 が. 이미 아는 화제면 は.
- **に vs から (받다)**: もらう・借りる・習う는 「人**に**」「人**から**」 둘 다 OK. 단, 회사·학교 같은 기관이면 **から**만.
- **を 쓰는 이동동사**: 散歩する・歩く・走る・飛ぶ(통과) / 出る・降りる(출발·이탈) → 場所**を**

## 3. N4 핵심 문법

문법형식판단에 나오는 문형을 계열별로 정리. **접속(앞에 무슨 형이 오는지)이 곧 답**이다.

### 3.1 て형 계열 (최대 세력)

| 문형                     | 뜻                                                     | 예문                                                          |
| ------------------------ | ------------------------------------------------------ | ------------------------------------------------------------- |
| 〜ている                 | ~하고 있다 / 상태                                      | 結婚して**いる**(기혼 상태), 知って**いる** ⚠️부정은 知らない |
| 〜てある                 | (누가) ~해 둔 상태                                     | ビールが冷やして**ある**。                                    |
| 〜ておく                 | 미리 ~해두다 (회화: 〜とく)                            | ホテルを予約して**おきます**。                                |
| 〜てみる                 | ~해 보다                                               | この服を着て**みて**もいいですか。                            |
| 〜てしまう               | 다 ~해버리다 / ~해버렸다(유감) (회화: 〜ちゃう/じゃう) | 財布を忘れて**しまいました**。                                |
| 〜ていく                 | ~해 가다 (멀어짐/앞으로)                               | これから寒くなって**いく**でしょう。                          |
| 〜てくる                 | ~해 오다 (다가옴/지금까지)                             | 雨が降って**きた**。/ 買って**きます**。                      |
| 〜てもいい               | ~해도 된다                                             | ここで写真を撮って**もいいですか**。                          |
| 〜てはいけない           | ~하면 안 된다 (회화: 〜ちゃだめ)                       | ここに車を止めて**はいけません**。                            |
| 〜てから                 | ~하고 나서                                             | 手を洗って**から**食べます。                                  |
| 〜てくれる/あげる/もらう | §3.5 수수동사 참고                                     | —                                                             |
| 〜てほしい               | ~해 줬으면 좋겠다                                      | 早く来て**ほしい**です。                                      |

| 문형                                    | 뜻                                     | 예문                                                               |
| --------------------------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| 〜たことがある                          | ~한 적이 있다 (경험)                   | 日本へ行っ**たことがあります**。                                   |

| 〜たほうがいい                          | ~하는 편이 좋다 (충고)                 | 早く寝**たほうがいい**ですよ。                                     |
| 〜ないほうがいい                        | ~하지 않는 편이 좋다                   | お酒は飲ま**ないほうがいい**。                                     |
| 〜たあとで                              | ~한 후에                               | ご飯を食べ**たあとで**、散歩します。⚠️ 명사는 「명사**の**あとで」 |

### 3.3 추측·전문 4대장 (⭐⭐⭐ 반드시 구분)

| 문형            | 뜻                                              | 접속                                                  | 예문                                              |
| --------------- | ----------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------- |
| **そうだ①양태** | ~할 것 같다, ~해 보인다 (눈으로 본 인상)        | **ます형 어간**+そうだ / 형용사 어간+そうだ           | 雨が降り**そうだ**。/ このケーキ、おいし**そう**! |
| **そうだ②전문** | ~라고 한다 (들은 것 그대로)                     | **보통형**+そうだ                                     | 天気予報によると、明日は雨が降る**そうだ**。      |
| **ようだ**      | ~인 것 같다 (관찰·근거 있는 추측) / ~같다(비유) | 보통형+ようだ / 명사**の**+ようだ / な형**な**+ようだ | 誰もいない**ようだ**。/ 雪**のように**白い。      |
| **みたいだ**    | ようだ의 회화체                                 | 명사에 직접 붙음                                      | 子ども**みたい**だね。                            |
| **らしい**      | ~인 것 같다 (전해들은 근거) / ~답다             | 보통형+らしい / 명사+らしい                           | あの店はおいしい**らしい**。/ 男**らしい**。      |

- 양태 そうだ의 예외: いい→**よさそう**, ない→**なさそう**
- 양태 부정: 降りそう**もない**/そう**にない**

| 문형           | 뜻                                | 예문                                               |
| -------------- | --------------------------------- | -------------------------------------------------- |
| 〜かもしれない | ~일지도 모른다 (50%)              | 明日は雨**かもしれません**。                       |
| 〜はずだ       | (논리적으로) ~일 것이다           | 田中さんは今日来る**はずです**。約束しましたから。 |
| 〜はずがない   | ~일 리가 없다                     | 彼がうそをつく**はずがない**。                     |
| 〜でしょう     | ~겠지요 (추측) / ~잖아요?(확인↗) | 明日は晴れる**でしょう**。                         |

### 3.4 조건 4형제 (と・ば・たら・なら)

| 형태     | 핵심 감각                           | 예문                                                           | 주의                            |
| -------- | ----------------------------------- | -------------------------------------------------------------- | ------------------------------- |
| **と**   | ~하면 반드시 (자연법칙·기계·길안내) | 春になる**と**、花が咲く。/ ボタンを押す**と**、切符が出ます。 | 뒤에 의지·명령·권유 **불가**    |
| **ば**   | ~하면 (가정, 아직 모름)             | 安けれ**ば**、買います。/ どうすれ**ば**いいですか。           | 속담·일반론에 강함              |
| **たら** | ~하(고 나)면 (개별·1회)             | 家に帰っ**たら**、電話します。/ 暇だっ**たら**、来てください。 | 뒤에 의지·명령 **OK**, 만능선수 |
| **なら** | (상대 말 받아서) ~라면              | A:日本へ行きます。B:日本へ行く**なら**、JRパスが便利ですよ。   | 조언·추천에 사용                |

### 3.5 수수동사 (あげる・くれる・もらう) ⭐⭐⭐

방향 감각이 전부다. **내(우리)쪽으로 들어오면 くれる/もらう, 나가면 あげる.**

| 동사   | 방향                            | 예문                                 |
| ------ | ------------------------------- | ------------------------------------ |
| あげる | 나(제3자) → 남                  | 私は友達にプレゼントを**あげた**。   |
| くれる | 남 → **나(내 가족)**            | 友達が私にプレゼントを**くれた**。   |
| もらう | 내가 받다 (주는 사람에 に/から) | 私は友達にプレゼントを**もらった**。 |

#### て형 결합 (행위를 주고받음)

| 문형       | 뜻                       | 예문                                                  |
| ---------- | ------------------------ | ----------------------------------------------------- |
| 〜てあげる | ~해 주다 (내가 남에게)   | 弟に本を読ん**であげた**。⚠️윗사람에게 직접 쓰면 실례 |
| 〜てくれる | ~해 주다 (남이 나에게)   | 友達が手伝っ**てくれた**。                            |
| 〜てもらう | ~해 받다 (부탁해서 받음) | 先生に作文を直し**てもらった**。                      |

#### 높임 버전 (경어 문제와 연동)

| 보통   | 높임 (상대가 윗사람)        |
| ------ | --------------------------- |
| あげる | さしあげる                  |
| くれる | **くださる** (くださいます) |
| もらう | **いただく**                |

- 先生が本を**くださいました**。/ 先生に本を**いただきました**。(같은 상황!)

## 4. 경어 총정리

N4 경어는 **특수 경어동사 표 + お〜になる/お〜する** 만 알면 끝. 문법·청해 양쪽에서 나온다.

### 4.1 특수 경어동사 표 (이 표가 배점 그 자체 ⭐⭐⭐)

| 보통 동사      | 존경어 (상대를 높임)        | 겸양어 (나를 낮춤)        |
| -------------- | --------------------------- | ------------------------- |
| 行く(가다)     | いらっしゃる                | 参(まい)る / 伺(うかが)う |
| 来る(오다)     | いらっしゃる / おいでになる | 参る / 伺う               |
| いる(있다)     | いらっしゃる                | おる                      |
| 食べる・飲む   | 召(め)し上(あ)がる          | いただく                  |
| 言う(말하다)   | おっしゃる                  | 申(もう)す / 申し上げる   |
| 見る(보다)     | ご覧(らん)になる            | 拝見(はいけん)する        |
| する(하다)     | なさる                      | いたす                    |
| 知っている     | ご存(ぞん)じだ              | 存じている / 存じておる   |
| 聞く・방문하다 | —                           | 伺う                      |
| 会う(만나다)   | —                           | お目(め)にかかる          |
| くれる         | くださる                    | —                         |
| あげる         | —                           | さしあげる                |
| もらう         | —                           | いただく                  |
| 寝る(자다)     | お休(やす)みになる          | —                         |
| 〜です         | —                           | 〜でございます            |
| あります       | —                           | ございます                |

- ⚠️ **활용 예외**: いらっしゃる→いらっしゃ**い**ます, おっしゃる→おっしゃ**い**ます, なさる→なさ**い**ます, くださる→くださ**い**ます (「り」가 아니라 「い」!)

### 4.2 경어 공식 (특수동사가 없을 때)

| 공식                           | 종류               | 예                                                     |
| ------------------------------ | ------------------ | ------------------------------------------------------ |
| **お+ます형 어간+になる**      | 존경               | 先生はもう**お帰りになりました**。                     |
| **〜(ら)れる** (수동형과 동형) | 존경 (가벼움)      | 社長が**来られました**。                               |
| **お+ます형 어간+ください**    | 존경 (의뢰)        | こちらに**お座りください**。/ 少々**お待ちください**。 |
| **お+ます형 어간+する**        | 겸양               | 荷物を**お持ちします**。/ ご案内**します**。           |
| **〜させていただく**           | 겸양 (허락받아 함) | 発表**させていただきます**。                           |

### 4.3 회화 정형 경어 (청해 즉시응답 단골)

| 표현                                            | 뜻 / 쓰는 상황                     |
| ----------------------------------------------- | ---------------------------------- |
| いらっしゃいませ                                | 어서 오세요 (가게)                 |
| かしこまりました                                | 알겠습니다 (점원→손님)             |
| 少々(しょうしょう)お待ちください                | 잠시만 기다려 주세요               |
| お待たせしました                                | 오래 기다리셨습니다                |
| 失礼(しつれい)します / 失礼しました             | 실례합니다 / 실례했습니다          |
| お世話(せわ)になりました                        | 신세 많이 졌습니다                 |
| よろしくお伝(つた)えください                    | 안부 전해 주세요                   |
| ご遠慮(えんりょ)なく                            | 사양 마시고                        |
| お先(さき)に失礼します → お疲(つか)れさまでした | 먼저 가보겠습니다 → 수고하셨습니다 |

### 8.2 과제이해·포인트이해 함정 패턴

1. **첫 번째 제안은 대부분 기각된다**: 「Aはどう?」「うーん、Aはちょっと…」→ 정답은 뒤에 나오는 B나 C.
2. **やっぱり가 나오면 그 뒤가 최종 결정**: 「やっぱりBにします」→ 답은 B.
3. **「〜はちょっと…」= 거절**이다. 끝까지 말 안 해도 No.
4. **「じゃあ」「それでは」뒤에 결론**이 온다. 그 앞은 다 미끼.
5. 숫자는 **반드시 메모**: 시간 변경(3時→4時半), 개수 추가(2つ→もう1つ→합계 3개), 층수(3階じゃなくて4階).
6. 순서 문제는 **まず(우선)→次に(다음에)→それから(그리고)→最後に(마지막에)** 표지어만 따라가면 됨.
7. **「〜んじゃなくて」= 앞 내용 부정**: 「月曜日じゃなくて火曜日」→ 답은 화요일.
8. 発話表現(그림 보고 말 고르기): 상황이 "부탁"인지 "허가요청"인지 "제안"인지 먼저 판단
   - 부탁: 〜てください / 〜てくれませんか
   - 허가: 〜てもいいですか
   - 제안: 〜ましょうか / 〜ませんか
