> 이 글은 기존 22편과 마지막 보강 자료를 시험장에서 사용할 판단 순서로 압축한 최종 지도다.

## 1. BJT 문제를 푸는 공통 공식

```text
장소 → 관계 → 목적 → 전환어 → 최종 상태 → 다음 행동
```

- 장소: 사무실, 회의실, 전화, 매장, 레스토랑, 공장
- 관계: 상사·부하, 동료, 자사·거래처, 직원·고객
- 목적: 보고, 요청, 확인, 변경, 거절, 사과, 협상
- 전환어: 그러나, 단, 그러면, 결국
- 최종 상태: 미정, 예정, 확정, 진행, 완료, 보류, 취소
- 다음 행동: 누가 무엇을 언제까지 하는가

## 2. 청해 최종 공식

### 장면 파악

`사람 → 행동 → 대상 → 진행/완료 상태`

### 발언 청해

`말하는 사람의 위치 → 듣는 사람 → 자연스러운 경어 → 발언 목적`

### 종합 청해

`처음 안 → 문제 → 수정안 → 최종 결정 → 담당자·기한`

### 놓쳤을 때

과거 문장을 복원하지 않고 `しかし・ただ・では・結局`부터 다시 듣는다.

## 3. 청독해 최종 공식

```text
화면의 사실 + 음성의 변경·의도 = 정답
```

- 표: 행·열·단위
- 그래프: 축·증감·비교 기준
- 광고: 기간·가격·대상·예외
- 이메일: 발신자·목적·요청·기한
- 일정표: 시간 충돌과 변경
- 결재 화면: 승인·반려·보류 상태

화면에 있는 숫자를 그대로 고르지 말고 음성에서 변경됐는지 확인한다.

## 4. 독해 최종 공식

```text
질문 먼저 → 키워드 표시 → 접속어 주변 탐색 → 근거와 선택지 대조
```

- 이유 질문: `ため・ので・から・なぜなら`
- 결론 질문: 마지막 문장, `つまり・したがって`
- 일치 질문: 범위와 부정 확인
- 다음 행동: 요청 표현과 기한 확인

지문 전체를 번역하지 않는다.

## 5. 상태 사다리

| 단계 | 표현                     |
| ---- | ------------------------ |
| 미정 | 検討する・考える         |
| 의향 | 〜つもりだ・〜たい       |
| 예정 | 〜予定だ・〜見込みだ     |
| 결정 | 決定する・〜ことになった |
| 진행 | 〜ている・実施中         |
| 완료 | 完了した・提出済み       |
| 보류 | 見送る・持ち越す         |
| 취소 | 中止する・取りやめる     |

선택지가 실제 상태보다 한 단계 앞서 있으면 오답일 가능성이 높다.

## 6. 핵심 업무 흐름

```text
作成 → 確認 → 修正 → 提出 → 承認
申請 → 承認 / 差し戻し
見積もり → 発注 → 受注 → 出荷 → 納品
発生 → 影響確認 → 原因調査 → 復旧 → 報告 → 再発防止
予約 → 確認 → 変更 / 取消
不良品 → 交換 / 返品 / 返金
```

## 7. 숫자·기한

- `まで`: 그 시점까지 계속
- `までに`: 그 시점까지 완료
- `以上・以下`: 기준 숫자 포함
- `未満・超える`: 기준 숫자 미포함
- `遅くとも`: 늦어도
- `早くても`: 빨라도
- `少なくとも`: 적어도
- `約・ほど`: 약·정도

## 8. 경어 핵심

```text
상대·상사 행동 → 존경어
나·우리 회사 행동 → 겸양어
```

- おっしゃる / 申し上げる
- いらっしゃる / 伺う・参る
- ご覧になる / 拝見する
- なさる / いたす
- 召し上がる / いただく

경어의 길이가 아니라 행동 주체가 맞는지 확인한다.

## 9. 정중한 거절 신호

- `〜かねます`: 하기 어렵습니다
- `ご要望には添いかねます`: 요청에 응하기 어렵습니다
- `難しい状況です`: 어려운 상황입니다
- `今回は見送ります`: 이번에는 보류합니다
- `検討させてください`: 즉시 수락이 아니라 검토 요청

## 10. 상황별 한 줄 목표

| 상황          | 잡아야 할 것             |
| ------------- | ------------------------ |
| 상사와 대화   | 보고 내용·지시·승인      |
| 동료·타 부서  | 담당자·업무 분담·기한    |
| 거래처        | 조건부 수락·거절·납기    |
| 회의          | 최종 채택안·보류 여부    |
| 전화          | 부재·복귀·재연락 주체    |
| 레스토랑·호텔 | 예약·인원·대체안         |
| 매장 불만     | 교환·반품·환불 조건      |
| 공장·현장     | 작업 순서·안전·장애 상태 |

## 11. 선택지 함정

- 처음 나온 정보지만 나중에 변경됨
- 단어는 맞지만 주체가 반대
- 검토를 결정으로 과장
- 일부를 전부로 확대
- 이유와 결과를 뒤집음
- 정중한 거절을 수락으로 오해
- 맞는 내용이지만 질문에 답하지 않음

## 12. 시험 직전 15분

### 5분

`検討 / 決定 / 延期 / 前倒し / 承認 / 差し戻し / 納期 / 復旧`

### 5분

`まで / までに / 以上 / 以下 / 未満 / 遅くとも / 早くても`

### 5분

상황별 공식과 경어 주체만 읽는다. 이후에는 자료를 덮는다.

## 13. 시험 중 리셋

```text
한 문제는 한 문제일 뿐이다.
모르는 단어보다 아는 근거를 찾는다.
첫 제안보다 마지막 결론을 듣는다.
완벽한 번역보다 정확한 판단을 한다.
```
