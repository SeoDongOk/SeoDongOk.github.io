## 시험 직전 빈출도

> **우선순위 S · ★★★★★**
>
> 2020년 이후 결합도·응집도의 정의, 강도 순서, 사례 식별이 반복 출제됐다.

- **최소 암기:** 결합도는 약할수록, 응집도는 강할수록 좋다. 두 강도 순서를 통째로 암기
- **5점 후보:** 결합도 강→약: 내공외제스자 / 응집도 강→약: 기순교절시논우
- **판정 기준:** 별점은 Q-Net의 공식 출제 확률이 아니다. 2020년 1회~2026년 1회 복원 목록과 2026 시나공 핵심요약의 실기 출제 이력 표기를 개념군 단위로 교차해 정한 **시험 전날 상대 우선순위**다.

결합도와 응집도는 설명을 보고 정확한 종류를 쓰는 단답형으로 반복 출제된다. 좋은 모듈은 **낮은 결합도와 높은 응집도**를 가진다.

## 1. 핵심 비교

| 개념             | 측정 대상                  | 좋은 방향 |
| ---------------- | -------------------------- | --------- |
| 결합도(Coupling) | 모듈과 모듈 사이의 의존성  | 낮게      |
| 응집도(Cohesion) | 한 모듈 내부 요소의 관련성 | 높게      |

```text
결합도는 모듈 사이
응집도는 모듈 안
```

## 2. 결합도 강도 순서

강함에서 약함 순서다.

```text
내용 → 공통 → 외부 → 제어 → 스탬프 → 자료
```

암기:

```text
내공외제스자
```

## 3. 결합도 종류

| 결합도        | 설명                                              | 식별어         |
| ------------- | ------------------------------------------------- | -------------- |
| 내용 결합도   | 다른 모듈의 내부 기능이나 데이터를 직접 참조·변경 | 내부 직접 접근 |
| 공통 결합도   | 여러 모듈이 공통 데이터 영역을 사용               | 전역 변수      |
| 외부 결합도   | 외부 장치·프로토콜·파일 형식에 함께 의존          | 외부 환경      |
| 제어 결합도   | 제어 플래그를 전달해 상대 모듈의 흐름을 결정      | 선택·제어값    |
| 스탬프 결합도 | 배열·구조체·객체·레코드 전체를 전달               | 자료구조 전체  |
| 자료 결합도   | 필요한 단순 데이터만 매개변수로 전달              | 값만 전달      |

### 즉답 키워드

```text
다른 모듈 내부를 직접 수정 → 내용
전역 데이터 공유 → 공통
파일 형식이나 장치 공유 → 외부
처리 방법을 결정하는 플래그 → 제어
필요 없는 필드까지 포함한 구조체 전달 → 스탬프
필요한 값만 전달 → 자료
```

## 4. 응집도 강도 순서

강함에서 약함 순서다.

```text
기능 → 순차 → 교환 → 절차 → 시간 → 논리 → 우연
```

암기:

```text
기순교절시논우
```

## 5. 응집도 종류

| 응집도               | 설명                                          | 식별어         |
| -------------------- | --------------------------------------------- | -------------- |
| 기능적 응집도        | 모든 요소가 하나의 명확한 기능을 수행         | 단일 목적      |
| 순차적 응집도        | 한 활동의 출력이 다음 활동의 입력             | 출력→입력      |
| 교환적·통신적 응집도 | 여러 활동이 같은 입력 또는 출력 데이터를 사용 | 동일 데이터    |
| 절차적 응집도        | 관련 기능을 정해진 순서로 수행                | 수행 순서      |
| 시간적 응집도        | 특정 시점에 함께 실행되는 기능을 모음         | 초기화·종료    |
| 논리적 응집도        | 유사 기능 중 매개변수에 따라 하나를 선택      | 같은 범주·선택 |
| 우연적 응집도        | 관련 없는 기능을 임의로 모음                  | 관계없음       |

## 6. 가장 헷갈리는 비교

### 순차적과 절차적

```text
앞의 출력이 다음 입력으로 사용 → 순차적
데이터 연결 없이 실행 순서만 관련 → 절차적
```

### 교환적과 절차적

```text
동일한 입력·출력 데이터를 공유 → 교환적
단순히 정해진 순서대로 수행 → 절차적
```

### 제어 결합도와 자료 결합도

```text
전달값이 상대 모듈의 처리 흐름을 선택 → 제어 결합도
전달값 자체가 처리할 업무 데이터 → 자료 결합도
```

### 스탬프와 자료 결합도

```text
객체·구조체 전체 전달 → 스탬프
필요한 필드값만 전달 → 자료
```

## 7. Fan-In과 Fan-Out

| 용어    | 의미                                         |
| ------- | -------------------------------------------- |
| Fan-In  | 해당 모듈을 호출하거나 제어하는 상위 모듈 수 |
| Fan-Out | 해당 모듈이 호출하거나 제어하는 하위 모듈 수 |

- Fan-In이 높으면 여러 곳에서 재사용되는 공통 모듈일 가능성이 있다.
- Fan-Out이 지나치게 높으면 다른 모듈에 대한 의존성이 클 수 있다.

## 8. 모듈화의 장점

```text
복잡도 감소
재사용성 증가
변경 영향 범위 축소
테스트와 유지보수 용이
병렬 개발 가능
```

모듈 독립성은 응집도와 결합도를 통해 평가한다.

## 9. 미니 확인 문제

1. 다른 모듈의 내부 로직을 직접 호출한다. → **내용 결합도**
2. 여러 모듈이 하나의 전역 설정값을 수정한다. → **공통 결합도**
3. 처리 모드를 나타내는 플래그를 전달한다. → **제어 결합도**
4. 한 단계의 결과가 다음 단계의 입력이 된다. → **순차적 응집도**
5. 시스템 시작 시 필요한 기능을 한 모듈에 모았다. → **시간적 응집도**
6. 모듈이 하나의 계산 기능만 수행한다. → **기능적 응집도**

## 10. 시험 직전 암기

```text
좋은 설계 = 낮은 결합도 + 높은 응집도
결합도 강→약 = 내공외제스자
응집도 강→약 = 기순교절시논우
전역 = 공통 결합도
플래그 = 제어 결합도
구조체 전체 = 스탬프 결합도
출력→입력 = 순차적 응집도
같은 데이터 = 교환적 응집도
같은 시점 = 시간적 응집도
```
