## 오늘의 문제의식

기존 봇은 고정 익절(마진 +40%)에서 무조건 청산했다. 추세가 크게 터지는 날에도
+1.33%(가격 기준)에서 수익을 잘라먹는 구조. 오늘은 두 가지를 바꿨다.

1. **하한선은 걸되 상방은 열어두기** — 익절 주문 제거 + 트레일링 스탑
2. **선행지표가 가리키면 미리 들어가기** — 조기진입 경로 신설

## 1. 상방 무제한 전환에서 배운 것

설정(`TP_DISABLED_SYMBOLS`)만 바꾸면 끝인 줄 알았는데, **거래소에 이미 등록된
TAKE_PROFIT_MARKET 주문은 설정과 무관하게 살아있었다**.

```
TP 트리거 96.55 = 진입가 +1.33%   ← 여기서 익절돼버림
트레일링 활성  = 진입가 +1.50%   ← 여기 도달 전에!
```

트레일링이 켜지기도 전에 예전 TP가 먼저 맞는 타이밍 함정. 보호주문 재장전
로직(`cancel_protective_orders` → SL만 재등록)을 수동 실행해서 해결했다.

```python
c.cancel_protective_orders('SOLUSDT')      # SL/TP 조건부 주문만 취소
c.place_stop_loss('SOLUSDT', 'LONG', 17.67, 94.3272)  # 하한선만 복구
```

교훈: **내부 상태와 거래소 상태는 별개다.** 설정 변경 후엔 반드시 거래소
미체결 주문을 직접 조회해서 검증할 것.

## 2. 선행지표 조기진입 (early entry)

기존 구조의 모순: 선행지표(CVD·OI·펀딩·탑트레이더·베이시스)는 그룹 하드캡
±0.6인데 진입 임계값은 3.0. 선행지표가 만장일치로 외쳐도 후행 가격지표들이
확인해줄 때까지 진입 불가 — "선행"의 의미가 없었다.

### 설계

```
경로 A (early_leading):  선행그룹 원점수 ≥ 0.8 + HTF 추세 동의
                          → 예산 50%로 선진입
경로 B (early_counter):  펀딩 극단 + 탑트레이더 갭 동일 역방향
                          → 군중 반대로 50% 선진입 (HTF 불요)

이후:
  결합점수 임계 도달(확인)  → 나머지 50% 시장가 증량, SL 재계산
  180분 내 미확인 + 신호소멸 → 조기 청산
```

핵심 구현 포인트:

```python
# Signal에 진입 종류 태그 추가 — reason 문자열 파싱 대신 명시적 필드
entry_kind: str = ""  # "" | "early_leading" | "early_counter"

# 증량 시 SL은 "더 보호적인 쪽"만 채택 (트레일링이 올려둔 SL을 되돌리지 않음)
pos.stop_loss = max(pos.stop_loss, default_sl) if side == "LONG" else min(...)
```

증량 후 평균단가는 내부 계산 대신 **거래소 기록(entryPrice)을 신뢰**한다 —
시장가 슬리피지가 반영된 값이라 SL/TP 거리가 의도와 어긋나지 않는다
(지난주 시장가 체결가 보정 픽스와 같은 원칙).

### 안전장치

- 두 경로가 반대 방향이면 진입 보류 (근거 모호)
- 결합점수가 반대로 절반 임계 이상 기울면 차단
- env 기본값 전부 OFF — 기존 테스트 120개 그대로 통과 확인 후 8개 추가 (128개)

## 3. 병합에서 만난 함정 — 자동 병합이 만든 중복 블록

파이(운영)와 맥(개발) 브랜치를 병합하는데, git이 충돌 없이 "성공"한 영역에서
점수 가산 블록(htf/volume/taker/선행지표/trend_bonus)이 **통째로 두 번** 들어갔다.

발견 경로가 재미있다. 테스트 로그에 `TREND_BONUS:BUY(c=+0.30)`가 두 번 찍혔고,
점수가 정확히 2배로 뻥튀기돼 있었다. 충돌 마커만 보고 병합을 끝냈다면 실계좌에서
가짜 신호가 났을 것. **병합 후 전체 테스트는 선택이 아니라 필수다.**

## 오늘의 상태

- 파이 운영: `feat/early-leading-entry` 배포, 조기진입은 OFF (관찰 후 ON 예정)
- SOL LONG: TP 없이 트레일링만 — 마진 +45% 도달 시부터 하한선이 고점 추적
- 다음: 조기진입 ON 시점 판단, TTM 스퀴즈·RSI 다이버전스 전략 추가 검토
