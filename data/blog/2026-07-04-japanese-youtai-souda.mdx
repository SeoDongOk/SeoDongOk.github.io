일본어 추측 표현 중에서 시험에 제일 잘 나오고 제일 헷갈리는 게 **そうだ**다.
같은 そうだ인데 접속에 따라 **"~해 보인다"(양태)**가 되기도 하고 **"~라고 한다"(전문)**가 되기도 하기 때문이다.

이 글은 그중 **양태(様態, ようたい)** 를 중심으로 정리한다.

## 양태란 무엇인가

양태 そうだ는 **눈앞의 모습을 보고 받은 인상**을 말하는 표현이다.

- 空(そら)が暗(くら)い。雨(あめ)が**降(ふ)りそうだ**。— 하늘이 어둡다. 비가 **내릴 것 같다**.
- このケーキ、**おいしそう**！— 이 케이크 **맛있어 보인다**!

핵심 감각: **아직 일어나지 않았거나 확인하지 않았지만, 겉모습이 그렇게 보인다.**
케이크를 아직 안 먹었으니까 おいしそう다. 먹어보고 나면 그냥 おいしい라고 하면 된다.

## 접속 규칙 — 여기가 점수 갈리는 지점

양태 そうだ는 **짧은 형태**에 붙는다. 이게 전문 そうだ와의 결정적 차이다.

| 품사     | 접속                       | 예                                                         |
| -------- | -------------------------- | ---------------------------------------------------------- |
| 동사     | **ます형 어간** + そうだ   | 降り**そうだ** / 倒(たお)れ**そうだ** / 泣(な)き**そうだ** |
| い형용사 | **어간(い 떼고)** + そうだ | おいし**そうだ** / 高(たか)**そうだ** / 寒(さむ)**そうだ** |
| な형용사 | **어간** + そうだ          | 元気(げんき)**そうだ** / ひま**そうだ** / まじめ**そうだ** |

⚠️ 명사에는 양태 そうだ를 붙일 수 없다. 「学生そうだ」(×) → 「学生のようだ / 学生らしい」(○)

### 예외 2개 (시험 단골)

| 원형        | 양태형       | 비고                                   |
| ----------- | ------------ | -------------------------------------- |
| いい (좋다) | **よさそう** | いさそう(×), いいそう(×→이건 전문)     |
| ない (없다) | **なさそう** | お金が**なさそう**だ。돈이 없어 보인다 |

い형용사의 부정형에도 같은 규칙이 적용된다: おいしく**ない** → おいしく**なさそう** (맛없어 보인다)

### 부정형 — "~할 것 같지 않다"

동사의 양태 부정은 형태가 특이해서 따로 외워야 한다.

- 雨は降り**そうもない** / 降り**そうにない**。— 비는 내릴 것 같지 않다.
- バスはなかなか来(き)**そうもない**。— 버스는 좀처럼 올 것 같지 않다.

## 양태 そうだ는 な형용사처럼 활용된다

そうだ가 붙으면 통째로 な형용사가 된다. 그래서 명사를 꾸밀 땐 **そうな**, 동사를 꾸밀 땐 **そうに**.

| 형태                | 예문                                                                             |
| ------------------- | -------------------------------------------------------------------------------- |
| 〜そうだ (술어)     | 雨が降り**そうだ**。                                                             |
| 〜そうな + 명사     | 降り**そうな**空(そら) — 비가 올 것 같은 하늘 / おいし**そうな**ケーキ           |
| 〜そうに + 동사     | 子(こ)どもがおいし**そうに**食べている。— 아이가 맛있게(맛있어 보이게) 먹고 있다 |
| 〜そうでした (과거) | 赤(あか)ちゃんが泣(な)き**そうでした**。— 아기가 울 것 같았다                    |

「今(いま)にも」(지금이라도)와 세트로 자주 나온다: 今にも雨が降り**そうだ**。

## 양태 vs 전문 — 접속만 보면 1초 만에 구분된다

|               | 양태 (~해 보인다)           | 전문 (~라고 한다)          |
| ------------- | --------------------------- | -------------------------- |
| 근거          | 내 눈 (직접 본 인상)        | 남의 말·뉴스 (들은 정보)   |
| 동사 접속     | ます형 어간: 降**り**そうだ | 보통형: 降**る**そうだ     |
| い형용사 접속 | 어간: おいし**そうだ**      | 그대로: おいし**い**そうだ |
| な형용사 접속 | 어간: 元気**そうだ**        | だ 붙임: 元気**だ**そうだ  |
| 명사          | 불가                        | 学生**だ**そうだ           |
| 신호 표현     | 今にも, (~を見て)           | 〜によると, 〜の話では     |

같은 문장으로 비교하면:

- 雨が**降りそうだ**。→ (하늘을 보니) 비가 **올 것 같다**. 【양태】
- 雨が**降るそうだ**。→ (일기예보에서) 비가 **온다고 한다**. 【전문】
- このパン、**おいしそうだ**。→ (보기에) 맛있겠다. 【양태】
- このパン、**おいしいそうだ**。→ 맛있다**고 들었다**. 【전문】

딱 한 글자 차이로 뜻이 완전히 달라진다. **짧으면 양태, 길면(보통형 그대로면) 전문.**

## ようだ・みたいだ・らしい와의 경계

추측 4대장 전체에서 양태 そうだ의 위치는 "**직전의 시각 인상**" 담당이다.

| 표현            | 근거                       | 예문                                               |
| --------------- | -------------------------- | -------------------------------------------------- |
| 〜そうだ (양태) | 지금 눈에 보이는 모습      | 木が倒れ**そうだ** (나무가 기울어져 있는 걸 봄)    |
| 〜ようだ        | 관찰을 종합한 나의 판단    | 誰(だれ)もいない**ようだ** (불 꺼짐+조용함을 종합) |
| 〜みたいだ      | ようだ의 회화체            | 留守(るす)**みたい**だね                           |
| 〜らしい        | 남에게 들은 정보 기반 판단 | あの店(みせ)はおいしい**らしい** (소문)            |

구분 요령: **"방금 그걸 직접 봤나?"** → Yes면 양태 そうだ. **"누가 말해줬나?"** → 그대로 전달이면 전문 そうだ, 내 판단이 섞였으면 らしい. **"내가 여러 정황을 종합했나?"** → ようだ.

## 셀프 체크 5문

1. （空を見て）今にも雨が＿＿だ。
2. 天気予報によると、明日は寒くなる＿＿だ。
3. この問題は＿＿だ。(어려워 보인다)
4. 彼女は元気が＿＿だ。(기운이 없어 보인다)
5. 楽し＿＿に話していますね。(즐거운 듯이)
