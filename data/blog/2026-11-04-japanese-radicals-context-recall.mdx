[부수 전체 목록과 테스트](/blog/2026-09-13-japanese-kanji-radicals-quiz), [부수 크러시 코스](/blog/2026-09-26-bjt-bushu-crash-course) 다음 단계다. 이번 목표는 부수 이름을 더 많이 외우는 것이 아니라 **단어 속에서 모양을 알아보고 문장 뜻까지 연결하는 것**이다.

## 1. 먼저 구분할 것: 부수와 구성 요소

부수는 사전에서 한자를 분류하는 기준이다. 한 글자 안에서 보이는 모든 조각이 그 글자의 부수인 것은 아니다. 이 글에서는 사전 분류를 말할 때는 ‘부수’, 기억을 위해 글자를 나눌 때는 ‘구성 요소’라고 부른다.

- `休`는 `亻 + 木`으로 나누어 기억할 수 있지만, 둘 다 休의 부수라고 부르지는 않는다.
- `氵`를 보면 물과 관련된 뜻을 예상할 수 있지만, 그것만으로 글자 전체 뜻이나 읽기를 확정할 수는 없다.
- `海`의 毎를 현대 일본어 뜻 ‘매일’과 연결한 이야기는 암기 보조일 뿐, ‘매일 물이 모여 바다가 됐다’는 식의 실제 어원 설명이 아니다.

**모양 분해 → 의미 힌트 → 단어와 문맥으로 확인**의 순서를 지킨다. 이야기로 기억한 내용과 역사적 자원 설명은 구분한다.

## 2. 변형을 묶어서 외울 12군

한 줄을 본 뒤 가리고, 변형 모양과 예시 단어 하나를 떠올린다. 아래는 학습용 묶음이지 공식 출제 빈도 순위가 아니다.

| 기본형·변형 | 대표 명칭 | 기억할 이미지 | 단어 속 연결 |
| --- | --- | --- | --- |
| 人 → 亻 | ひと・にんべん | 사람 | 休暇（きゅうか）휴가 |
| 水 → 氵 | みず・さんずい | 물 | 海外（かいがい）해외 |
| 手 → 扌 | て・てへん | 손·동작 | 指定（してい）지정 |
| 心 → 忄 | こころ・りっしんべん | 마음·상태 | 情報（じょうほう）정보 |
| 火 → 灬 | ひ・れっか | 불·열 | 照明（しょうめい）조명 |
| 犬 → 犭 | いぬ・けものへん | 짐승 | 独立（どくりつ）독립 |
| 刀 → 刂 | かたな・りっとう | 칼·나눔 | 判断（はんだん）판단 |
| 糸（왼쪽 糹 모양） | いと・いとへん | 실·연결 | 給料（きゅうりょう）급료 |
| 言（왼쪽 訁 모양） | ことば・ごんべん | 말 | 計画（けいかく）계획 |
| 金（왼쪽 釒 모양） | かね・かねへん | 금속 | 銀行（ぎんこう）은행 |
| 艸 → 艹 | くさ・くさかんむり | 풀·식물 | 薬局（やっきょく）약국 |
| 辵 → 辶 | しんにょう | 이동 | 送信（そうしん）송신 |

일본어 신자체의 일반적인 표기는 `糸・言・金`을 유지한다. 중국어 간체의 `纟・讠・钅`로 바꾸어 외우지 않는다. 변형 모양은 폰트에 따라 다르게 보일 수 있다.

표의 이미지는 범주를 잡는 힌트다. 예를 들어 `独立`의 뜻 ‘독립’을 犭의 ‘짐승’만으로 알아낼 수는 없다. **힌트가 약한 단어는 단어 전체로 따로 기억**한다.

## 3. 모양이 비슷해도 같은 부수가 아니다

| 비교 | 구별 포인트 | 예시 |
| --- | --- | --- |
| 氵 / 冫 | 세 점 / 두 점 | 海・洗 / 冷・凍 |
| 扌 / 忄 | 손 계열 / 마음 계열. 둘 다 세 획처럼 보여도 획 배치가 다르다. | 持・指 / 情・忙 |
| 礻 / 衤 | 보일 시 계열 / 옷 의 계열. 衤는 아래쪽 획을 더 확인한다. | 社・神 / 被・補 |
| 口 / 囗 | 입 모양 / 글자를 둘러싸는 큰 테두리 | 味・唱 / 国・園 |
| 왼쪽 阝 / 오른쪽 阝 | 왼쪽은 阜 계열, 오른쪽은 邑 계열 | 院・階 / 都・部 |

특히 `阝`는 위치를 함께 외운다. 왼쪽의 こざとへん과 오른쪽의 おおざとは 모양이 닮았어도 다른 계열이다.

`月`도 주의한다. `期`의 月과 `胸・腕` 같은 몸 관련 글자의 月 모양을 무조건 같은 ‘달’로 해석하지 않는다. 몸 관련 글자에는 肉이 변형된 **にくづき**가 쓰인다.

## 4. 한자 하나가 아니라 단어 가족으로

### 言: 말 → 확인하고 전달하는 업무

| 단어 | 읽기 | 뜻 |
| --- | --- | --- |
| 計画 | けいかく | 계획 |
| 説明 | せつめい | 설명 |
| 調整 | ちょうせい | 조정 |
| 認識 | にんしき | 인식 |

> 計画を説明し、日程を調整します。  
> 계획을 설명하고 일정을 조정합니다.

計・説・調・認에서 言을 찾는다. 그다음 각 단어의 **읽기와 실제 쓰임**을 따로 확인한다. 言이 있다는 이유로 네 단어를 같은 뜻으로 처리하지 않는다.

### 糸: 실 → 잇고 맺는 이미지

| 단어 | 읽기 | 뜻 |
| --- | --- | --- |
| 連絡 | れんらく | 연락 |
| 結果 | けっか | 결과 |
| 継続 | けいぞく | 계속 |
| 給料 | きゅうりょう | 급료 |

> 結果を確認してから、担当者に連絡します。  
> 결과를 확인한 뒤 담당자에게 연락합니다.

絡・結・継・続・給의 공통 모양을 찾는다. **連에는 糸가 없고 辶가 있다.** 단어에 한자 두 개가 있다고 해서 같은 부수로 묶이지는 않는다.

### 辶: 이동 → 보내고 진행하는 이미지

| 단어 | 읽기 | 뜻 |
| --- | --- | --- |
| 送信 | そうしん | 송신 |
| 返信 | へんしん | 회신 |
| 進捗 | しんちょく | 진척 |
| 遅延 | ちえん | 지연 |

> 進捗を確認し、遅延があれば連絡します。  
> 진척을 확인하고 지연이 있으면 연락합니다.

送・返・進・遅에서 辶를 찾는다. `進捗`의 읽기는 부수로 계산할 수 없으므로 단어 단위로 기억한다.

## 5. 가리고 푸는 회상 테스트 12문제

종이에 답을 적고 나서 아래 정답을 펼친다. 부수 이름만 기억나지 않더라도 이미지와 단어를 맞혔다면 따로 표시한다.

1. 水가 왼쪽에 놓일 때 자주 나타나는 모양은?
2. 心이 왼쪽에 놓일 때 자주 나타나는 모양은?
3. 氵와 冫는 각각 어떤 의미 이미지를 떠올리게 하는가?
4. 社와 補의 왼쪽 부분은 같은 계열인가?
5. 院과 部의 阝는 어느 위치에 있으며 같은 계열인가?
6. 胸의 月 모양을 무조건 ‘달’로 해석해도 되는가?
7. 計画・説明・調整의 計・説・調에서 공통으로 보이는 요소는?
8. 連絡에서 糸 모양이 있는 한자는 어느 쪽인가?
9. 送信의 읽기와 뜻은?
10. 進捗의 읽기와 뜻은?
11. `結果を確認してから、担当者に連絡します。`를 해석하라.
12. 부수만 알면 처음 보는 한자의 읽기까지 확정할 수 있는가?

1. 氵. さんずい.
2. 忄. りっしんべん.
3. 氵는 물, 冫는 얼음·차가움의 이미지.
4. 아니다. 社는 礻, 補는 衤 계열.
5. 院은 왼쪽, 部는 오른쪽. 각각 阜와 邑 계열로 다르다.

## 6. 오답을 네 종류로 나누기

| 오답 유형 | 기록 예시 | 다음 행동 |
| --- | --- | --- |
| 모양 혼동 | 社의 왼쪽을 衤로 봄 | 社 / 補를 나란히 쓰고 획 비교 |
| 의미 과잉 추론 | 犭만 보고 独立의 뜻을 추측함 | 뜻은 단어 전체로 다시 학습 |
| 읽기 실패 | 進捗의 뜻은 알지만 못 읽음 | しんちょく를 가리고 회상 |
| 문장 적용 실패 | 단어를 알지만 문장 순서를 놓침 | 確認してから의 선후 관계까지 해석 |

모양을 틀린 사람과 읽기를 틀린 사람이 같은 목록을 처음부터 다시 볼 필요는 없다.

## 7. 하루 15분 복습 설계

- **3분:** 변형 12군 중 헷갈린 3군만 가리고 쓰기
- **4분:** 단어 가족 한 묶음의 뜻과 읽기 회상
- **5분:** 예문 하나 읽기 → 가리기 → 의미 말하기
- **3분:** 오늘 오답을 분류하고 다음 복습 항목 선택

신규 단어는 하루 10개 이하로 제한한다. 당일·다음 날·3일 뒤·7일 뒤에 다시 떠올리되, 계속 틀리면 간격을 줄이고 해당 단어를 더 짧은 문장에 넣는다.

이 글의 종료 목표는 **12문제 중 10개 이상 + 틀린 문제를 다음 날 다시 맞히기**다. 이는 개인 학습용 기준이며 JLPT·BJT 합격을 보장하는 기준은 아니다.

부수는 정답을 자동으로 만들어 주는 공식이 아니다. **모양을 기억하는 발판으로 사용하고, 뜻과 읽기는 단어·문장으로 완성한다.**
