정보처리기사 실기에서 C언어 출력 문제는 가장 점수 비중이 크고, 동시에 가장 실수하기 쉽다.  
내가 약한 부분은 포인터와 배열이 섞이거나, 재귀와 증감 연산이 같이 나오면 추적이 흔들리는 점이다.

이번 글은 고난이도 C 문제를 패턴별로 정리한다.

## 1. C 출력 문제 풀이 순서

C 문제는 눈으로 대충 풀면 틀린다. 항상 표를 그리듯이 추적한다.

```text
1. 변수 초기값을 적는다.
2. 포인터가 무엇을 가리키는지 화살표로 표시한다.
3. 반복문은 i, j 값을 표로 쓴다.
4. 재귀는 호출 스택을 펼친다.
5. 출력 직전의 값만 최종 확인한다.
```

특히 포인터 문제는 아래 차이를 반드시 구분한다.

```c
*p + 1     // p가 가리키는 값에 1 더함
*(p + 1)   // p 다음 위치의 값을 참조
```

## 2. 포인터 + 배열 패턴

```c
#include <stdio.h>
int main() {
    int a[] = {10, 20, 30, 40};
    int *p = a;
    printf("%d\n", *(p + 2));
    printf("%d\n", *p + 2);
    return 0;
}
```

정답:

```text
30
12
```

풀이:

```text
p = a = &a[0]
*(p+2) = a[2] = 30
*p + 2 = a[0] + 2 = 10 + 2 = 12
```

포인트는 괄호다.

## 3. 포인터 증감 패턴

```c
#include <stdio.h>
int main() {
    int a[] = {1, 2, 3, 4, 5};
    int *p = a;
    p++;
    printf("%d\n", *p);
    printf("%d\n", *(++p));
    return 0;
}
```

정답:

```text
2
3
```

풀이:

```text
처음 p는 a[0]
p++ 후 p는 a[1], *p = 2
++p 후 p는 a[2], *(++p) = 3
```

포인터가 이동하는지, 값이 증가하는지 구분해야 한다.

## 4. 이중 포인터 패턴

```c
#include <stdio.h>
int main() {
    int x = 7;
    int *p = &x;
    int **pp = &p;
    **pp += 5;
    printf("%d %d %d\n", x, *p, **pp);
    return 0;
}
```

정답:

```text
12 12 12
```

풀이:

```text
pp → p → x
**pp는 x 자체를 의미
x에 5를 더해서 12
```

## 5. 문자열 포인터 패턴

```c
#include <stdio.h>
int main() {
    char *s = "PROGRAM";
    printf("%c\n", *(s + 3));
    printf("%s\n", s + 4);
    return 0;
}
```

정답:

```text
G
RAM
```

풀이:

```text
P(0) R(1) O(2) G(3) R(4) A(5) M(6)
*(s+3) = 'G'
s+4 = "RAM"
```

`%c`는 문자 하나, `%s`는 해당 주소부터 널 문자 전까지 출력한다.

## 6. 구조체 + 포인터 패턴

```c
#include <stdio.h>
struct Node {
    int value;
};
int main() {
    struct Node n = {10};
    struct Node *p = &n;
    p->value += 3;
    printf("%d\n", n.value);
    return 0;
}
```

정답:

```text
13
```

풀이:

```text
p는 n의 주소
p->value는 n.value와 동일
10 + 3 = 13
```

구조체 포인터는 `->`를 사용한다.

```c
p->value
(*p).value
```

둘은 같은 의미다.

## 7. 재귀 함수 패턴

```c
#include <stdio.h>
int f(int n) {
    if(n == 0) return 0;
    return n + f(n - 1);
}
int main() {
    printf("%d\n", f(4));
    return 0;
}
```

정답:

```text
10
```

풀이:

```text
f(4) = 4 + f(3)
f(3) = 3 + f(2)
f(2) = 2 + f(1)
f(1) = 1 + f(0)
f(0) = 0
합계 = 4 + 3 + 2 + 1 + 0 = 10
```

재귀는 무조건 종료 조건부터 찾는다.

## 8. 재귀 출력 순서 패턴

```c
#include <stdio.h>
void f(int n) {
    if(n == 0) return;
    printf("%d", n);
    f(n - 1);
    printf("%d", n);
}
int main() {
    f(3);
    return 0;
}
```

정답:

```text
321123
```

풀이:

```text
f(3): 3 출력 → f(2) → 3 출력
f(2): 2 출력 → f(1) → 2 출력
f(1): 1 출력 → f(0) → 1 출력
```

호출 전 출력과 호출 후 출력의 위치를 구분해야 한다.

## 9. 증감 연산 패턴

```c
#include <stdio.h>
int main() {
    int a = 3;
    int b = a++ + ++a;
    printf("%d %d\n", a, b);
    return 0;
}
```

정답:

```text
5 8
```

풀이:

```text
a++: 3을 사용한 뒤 a=4
++a: 먼저 a=5, 5를 사용
b = 3 + 5 = 8
a = 5
```

전위는 먼저 증가, 후위는 나중 증가다.

## 10. switch fall-through 패턴

```c
#include <stdio.h>
int main() {
    int x = 2;
    switch(x) {
        case 1: printf("A");
        case 2: printf("B");
        case 3: printf("C"); break;
        case 4: printf("D");
    }
    return 0;
}
```

정답:

```text
BC
```

풀이:

```text
case 2부터 실행
break가 없으므로 case 3까지 실행
case 3의 break에서 종료
```

switch는 `break`가 없으면 아래 case로 계속 흐른다.

## 11. 비트 연산 패턴

```c
#include <stdio.h>
int main() {
    int a = 5; // 0101
    int b = 3; // 0011
    printf("%d %d %d\n", a & b, a | b, a ^ b);
    return 0;
}
```

정답:

```text
1 7 6
```

풀이:

```text
0101 & 0011 = 0001 = 1
0101 | 0011 = 0111 = 7
0101 ^ 0011 = 0110 = 6
```

암기:

```text
& = 둘 다 1
| = 하나라도 1
^ = 다르면 1
```

## 12. 자주 틀리는 포인트

| 패턴        | 실수                      | 해결                 |
| ----------- | ------------------------- | -------------------- |
| `*(p+1)`    | `*p+1`과 혼동             | 괄호 먼저 확인       |
| `p++`       | 값 증가로 착각            | 포인터 위치 이동     |
| `a++`       | 즉시 증가값 사용으로 착각 | 후위는 사용 후 증가  |
| 재귀        | 호출 후 코드 누락         | 스택 접기 전/후 구분 |
| switch      | break 누락                | fall-through 추적    |
| 문자열 `%s` | 문자 하나만 출력으로 착각 | 주소부터 문자열 출력 |

## 13. 시험 직전 체크리스트

```text
포인터가 어디를 가리키는지 표시했는가?
배열 인덱스를 0부터 세었는가?
전위/후위 증감 순서를 구분했는가?
재귀 종료 조건을 먼저 찾았는가?
switch의 break 위치를 확인했는가?
문자 출력인지 문자열 출력인지 확인했는가?
```

## 마무리

C언어 출력 문제는 감으로 풀면 틀린다.  
시험장에서는 코드가 길어 보여도 결국 아래 세 가지를 추적하는 문제다.

```text
값이 어떻게 바뀌는가?
포인터가 어디를 가리키는가?
출력 순서가 언제인가?
```

남은 기간에는 새로운 문법을 늘리기보다, 포인터·배열·재귀·문자열·구조체 패턴을 반복해서 손으로 추적하는 것이 가장 효율적이다.
