> FSA에서 개별 회계처리를 외우기 전에 반드시 먼저 잡아야 할 것이 있다. **한 거래가 세 재무제표를 동시에 어떻게 움직이는가**다. 이걸 못 따라가면 뒤에 나오는 재고자산·감가상각·이연법인세가 전부 따로 노는 암기가 된다.

## 회계등식

모든 것의 출발점은 한 줄이다.

```text
Assets = Liabilities + Equity
자산 = 부채 + 자본
```

이 등식은 "회사가 가진 것(자산)은 누군가에게 갚아야 할 몫(부채)과 주주 몫(자본)의 합"이라는 뜻이다. 어떤 거래를 기록하든 이 등식은 항상 성립한다. 복식부기가 하는 일이 바로 이 등식을 깨지지 않게 유지하는 것이다.

자본을 한 단계 더 풀면 이렇게 된다.

```text
Equity = Contributed capital + Retained earnings
자본 = 납입자본 + 이익잉여금
```

그리고 이익잉여금은 다시 이렇게 움직인다.

```text
기말 이익잉여금 = 기초 이익잉여금 + 당기순이익 - 배당
```

**이 마지막 줄이 손익계산서와 재무상태표를 잇는 다리다.** 손익계산서의 결론인 당기순이익이 재무상태표의 이익잉여금으로 들어간다.

## 재무제표 3종의 역할

| 재무제표   | 답하는 질문                        | 시점 성격     |
| ---------- | ---------------------------------- | ------------- |
| 재무상태표 | 특정 시점에 무엇을 가지고 있는가   | 스톡 (시점)   |
| 손익계산서 | 기간 동안 얼마를 벌었는가          | 플로우 (기간) |
| 현금흐름표 | 기간 동안 현금이 어떻게 움직였는가 | 플로우 (기간) |

여기서 자주 헷갈리는 지점: **재무상태표는 시점, 나머지 둘은 기간이다.** "2026년 12월 31일 현재"의 재무상태표와 "2026년 1월 1일부터 12월 31일까지"의 손익계산서는 성격이 다르다. 재무비율을 계산할 때 평균 잔액을 쓸지 기말 잔액을 쓸지 헷갈리는 원인이 여기 있다.

## 발생주의: 이익과 현금이 다른 이유

손익계산서는 **발생주의(accrual basis)** 로 작성된다. 현금이 오갔는지가 아니라, 수익이 벌어졌는지·비용이 발생했는지를 기준으로 기록한다.

- 외상으로 물건을 팔았다 → 현금은 안 들어왔지만 **매출은 인식된다**
- 다음 해 보험료를 미리 냈다 → 현금은 나갔지만 **당기 비용이 아니다**

그래서 이익이 나는데 현금이 마르는 회사가 존재한다. 현금흐름표가 따로 필요한 이유가 이것이다.

이 차이를 만드는 계정들이 발생액(accruals)이다.

| 계정     | 성격      | 이익과 현금의 관계                  |
| -------- | --------- | ----------------------------------- |
| 매출채권 | 자산 증가 | 이익은 잡혔지만 현금은 아직 없음    |
| 선급비용 | 자산 증가 | 현금은 나갔지만 비용은 아직 아님    |
| 매입채무 | 부채 증가 | 비용은 잡혔지만 현금은 아직 안 나감 |
| 선수수익 | 부채 증가 | 현금은 들어왔지만 수익은 아직 아님  |

## 현금흐름표의 3분류

현금흐름표는 현금 변동을 세 갈래로 나눈다.

- **영업활동(CFO)**: 본업에서 나온 현금
- **투자활동(CFI)**: 유형자산·투자자산의 취득과 처분
- **재무활동(CFF)**: 차입, 상환, 증자, 배당

```text
CFO + CFI + CFF = 현금의 순증감
기초 현금 + 현금의 순증감 = 기말 현금
```

그리고 이 기말 현금이 **재무상태표의 현금 계정과 일치해야 한다.** 여기서 세 표가 닫힌다.

## 거래 하나로 3표 추적하기

가장 중요한 훈련이다. 예제 하나로 확인한다.

> 재고를 100에 현금으로 매입한 뒤, 이를 150에 외상으로 판매했다.

**1단계 — 재고 매입 (현금 100 지출)**

| 재무제표   | 영향                                |
| ---------- | ----------------------------------- |
| 재무상태표 | 현금 −100, 재고 +100 (자산 내 대체) |
| 손익계산서 | 영향 없음                           |
| 현금흐름표 | CFO −100                            |

자산 총액은 그대로다. 등식이 유지된다. 그리고 **아직 비용이 아니다.** 재고는 팔릴 때 비용(매출원가)이 된다.

**2단계 — 150에 외상 판매**

| 재무제표   | 영향                                     |
| ---------- | ---------------------------------------- |
| 재무상태표 | 매출채권 +150, 재고 −100, 이익잉여금 +50 |
| 손익계산서 | 매출 +150, 매출원가 −100, 당기순이익 +50 |
| 현금흐름표 | 영향 없음 (현금 미수취)                  |

자산은 +50(150−100), 자본은 이익잉여금 +50. 등식 성립.

**여기가 핵심이다.** 이 시점에서 회사는 이익 50을 보고하지만, 현금은 오히려 100이 빠져 있다. 이익과 현금의 방향이 정반대다.

**3단계 — 매출채권 150 회수**

| 재무제표   | 영향                     |
| ---------- | ------------------------ |
| 재무상태표 | 현금 +150, 매출채권 −150 |
| 손익계산서 | 영향 없음                |
| 현금흐름표 | CFO +150                 |

이제야 현금이 들어온다. 손익계산서는 이미 2단계에서 끝났으므로 아무 일도 일어나지 않는다.

## 오답 포인트

| 함정                           | 확인할 것                                       |
| ------------------------------ | ----------------------------------------------- |
| 현금 지출 = 비용으로 착각      | 재고 매입, 유형자산 취득은 지출이지 비용이 아님 |
| 비용 발생 = 현금 유출로 착각   | 감가상각은 비용이지만 현금 유출이 아님          |
| 이익이 나면 현금도 는다고 가정 | 매출채권·재고가 늘면 반대가 될 수 있음          |
| 시점과 기간 혼동               | 재무상태표만 시점, 나머지는 기간                |
| 이익잉여금에 배당 반영 누락    | 기말 RE = 기초 RE + NI − 배당                   |
