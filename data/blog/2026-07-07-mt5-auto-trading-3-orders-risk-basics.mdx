> 이 글은 학습용 정리이며 투자 권유가 아니다. 자동매매의 첫 목표는 수익 극대화가 아니라 계좌 생존이다.

MT5 자동매매에서 초보자가 가장 먼저 배워야 할 것은 전략 지표가 아니라 **주문과 리스크 관리**다. 프로그램이 아무리 잘 짜여 있어도 주문 크기와 손절 규칙이 잘못되면 계좌는 빠르게 망가질 수 있다.

## 1. 시장가와 예약 주문

MT5에서 자주 쓰는 주문은 크게 두 종류다.

| 구분        | 설명                                |
| ----------- | ----------------------------------- |
| 시장가 주문 | 현재 가능한 가격으로 즉시 매수/매도 |
| 예약 주문   | 특정 가격 조건이 오면 주문 실행     |

예약 주문은 다시 여러 종류로 나뉜다.

| 주문       | 의미                                 |
| ---------- | ------------------------------------ |
| Buy Limit  | 현재가보다 낮은 가격에 매수 대기     |
| Sell Limit | 현재가보다 높은 가격에 매도 대기     |
| Buy Stop   | 현재가보다 높은 가격을 돌파하면 매수 |
| Sell Stop  | 현재가보다 낮은 가격을 이탈하면 매도 |
| Stop Limit | Stop 조건 도달 후 Limit 주문을 배치  |

처음 자동매매를 만들 때는 시장가 주문부터 이해하는 것이 좋다. 예약 주문은 체결 조건과 취소 로직까지 관리해야 해서 복잡도가 올라간다.

## 2. Bid, Ask, Spread

거래에는 보통 두 가격이 있다.

| 가격   | 의미                     |
| ------ | ------------------------ |
| Bid    | 내가 매도할 수 있는 가격 |
| Ask    | 내가 매수할 수 있는 가격 |
| Spread | Ask와 Bid의 차이         |

매수는 Ask에 체결되고, 매도는 Bid에 체결된다. 그래서 진입하는 순간 스프레드만큼 불리하게 시작한다.

자동매매에서는 스프레드 필터가 중요하다.

```text
스프레드가 평소보다 너무 넓으면 진입하지 않는다.
```

특히 뉴스 발표, 장 시작/마감, 유동성이 낮은 시간에는 스프레드가 넓어질 수 있다.

## 3. Lot이란?

MT5에서 주문 수량은 보통 `lot` 단위로 입력한다. 다만 종목과 브로커마다 1 lot의 의미가 다르다.

예를 들어 FX에서는 1 lot이 100,000 통화 단위인 경우가 많지만, 금(XAUUSD), 지수, CFD는 계약 명세가 다르다. 따라서 코드를 만들기 전에 반드시 종목 명세를 확인해야 한다.

확인할 항목:

- 최소 lot
- lot 증가 단위
- 최대 lot
- 계약 크기
- 증거금 방식
- 최소 손절 거리

초보자는 고정 lot보다 “계좌 대비 리스크” 기준으로 수량을 계산하는 습관이 좋다.

## 4. 손절과 익절

자동매매에서 손절(Stop Loss)은 선택이 아니라 필수에 가깝다.

| 항목          | 의미                                                        |
| ------------- | ----------------------------------------------------------- |
| Stop Loss     | 손실 제한 가격                                              |
| Take Profit   | 이익 실현 가격                                              |
| Trailing Stop | 가격이 유리하게 움직이면 손절선을 따라 올리거나 내리는 방식 |

손절 없이 자동매매를 돌리면 다음 문제가 생긴다.

- 서버를 보지 않는 사이 손실이 커질 수 있다.
- 전략 오류가 계좌 손실로 바로 이어진다.
- 급변동장에서 강제청산 위험이 커진다.

가장 단순한 원칙은 이렇다.

```text
한 번의 거래에서 잃을 금액을 계좌의 0.5%~1% 이내로 제한한다.
```

이 수치는 예시일 뿐이며, 실제 비율은 상품 변동성, 레버리지, 전략 승률과 손익비에 따라 더 보수적으로 잡아야 한다.

## 5. 슬리피지와 체결 실패

자동매매는 주문 요청 가격과 실제 체결 가격이 다를 수 있다. 이를 슬리피지라고 한다.

슬리피지가 커지는 상황:

- 뉴스 발표 직후
- 유동성이 낮은 시간
- 급등락 장세
- 서버 지연
- 너무 작은 시간봉에서 잦은 주문

EA나 Python 코드에서는 주문 결과를 반드시 확인해야 한다.

```text
주문 요청 보냄
→ 성공 여부 확인
→ 실패 코드 확인
→ 실패 시 재시도 여부 판단
→ 로그 기록
```

주문 함수를 호출했다고 해서 반드시 체결된 것은 아니다.

## 6. 포지션 중복 방지

초보 자동매매에서 자주 나는 사고는 같은 조건에서 주문이 반복으로 나가는 것이다.

예를 들어 `OnTick()`은 새 가격 틱이 들어올 때마다 호출된다. 조건이 참인 동안 매번 매수 주문을 보내면 몇 초 만에 포지션이 여러 개 생길 수 있다.

따라서 최소한 아래 조건이 필요하다.

```text
이미 해당 종목 포지션이 있으면 신규 진입하지 않는다.
오늘 손실 한도에 도달하면 거래하지 않는다.
스프레드가 너무 넓으면 거래하지 않는다.
거래 시간이 아니면 거래하지 않는다.
```

## 7. 하루 손실 한도

전략 하나의 손절뿐 아니라 하루 전체 손실 한도도 필요하다.

예시:

```text
- 하루 손실이 계좌의 -2% 도달 → 그날 거래 중지
- 연속 손절 3회 → 그날 거래 중지
- 서버/주문 오류 3회 이상 → 자동매매 중지
```

자동매매에서 “멈추는 규칙”은 “진입하는 규칙”만큼 중요하다.

## 8. 초보자용 리스크 체크리스트

실계좌로 가기 전에 아래 질문에 모두 답할 수 있어야 한다.

- 이 종목의 최소 lot은 얼마인가?
- 1 lot당 가격이 1포인트 움직이면 손익은 얼마인가?
- 내 손절가는 어디인가?
- 한 번 틀렸을 때 얼마를 잃는가?
- 스프레드가 넓을 때 진입을 막는가?
- 포지션 중복 진입을 막는가?
- 하루 손실 한도가 있는가?
- 주문 실패 시 로그가 남는가?
