## 시험 직전 빈출도

> **우선순위 A · ★★★★☆**
>
> 스케줄링 계산과 교착상태 4조건은 운영체제 영역의 대표적인 계산·단답 혼합 유형이다.

- **최소 암기:** FCFS·SJF·SRT·RR, 대기/반환 시간, 상호배제·점유대기·비선점·환형대기
- **5점 후보:** SJF=비선점 최단 작업 / SRT=선점 최단 잔여 / 교착상태 예방=4조건 중 하나 제거
- **판정 기준:** 별점은 Q-Net의 공식 출제 확률이 아니다. 2020년 1회~2026년 1회 복원 목록과 2026 시나공 핵심요약의 실기 출제 이력 표기를 개념군 단위로 교차해 정한 **시험 전날 상대 우선순위**다.

운영체제 문제는 프로세스 상태 전이, 스케줄링 방식, 평균 대기 시간, 교착상태 네 조건이 핵심이다. 계산 문제는 간트 차트를 먼저 그린다.

## 1. 프로세스와 프로그램

```text
프로그램 = 저장된 명령어 집합, 수동적
프로세스 = 실행 중인 프로그램, 능동적
```

## 2. 프로세스 상태

| 상태      | 의미                            |
| --------- | ------------------------------- |
| 생성      | 프로세스 생성 중                |
| 준비      | CPU 할당을 기다림               |
| 실행      | CPU를 사용하여 명령 수행        |
| 대기·블록 | 입출력이나 이벤트 완료를 기다림 |
| 종료      | 실행 완료                       |

### 상태 전이

```text
준비 → 실행: 디스패치
실행 → 준비: 시간 할당량 만료·선점
실행 → 대기: 입출력 요청
대기 → 준비: 입출력 완료
실행 → 종료: 작업 완료
```

## 3. PCB

운영체제가 프로세스를 관리하기 위해 유지하는 정보 구조다.

```text
프로세스 ID
프로세스 상태
프로그램 카운터
CPU 레지스터
스케줄링 정보
메모리 관리 정보
입출력 상태 정보
```

## 4. 문맥 교환

CPU가 실행할 프로세스를 바꿀 때 현재 프로세스의 상태를 PCB에 저장하고 다음 프로세스의 상태를 복원하는 작업이다.

- 문맥 교환 시간은 실제 사용자 작업을 수행하지 않는 오버헤드다.
- 지나치게 짧은 시간 할당량은 문맥 교환을 증가시킨다.

## 5. 선점과 비선점

| 구분     | 선점                   | 비선점                         |
| -------- | ---------------------- | ------------------------------ |
| CPU 회수 | 운영체제가 강제로 가능 | 프로세스 종료·대기 전까지 불가 |
| 응답성   | 높음                   | 상대적으로 낮음                |
| 오버헤드 | 큼                     | 작음                           |

## 6. 스케줄링 알고리즘

| 방식        | 선점 여부  | 핵심                                 |
| ----------- | ---------- | ------------------------------------ |
| FCFS        | 비선점     | 도착 순서                            |
| SJF         | 비선점     | 실행 시간이 가장 짧은 작업 우선      |
| SRT         | 선점       | 남은 실행 시간이 가장 짧은 작업 우선 |
| 우선순위    | 둘 다 가능 | 우선순위가 높은 작업 우선            |
| Round Robin | 선점       | 시간 할당량만큼 순환 실행            |
| HRN         | 비선점     | 대기 시간과 서비스 시간을 함께 고려  |

### HRN 우선순위

```text
(대기 시간 + 서비스 시간) / 서비스 시간
```

값이 클수록 우선순위가 높다. SJF의 긴 작업 기아 문제를 완화한다.

## 7. 시간 계산

```text
반환 시간 = 종료 시간 - 도착 시간
대기 시간 = 반환 시간 - 실행 시간
응답 시간 = 최초 실행 시간 - 도착 시간
```

계산 순서:

```text
1. 도착 시간과 실행 시간을 표로 정리
2. 알고리즘에 따라 간트 차트 작성
3. 각 프로세스 종료 시간 표시
4. 반환 시간 계산
5. 대기 시간 계산
```

## 8. 기아와 에이징

| 용어   | 의미                                            |
| ------ | ----------------------------------------------- |
| 기아   | 우선순위가 낮은 프로세스가 계속 CPU를 얻지 못함 |
| 에이징 | 오래 기다린 프로세스의 우선순위를 점차 높임     |

## 9. 교착상태

둘 이상의 프로세스가 서로 상대방이 가진 자원을 기다리며 영원히 진행하지 못하는 상태다.

### 발생 필요조건

```text
상호 배제
점유와 대기
비선점
환형 대기
```

네 조건이 모두 성립해야 교착상태가 발생할 수 있다.

## 10. 교착상태 처리

| 방법 | 의미                                              |
| ---- | ------------------------------------------------- |
| 예방 | 네 필요조건 중 하나가 성립하지 않게 함            |
| 회피 | 안전 상태를 유지하도록 자원 할당, 은행원 알고리즘 |
| 탐지 | 교착상태 발생 여부를 주기적으로 검사              |
| 회복 | 프로세스 종료·자원 선점으로 교착상태 제거         |

### 안전 상태

모든 프로세스가 정상적으로 종료할 수 있는 안전 순서가 존재하는 상태다. 안전 상태이면 교착상태가 발생하지 않는다.

## 11. 세마포어와 뮤텍스

| 구분   | 세마포어                 | 뮤텍스                       |
| ------ | ------------------------ | ---------------------------- |
| 값     | 정수 카운터 가능         | 일반적으로 잠금·해제 두 상태 |
| 소유권 | 소유권 개념이 약함       | 잠근 스레드가 해제           |
| 용도   | 여러 자원 개수 제어 가능 | 하나의 임계구역 상호배제     |

## 12. 시험 직전 암기

```text
준비→실행 = 디스패치
실행→대기 = 입출력 요청
대기→준비 = 입출력 완료
FCFS = 도착 순서
SJF = 짧은 실행 시간, 비선점
SRT = 짧은 남은 시간, 선점
RR = 시간 할당량
HRN = (대기+서비스)/서비스
반환 시간 = 종료-도착
대기 시간 = 반환-실행
기아 해결 = 에이징
교착상태 = 상호배제·점유대기·비선점·환형대기
회피 = 은행원 알고리즘
```
